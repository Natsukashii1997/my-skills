# AI 学习路径

常浩的学习总目录：每学会一样和 AI 一起做事的方法，就加一站；各站讲到的词收进同一本共用词典。只做汇总，不设自测（常浩 2026-11-11 定，issue #91）。

- 页面：`index.html`，发布在 https://claude.ai/artifact/PA1Zoa5EcKU3twHuNopsZV
- 风格：ui-styles「细线」，A 版「线路站点」布局（常浩 2026-11-11 从三版里选定）；只做浅色一套。
- 第 1 站：Matt 技能库指南（`docs/matt-guide/`）。

## 加一站

常浩说「把这个加进学习路径」时，按下面做：

1. 这一站自己的讲解页先做好、发布，拿到链接。讲解页不放进本目录，各在各的位置。
2. 在 `index.html` 的 `STATIONS` 末尾加一项：`id`（英文短名）、`n`（接着上一站编号）、`c`（识别色，按 `c1`→`c4` 轮换）、`name`、`en`、`date`（加入日期）、`what`（一句话学什么）、`parts`（讲解页的几个部分）、`url`。
3. 把这一站讲到的词加进 `GL`，每条 7 项：`[类别, 术语, 英文/别名, 白话, 比喻, 什么时候碰到, 所属站 id]`。
   - 类别优先用已有的；确实放不下再加新类别。
   - 词典里已经有的词不重复加（测试会拦重名）。
4. 讲解页里有自己的术语表数组（`var GL=[...]`）的，在 `tests/learning-path-glossary.test.mjs` 的 `SOURCES` 里登记「站 id → 文件」，测试会检查两边逐条一致。
5. 跑 `node --test tests/*.test.mjs`；电脑、手机两种宽度截图自检，等字体加载完再截；发布到上面的原链接。

## 改已有的词

先改那一站讲解页的术语表，再把同样的改动抄进这里的 `GL`。只改一边，测试会失败。
