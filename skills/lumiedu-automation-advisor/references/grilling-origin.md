# Grilling 的来源与改造对照

原作者 Matt Pocock，MIT 许可见包内 `LICENSE.grilling.txt`。本包保留 [原文字协议](grill-me-original.md)，以此改造提问控制逻辑；原版没有可继承的程序代码。

来源：[mattpocock/skills 中的 grilling](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md)。2026-09-23 核对用户压缩包正文、当前本地安装正文与公开原文，设计树、前沿、逐轮重算、事实自查和确认后行动的机制一致。公开链接指向可变化的 main，分发基准是本包保留的文字快照，不声称已固定上游提交。

| 原机制 | 本版保留 | 适配企业诊断的修改与理由 |
|---|---|---|
| 设计树 | 决策依赖和未解节点 | 根是合格业务结果；另建 G→W 追溯，防止只问完登记的问题却漏目标 |
| 一轮问整个前沿 | 所有可问节点都保留 | 每轮按影响和用户负担呈现部分，其余留待后续；避免部门级问题一次倾倒 |
| 问题正文与选项之后给推荐 | 题头明确单选/多选，列齐答案后给推荐 | 按用户要求把题型写进标题；推荐引用已有选项并遵守题型，不在选项外另设答案；开放事实题不猜推荐，诊断假设保留证据边界 |
| 找事实是 Agent 工作 | 自查可访问材料 | 只在当前授权内查询；私有经历和有权决定由业务方补充 |
| 回答重塑树 | 修正依赖与判断 | 纠正后图文和确认也随受影响范围失效，独立分支继续 |
| 理解一致后行动 | 承重取舍由有权人确认 | 分析和草稿可以先交；定案、施工和外部动作分别按现有授权，避免把出草稿也变成审批 |

U 型思考负责推理与收敛，机制库负责候选路径，能力表负责实现分工，元认知负责校准；它们进入同一个诊断循环，不各自独立跑一遍问卷。
