# 路觅业务自动化顾问 v1.0.1

带着一个部门困扰进入，通过提问和分析，得到一份能看懂未来运行的业务流转图，以及可以交给实施方的项目启动说明文档。不要求你先懂技术。

本 Skill 从路觅 AI 自动化诊断 v3.0.1 独立命名而来，沿用已修正的提问协议与全部诊断能力；新名称、新调用标识和独立版本号用于与原 Skill 分开使用。

## 怎么开始

将整个 `lumiedu-automation-advisor` 文件夹交给支持 Skill 的工作环境，保留 `references/`、`assets/` 和许可文件。具体导入方式以所用产品当前支持为准；一个 ZIP 不代表所有 AI 产品都会自动加载完整文件。本包的 Codex 配置保留“明确调用”策略。

使用以下一句话，然后描述业务：

> 请使用 $lumiedu-automation-advisor，帮我诊断这个业务场景怎样在飞书上实现合适的自动化。我的问题是……；目前的限制是……。

若环境不支持 Skill 文件夹，但能读附件，可上传主文件及参考材料并请它按本包诊断；这是对话使用方式，不宣称与原生加载效果相同。只读了主文件时应说明是简化诊断。

## 你需要提供什么

真实目标、现行做法、已知限制，以及方便提供的一条脱敏正常或失败过程。说不清或不知道可以直接说；Agent 应先查已有材料，再问会改变方案的关键问题。不要上传密钥、无关员工/学员隐私或完整敏感数据库。

你已有明确范围、首期或决定时直接说，诊断会沿该边界补齐必要依赖。已有材料充分时可以直接要求产出草稿，不需要重新回答一套问卷。

每道选择题会在标题末尾明确写“（单选）”或“（多选）”，再列完整选项，最后给推荐及理由。推荐答案也在选项内，选项数量没有固定值或上下限。事实不清时可以直接说不知道，不需要认同 Agent 的推测。

## 应该拿到什么

1. **可打开的业务流转图**：看清从哪里开始、人和系统分别做什么、结果到哪里、失败怎么接手。
2. **项目启动说明文档**：问题与证据、突破口、适配理由、逐项方案、飞书承载、施工顺序和验收办法。

证据不足时交条件版，清楚说明“查到什么就走哪条路”，并给有限取证任务。只给 Mermaid 文字说明还没完成可见图文件，不能算完全交付。

## 如何判断有用

你应能据此说明：为什么选择这条路；自己今后在哪里操作；什么算做成；失败找谁；实施方第一项能做什么。增加表格、提醒或机器人数量不是效果。

本包不自动连接公司系统、发送消息或部署，也不附带企业权限。完成诊断后，按具体对象和动作交给获准的实施能力。无需 Python 或其他必装依赖即可执行诊断；图文件由宿主能力生成。

v1.0.1 是重构后的可试用版本。结构检查和模拟测试只能证明被检验的内容；跨部门真人使用完成率、实际落地与长期效果仍需真实试用。你可在任何阶段要求“交当前版本”“只看本期范围”或“从工作底稿继续”。
