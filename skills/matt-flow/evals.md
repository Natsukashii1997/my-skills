**盲测做法**：
- **E 组**：新开一个 agent，只给它去掉 evals.md、CHANGELOG.md 的 skill 副本，以及「请求」「给的材料」，让它写出这一轮会做什么、回什么（含要调用的技能、要读的文件、要跑的命令）。
- **T 组**：另开一个 agent，只给它一份可用技能清单（名字 + description，含 matt-flow 和容易撞车的技能）和请求，不说要用哪个，让它说会调用哪个技能。
- 两组都由出题以外的 agent 按「判定标准」打分。
