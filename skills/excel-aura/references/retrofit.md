# 美化已有表

已有表和新建表最大的不同：表里已经有别人的数据、公式、合并、隐藏列和一层旧样式，别的子表可能还引用着这一页。所以原则是**只加样式、不动结构；先洗旧样式再上新的；写之前给人看，写完核对**。

下面的流程以飞书为例；本地 xlsx 走同一套流程，命令见下一节。

## 本地 xlsx 的命令

```bash
cp 原表.xlsx 原表-备份.xlsx                                          # 1. 备份；原表全程不动
python3 $A/aura.py audit 原表.xlsx                                     # 2. 审原表，列出要洗的旧样式
# 3–4. 读懂结构，写 layout.json（gutter: false，reset 盖住整片用过的区域）
python3 $A/aura.py preview layout.json --cells 原表.xlsx --png preview.png   # 5. 预览 + 风险检查
python3 $A/aura.py xlsx layout.json 原表.xlsx 美化后.xlsx               # 7. 写到新文件
python3 $A/aura.py audit 美化后.xlsx --before 原表.xlsx                 # 8. 核对值、公式和残留
```

- 合并、隐藏行列、行高列宽都从 xlsx 里读，不用 `--info`，也不用自己转 cells.json。多页的表：`preview` 默认读 layout 里那一页同名的页，`audit` 用 `--sheet 页名`。
- `aura.py xlsx` 一次写完，不分片；layout 里写了 `unmerge` 会先取消合并，不用单独跑命令。
- 写到新文件不碰原表，可以先写出来，连同预览一起给用户看；**替换原表要等用户确认**。
- 写进输出目录的每个文件都算交付物，自检试写的也一样：回复里说「斜体全洗掉了」，`audit` 就得看不到斜体，包括隐藏格子。

## 流程

**1. 只读回读，备份。** 用项目规定的 lark-cli profile 和身份：

```bash
lark-cli sheets +sheet-info --url <表> --sheet-id <页> \
  --include merges,row_heights,col_widths,hidden_rows,hidden_cols,frozen > info.json
lark-cli sheets +cells-get --url <表> --sheet-id <页> --range A1:Z200 \
  --include value,formula,style --output-path ./cells.json
```

`cells.json`、`info.json` 原样备份到项目规定的证据目录，回滚时照它恢复。`+cells-get` 的结果要看 `has_more`，行列号按 `row_indices` / `col_indices` 取，不要按数组下标自己数。

**2. 先审一遍原表**：`aura.py audit cells.json --info info.json`。它会列出斜体、残留底色、字号层级、纯黑字、合并超宽、列宽过宽或会截断等问题，就是这次要解决的清单。

**3. 读懂结构**，在纸面上标出来再写 layout：
- **区块**：靠底色、合并、空行把表切成块，每块按 [table-types.md](table-types.md) 认表型。
- **共用列**：同一列在不同块里是什么意思，列宽取各块所需的最大值。
- **人填的和算出来的**：看 `formula` 字段，区分手填的价格、假设和公式结果。同一列里手填和公式混着的，记下来写进预览说明。
- **没表头的列**：多半是辅助计算，用 `muted`，并提醒用户补表头。
- **隐藏的行列**：不给它们设尺寸，设了就会显示出来。类型要写，就写在区块的 `columns` 里。隐藏格子里的旧样式也要洗，见第 4 步。
- **原表颜色的含义**：例如按活动分组上色、红字表示底价。把含义映射到套组色上，不要直接丢掉。

**4. 写 layout.json**，已有表固定加这几项：

```json
{"gutter": false,
 "reset": "A1:U47",
 "unmerge": ["A1:U1", "A2:H2"],
 "merges": ["A2:J2"]}
```

- `gutter: false`：不插页边距行列。插行插列会改动公式里的引用，别的子表、别人的公式也可能指着这里。
- `reset`：盖住整片用过的区域（含空格子和合并带），先洗成白底、常规字、无边框，再盖新样式；数字格式不动。
- `reset` 可以写一个范围，也可以写一组：`"reset": ["A1:B21", "D1:AA21"]`。
- **隐藏行列里的旧样式也要洗**。`reset` 和区块可以直接跨过隐藏列：它们只改样式、不设列宽，隐藏列不会因此显示出来，值也不动。隐藏格子看不见，所以靠检查兜底：隐藏格子里的斜体、删除线没被盖到时，`preview` 会报风险；盖到了，`preview` 会提示一行「隐藏格子 … 的样式也会改」，把这件事写进给用户的说明（例如「隐藏的 C 列也洗了旧斜体，值没动，仍然隐藏」）。
  - 例外：隐藏列的颜色看得出有业务含义（例如按状态上色），先问用户要不要保留。要保留，就把 `reset` 写成一组范围绕开它，区块范围也不跨过它，并在说明里写明「隐藏列 C 的旧样式按你的要求保留」。
  - 合并不要跨过有内容的隐藏列：合并会吞掉隐藏格子的内容（`preview` 会查）。

  旧样式（斜体、删除线、加粗、边框）必须清掉，底线 6 不能降级。删除线在预览里看不出，验收看 `audit`：它报看得见的斜体、删除线、只在空格子里的底色，也报隐藏格子里的斜体、删除线。真清不掉才停下来问用户。
- `unmerge`：要换范围的旧合并。`+styles-put` 不能取消合并，`aura.py feishu` 会把取消合并的命令打印出来，要先跑。
- 合并范围按表格实际宽度重新定：分区带不超过最右一列有内容的列，块标题盖住整块。

**5. 预览**：

```bash
python3 $A/aura.py preview layout.json --cells cells.json --info info.json --png preview.png
```

预览是「原表样式逐项叠上新样式」，和飞书写进去的效果一致，所以没被区块盖到的旧样式也会照实显示。页首列出写入前检查发现的风险：隐藏列被设宽、新旧合并重叠、合并会吞掉内容、没写 reset、隐藏格子里的旧样式没被盖到、A 列有内容却开着 gutter。有风险就先改 layout，直到显示「没发现风险」。

**6. 给用户看**：预览图，加一段说明（套组和色数、各列类型、行高列宽、合并和冻结的改动、数字显示变了哪些、发现但不改的数据问题）。等确认。

**7. 写入**：先跑 `+cells-unmerge`，再按顺序跑 `styles-NN.json`。写完一份回读一次，遇到限频或报错，按回读结果续跑，不要从头重放合并。重刷样式时加 `--skip-merges`。

**8. 核对**：重新回读 `cells-after.json`，然后：

```bash
python3 $A/aura.py audit cells-after.json --info info-after.json --before cells.json
```

本地表：`aura.py audit 美化后.xlsx --before 原表.xlsx`。

「值和公式与原表一致」必须出现；「问题」应当清零，剩下的要能说出理由。最后在浏览器里截一张整页图给用户验收。

## 验收清单（审查别人美化的表也用这份）

- [ ] 值和公式一个没变（`audit --before`）。
- [ ] 没有斜体、删除线（隐藏格子也算），没有只出现在空格子里的底色，没有旧边框。
- [ ] 只有一个深色；彩色底只在表头、输入、计算、合计这几处。
- [ ] 同一种底色在全页只代表一种意思。
- [ ] 合并带和表格一样宽，块标题盖住整块。
- [ ] 列宽贴合内容，没有被截断的，也没有空出一大截的。
- [ ] 间隔行、表头、正文的行高都设了，不是自动。
- [ ] 隐藏的行列还是隐藏的。
- [ ] 有浅色细边框，或者有不画边框的理由（看板）。
- [ ] 斑马纹只用在超过 10 行的块上。
- [ ] 数字显示和原表一致；有改动的已经跟用户说过。

## 坑

- **样式是逐项叠加的**：`+styles-put` 只改写到的字段。原表的斜体、底色、边框，新样式没写到就会留着，空格子里的也一样。所以要 `reset`。
- **合并不能重复做**：已经合并的区域再合并会报重叠；要换范围，先 `+cells-unmerge`。合并前确认除左上角以外的格子都是空的（`preview` 会查）。
- **隐藏列设宽会被显示出来**。
- **隐藏格子里的旧样式最容易漏**：预览不显示隐藏列，肉眼验收看不到。靠 `preview` 的风险检查和 `audit` 的隐藏格子检查兜底（见第 4 步）。
- **导入会放大尺寸**：不要导出 xlsx 改完再导入飞书，行高列宽会放大约 1.25–1.35 倍。
- **lark-cli 的 `@文件`** 只认当前目录下的相对路径。
- **一次最多 100 项操作**：合并、样式、行高列宽都算；脚本按 70 项分片，连续相同的行高列宽会并成一项。
- **原表的数字显示**：回读的 `value` 常是按原格式排好的字符串（如 `9,500`）。新格式会按数字重新显示，百分比的小数位、单价的取整方式可能变，要在说明里写清。
