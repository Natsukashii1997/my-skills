# 配色细则

## 来源

| 来源 | 内容 |
|---|---|
| 参考表（飞书「10月目标测算」） | 藏青 `#1F3864` 标题带、`#BDD7EE` 表头、`#D9E2F3` 浅蓝细边框、黄底 `#FFF2CC` 输入 / 绿底 `#E2F0D9` 计算。提成 3 条色阶：参考藏青、参考奶油、参考嫩绿 |
| 小红书·校园美学配色（笔格PPT） | 9 条：古籍苔绿、藏青校服、旧书纸棕、橘子汽水、泳池水青、紫藤花廊、晴空球场、礼堂幕红、樱粉步道。饱和度偏高 |
| 小红书·盐系生活美学色盘（笔格PPT） | 10 条：橄榄卡其、雾蓝灰紫、烟粉豆沙、青灰冷调、燕麦奶咖、杏桃暖橘、抹茶雾绿、灰紫鸢尾、姜黄暖棕、奶雾蓝灰。低饱和，最适合表格 |

每条都是 5 级色阶，L1 最浅、L5 最深。色值按原图像素取得，误差在 ±2 以内。

## 每个色系派生出的角色色

由 `aura.py` 计算，不手写：

| 角色 | 取法 | 用在 |
|---|---|---|
| band 深色带 | L5；配白字对比度不足 4.8 时，保持色相把明度往下压 | 标题、分区标题、重点值（白字） |
| soft 表头底 | L2 | 表头、分组表头上层 |
| chip 标记底 | L1 与 L2 各半 | 分类标记、多行表头下层；鲜艳色系的输入格、计算格 |
| tint 浅底 | L1 | 合计行 |
| zebra 斑马纹 | L1 掺 35% 白 | 隔行底色 |
| line 边框 | L2 掺 45% 白 | 全部细边框（S01 算出来正好接近参考表的 `#D9E2F3`） |
| ink 文字色 | 依次试 L4、L5，不够就压深 L5，直到在 L2 上对比度 ≥ 5 | 浅底上的文字 |

盐系的 L5 多是中间调，直接配白字只有 3.6–4.8 的对比度，看不清。所以 band 和 ink 一律走计算。

## 套组为什么这样排

排序原则：
1. **① 结构色**：压得住标题带，经计算加深后仍干净的色系。
2. **② 和 ① 冷暖相对**：互补或对比，让「输入 / 第二类」一眼分开。例如藏青配奶油、青灰配姜黄、灰紫配姜黄、水青配橘子。
3. **③ 过渡**：绿、灰、蓝灰这类中性色系，把 ①② 连起来。
4. **④⑤ 补位**：L2 明度和前面接近，饱和度不高于 ①，大多取烟粉豆沙、燕麦奶咖这类低饱和色。
5. **鲜艳色系不放 ①**：橘子、晴空、樱粉、紫藤只放在第 2 位以后，并且只用浅色级。

这样排保证任意前 N 个都协调：只用 ①② 时是一冷一暖，加 ③ 后多一个中性过渡，再加 ④⑤ 也不会跳色。

## 每套怎么用

- **S01 藏青账簿**：参考表同源。经营测算、预算、目标拆解首选，输入黄底、计算绿底的语义和参考表一致。
- **S02 雾蓝奶咖**：没有明显倾向时的默认选择，冷暖平衡，长时间看不累。
- **S03 苔绿书卷**：①② 是同类暖色，整体温润。适合学习、培训、阅读计划。
- **S04 青灰冷调**：冷静理性，② 姜黄只做点缀。适合数据和运营指标。
- **S05 豆沙暖调**：暖粉为主、青灰作衬。适合人和服务相关的表。
- **S06 鸢尾灰紫**：紫黄对比，安静里有个性。适合内容、品牌、创意排期。
- **S07 橄榄工装**：大地色。适合物料、库存、采购这类务实台账。
- **S08 水青汽水**：唯一偏活泼的套组。只在活动、营销、社群类表格用，② 橘子已自动降成浅档。
- **S09 红墙书院**：深红标题带庄重正式。适合年度总结、表彰、正式汇报；日常表不用。
- **S10 晴空紫藤**：蓝色明快。适合产品和项目管理。

## 状态色（全套共用）

| tone | 底 | 字 | 含义 |
|---|---|---|---|
| good | 抹茶 L1 | 抹茶深字 | 完成 / 达标 / 正向 |
| warn | 姜黄 L1 | 姜黄深字 | 进行中 / 待确认 / 提醒 |
| bad | 礼堂 L1 | 礼堂 L4 | 风险 / 未达标 / 负向 |
| info | 奶雾蓝灰 L1 | 蓝灰深字 | 计划中 / 说明 |
| neutral | `#F2F3F5` | `#646A73` | 暂停 / 无效 / 不适用 |

状态色不随套组变化，看惯一套，换表也认得出。
