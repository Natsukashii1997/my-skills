# 配色细则

## 来源

| 来源 | 内容 |

| 参考表（飞书「10月目标测算」） | 藏青 `#1F3864` 标题带、`#BDD7EE` 表头、`#D9E2F3` 浅蓝细边框、黄底 `#FFF2CC` 输入 / 绿底 `#E2F0D9` 计算。提成 3 条色阶：参考藏青、参考奶油、参考嫩绿 |

| 小红书·盐系生活美学色盘（笔格PPT） | 10 条：橄榄卡其、雾蓝灰紫、烟粉豆沙、青灰冷调、燕麦奶咖、杏桃暖橘、抹茶雾绿、灰紫鸢尾、姜黄暖棕、奶雾蓝灰。低饱和，最适合表格 |

每条都是 5 级色阶，L1 最浅、L5 最深。色值按原图像素取得，误差在 ±2 以内。

## 每个色系派生出的角色色

由 `aura.py` 计算，不手写：

| 角色 | 取法 | 用在 |
|---|---|---|
| band 深色带 | L5；配白字对比度不足 4.8 时，保持色相把明度往下压 | 标题、分区标题、重点值（白字） |
| soft 表头底 | L2 | 表头、分组表头上层 |
| chip 标记底 | L1 与 L2 各半 | 分类标记、多行表头下层；鲜艳色系的输入格、计算格 |
| tint 浅底 | L1 | 合计行 |
| zebra 斑马纹 | L1 掺 35% 白 | 隔行底色 |
| line 边框 | L2 掺 45% 白 | 全部细边框（S01 算出来正好接近参考表的 `#D9E2F3`） |
| ink 文字色 | 依次试 L4、L5，不够就压深 L5，直到在 L2 上对比度 ≥ 5 | 浅底上的文字 |

盐系的 L5 多是中间调，直接配白字只有 3.6–4.8 的对比度，看不清。所以 band 和 ink 一律走计算。

## 套组为什么这样排

第一版按「每套 5 个不同色系」来排，在表里一铺就像彩虹：S02 曾经同时出现 202° 蓝、35° 奶咖、100° 绿、0° 粉、268° 紫，常浩看了觉得「杂、有点对撞」。现在的规则：

1. **① 主色**：压得住标题带，经计算加深后仍然干净。
2. **② 辅色**：和 ① 冷暖相对，例如藏青配奶油、青灰配姜黄、灰紫配姜黄、水青配橘子、豆沙配青灰。
3. **③ 中性色**：青灰、燕麦、橄榄、雾蓝灰紫这类饱和度不超过 0.25 的色系，或 ① 的同家族浅色。
4. **④ 取 ① 的邻近色，⑤ 取 ② 的邻近色**：色相相差 30° 以内。
5. **鲜艳色系不放 ①**：橘子、晴空、杏桃只放在第 2 位以后，并且大块填充会自动降一档浅色。樱粉、紫藤和其他色系一搭就跳，不进任何套组，色阶留着备查。

## 状态色（全套共用）

| tone | 样式 | 含义 |
|---|---|---|
| good | 抹茶深字，无底 | 完成 / 达标 / 正向 |
| warn | 姜黄深字，无底 | 进行中 / 待确认 / 提醒 |
| info | 蓝灰深字，无底 | 计划中 / 说明 |
| neutral | 灰字 `#646A73`，无底 | 暂停 / 无效 / 不适用 |
| bad | 幕红字 + 浅红底 | 风险 / 未达标 / 负向（唯一带底，需要一眼看到） |

状态色不随套组变化：看惯一套，换表也认得出。只用文字色是为了不让状态列变成一列彩块。
