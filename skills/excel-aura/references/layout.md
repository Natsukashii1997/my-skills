# 版式细则与 layout.json 写法

## 默认值背后的道理

默认值来自参考表「10月目标测算」，知道为什么，才知道什么时候能调：

- **留白**：左边空一列、顶上空一行，表格不贴边；并排区块之间隔一列，像排版里的栏间距；区块上下隔一行。已有表不插行列，留白靠列宽和间隔行做。
- **层次**：三层底色分级——深色带（标题、分区）、浅色表头、白底正文。正文里再按含义上浅色：输入、计算、状态。
- **呼吸感**：正文行高 34–37px，比默认的 20 多 px 高出一截，这是看着不挤的最主要原因。行数很多时，扫读效率比呼吸感重要，就压到 28–30。
- **边框**：用带主色调的极浅细线，不用灰黑线。四周都画，但几乎感觉不到，只起对齐作用。

## 列类型（columns 里的 type）

| type | 对齐 | 宽度（px，最小–最大） | 数字格式 | 例子 |
|---|---|---|---|---|
| index | 居中 | 48–64 | | 序号 |
| code | 居中 | 80–140 | | 编号、单号 |
| date | 居中 | 100–120 | | 日期（写文本） |
| tag | 居中 | 80–110 | | 状态 |
| category | 居中 | 88–140 | | 业务线、类型 |
| name | 左 | 96–180 | | 姓名、项目名 |
| label | 左 | 140–300 | | 指标名 |
| text | 左，自动换行 | 120–320 | | 描述、备注 |
| longtext | 左，自动换行 | 240–360 | | 大段说明 |
| amount | 右 | 104–160 | `#,##0` | 金额（无符号） |
| money | 右 | 110–160 | `¥#,##0` | 金额 |
| number | 右 | 80–130 | `#,##0` | 数量 |
| decimal | 右 | 88–130 | `#,##0.00` | 小数 |
| percent | 右 | 80–110 | `0.0%` | 比率 |
| kpi | 居中 | 110–180 | | 单个指标值 |

列宽的定法：
- 默认写 `"max": "这一列大多数格子的长度"`，不写最长的那一两格，个别长格换行（见 table-types.md「所有表型通用」）；数字列照旧取最长的一条。按「中文每字 15px、其他 8px、加 28px」估算，再卡在该类型的上下限之间。
- 写了 `"width": 像素` 就直接用。只在有具体理由时直写，例如要和另一张表对齐、要给手填留空间；demo 为了展示固定版面才都写了 width。
- 都没写就用该类型的下限。
- 有特殊格式时写 `"fmt"`，要改对齐时写 `"align"`，都能覆盖默认值。

## layout.json

```json
{
  "font": "Arial",
  "suite": "S02",          // 默认套组，单页可覆盖
  "colors": 3,             // 用几色（1–5），单页可覆盖
  "sheets": [{
    "name": "明细",         // 真实子表名
    "gutter": true,        // 默认 true：A 列 20px 页边距 + 第 1 行 12px 顶边距；已有表写 false
    "reset": "A1:U47",     // 已有表：先把这片区域洗成白底常规字、无边框，再上新样式（数字格式不动）
    "unmerge": ["A1:U1"],  // 已有表：要换范围的旧合并；aura.py feishu 会打印取消合并的命令
    "density": "normal",   // compact / normal / airy：正文行高 28 / 34 / 38，表头、合计跟着变
    "rows": {"body": 32},  // 逐项覆盖行高默认值（top title subtitle gap section header body compact total note）
    "fonts": {"title": 18},// 逐项覆盖字号默认值（title section header body note）
    "gap_rows": [4],       // 12px 间隔行
    "gap_cols": ["K"],     // 24px 间隔列
    "columns": {"B": {"type": "index"}, "C": {"type": "name", "max": "最长的项目名称"}, "D": {"type": "money"}},
    "title": {"range": "B2:J2", "subtitle": "B3:J3", "align": "center"},
    "blocks": [{
      "hue": 1,                        // 这个区块的表头用第几色；正文边框始终用 ①
      "section": "B5:J5",              // 分区标题（① 深色带，白字），可省
      "header": "B6:J6",               // 表头；两行表头写 "B6:J7"
      "header_groups": [{"range": "D6:E7", "hue": 2}],   // 分组表头着色，依次取 ②③④⑤
      "body": "B8:J30",
      "total": "B31:J31",              // 合计行，可省
      "zebra": true,                   // 默认：正文超过 10 行才加斑马纹
      "compact": false,                // true 时这块正文用紧凑行高（normal 档 30）
      "columns": {}                    // 这个区块单独的列类型（覆盖页面级）
    }],
    "merges": ["B6:B7"],               // 额外合并（多行表头的竖向合并等）
    "roles": [{"range": "M7", "role": "input"}],
    "tags": [{"range": "G8", "tone": "good"}],
    "paint": [{"range": "L24", "bg": "#C7DDE6", "color": "#48596A", "bold": true, "fmt": "0.0%", "align": "center"}],
    "notes": ["B32:J32"],
    "freeze": {"rows": 7, "cols": 0},
    "row_sizes": {"9": 48}             // 个别行手动行高（如长文本行），优先于自动行高
  }]
}
```

**roles**
- `input`：输入或假设，用 ② 的浅底加粗。只标需要人调整、会带动计算的假设格；明细里逐行录入的数据不算 input，保持白底。
- `calc`：公式结果，用 ③ 的浅底。
- `key`：单个重点值，用 ① 的深色带配白字。
- `target`：目标值，用风险红字。
- `muted`：次要信息，灰字。例如没有表头的辅助计算列。
- `hue1` 到 `hue5`：用第 N 色的标记底标出一小块，例如交叉表的行头列、方案对比里推荐的那一列。**不要拿来给正文逐行按类别铺色**，那样整列会变成彩虹。

色数不够时自动退回：只有 1 色时，`input` 用 ① 的浅底，`calc` 用 ① 的斑马纹底。

**tags**
- 只给状态列用：`good`、`warn`、`bad`、`info`、`neutral`。只上文字色，`bad` 另加浅红底。

**paint**
- 逃生口，只在色卡展示这类特殊需求时用。正常表格不应该用到。

## 各表型怎么写

见 [table-types.md](table-types.md)：明细台账、汇总统计、测算模型、档位价目、交叉表、排期、看板、方案对比、录入模板、长文本表，每种都有写法片段。美化已有表的固定写法见 [retrofit.md](retrofit.md)。

同一份文件里有多张子表时：用同一套组、同一色数；子表标签色可以用 ① 的深色带。

## 写入前检查（preview 会报）

- 隐藏列出现在页级 `columns` 里（设了宽就会显示出来）。
- 新合并和表里已有的合并重叠，而旧的没写进 `unmerge`；或者合并完全相同（重刷要加 `--skip-merges`）。
- `unmerge` 里写了表里并没有的合并。
- 合并会吞掉非左上角格子的内容。
- A 列有内容却开着 `gutter`。
- 已有表（回读里带样式）却没写 `reset`。

## 本地 xlsx 的尺寸换算

`aura.py xlsx` 把像素换成 Excel 单位：行高 px × 0.75 得磅，列宽 px ÷ 7 得字符宽。这是近似值，Excel、WPS、Numbers、LibreOffice 的中文字体回退和字符宽度各不相同，打开后要检查有没有 `####`、被截断的文字和换行异常，按实际显示微调 `width`。
