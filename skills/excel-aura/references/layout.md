# 版式细则与 layout.json 写法

## 版式从参考表学到的

- **留白**
  - 左边留一列 20–24px 宽的空列，表格不贴边。
  - 第 1 行留 12px 作顶边距。
  - 并排区块之间隔一列 24–40px，像排版里的栏间距。
  - 区块上下之间隔一行 12px。
- **层次**：用三层底色分级——深色带（标题、分区）、浅色表头、白底正文。正文里再按含义上浅色：输入、计算、分类、状态。
- **呼吸感**：正文行高给到 34–37px，比默认的 20 多 px 高出一截。这是看着不挤的最主要原因。
- **边框**：用带主色调的极浅细线，不用灰黑线。四周都画，但几乎感觉不到，只起对齐作用。

## 列类型（columns 里的 type）

| type | 对齐 | 宽度（px，最小–最大） | 数字格式 | 例子 |
|---|---|---|---|---|
| index | 居中 | 48–64 | | 序号 |
| code | 居中 | 80–140 | | 编号、单号 |
| date | 居中 | 100–120 | | 日期（写文本） |
| tag | 居中 | 80–110 | | 状态 |
| category | 居中 | 88–140 | | 业务线、类型 |
| name | 左 | 96–180 | | 姓名、项目名 |
| label | 左 | 140–300 | | 指标名 |
| text | 左，自动换行 | 120–320 | | 描述、备注 |
| longtext | 左，自动换行 | 240–360 | | 大段说明 |
| amount | 右 | 104–160 | `#,##0` | 金额（无符号） |
| money | 右 | 110–160 | `¥#,##0` | 金额 |
| number | 右 | 80–130 | `#,##0` | 数量 |
| decimal | 右 | 88–130 | `#,##0.00` | 小数 |
| percent | 右 | 80–110 | `0.0%` | 比率 |
| kpi | 居中 | 110–180 | | 单个指标值 |

列宽的定法：
- 写了 `"width": 像素` 就直接用。
- 写了 `"max": "这一列最长的内容"`，就按「中文每字 15px、其他 8px、加 28px」估算，再卡在该类型的上下限之间。
- 都没写就用该类型的下限。
- 有特殊格式时写 `"fmt"`，要改对齐时写 `"align"`，都能覆盖默认值。

## layout.json

```json
{
  "font": "Arial",
  "suite": "S02",          // 默认套组，单页可覆盖
  "colors": 3,             // 用几色（1–5），单页可覆盖
  "sheets": [{
    "name": "明细",         // 真实子表名
    "gutter": true,        // 默认 true：A 列 20px 页边距 + 第 1 行 12px 顶边距
    "gap_rows": [4],       // 12px 间隔行
    "gap_cols": ["K"],     // 24px 间隔列
    "columns": {"B": {"type": "index"}, "C": {"type": "name", "max": "最长的项目名称"}, "D": {"type": "money"}},
    "title": {"range": "B2:J2", "subtitle": "B3:J3", "align": "center"},
    "blocks": [{
      "hue": 1,                        // 这个区块的表头用第几色；正文边框始终用 ①
      "section": "B5:J5",              // 分区标题（① 深色带，白字），可省
      "header": "B6:J6",               // 表头；两行表头写 "B6:J7"
      "header_groups": [{"range": "D6:E7", "hue": 2}],   // 分组表头着色，依次取 ②③④⑤
      "body": "B8:J30",
      "total": "B31:J31",              // 合计行，可省
      "zebra": true,                   // 默认：正文超过 10 行才加斑马纹
      "compact": false,                // true 时正文行高 30
      "columns": {}                    // 这个区块单独的列类型（覆盖页面级）
    }],
    "merges": ["B6:B7"],               // 额外合并（多行表头的竖向合并等）
    "roles": [{"range": "M7", "role": "input"}],
    "tags": [{"range": "G8", "tone": "good"}],
    "paint": [{"range": "L24", "bg": "#C7DDE6", "color": "#48596A", "bold": true, "fmt": "0.0%", "align": "center"}],
    "notes": ["B32:J32"],
    "freeze": {"rows": 7, "cols": 0},
    "row_sizes": {"9": 48}             // 个别行手动行高（如长文本行）
  }]
}
```

**roles**
- `input`：输入或假设，用 ② 的浅底加粗。
- `calc`：公式结果，用 ③ 的浅底。
- `key`：单个重点值，用 ① 的深色带配白字。
- `target`：目标值，用风险红字。
- `muted`：次要信息，灰字。
- `hue2` 到 `hue5`：用第 N 色的标记底标出一小块，例如并排区块里的某一格。**不要拿来给正文逐行按类别铺色**，那样整列会变成彩虹。

色数不够时自动退回：只有 1 色时，`input` 用 ① 的浅底，`calc` 用 ① 的斑马纹底。

**tags**
- 只给状态列用：`good`、`warn`、`bad`、`info`、`neutral`。只上文字色，`bad` 另加浅红底。

**paint**
- 逃生口，只在色卡展示这类特殊需求时用。正常表格不应该用到。

## 版式套路

- **明细清单**：标题加副标题，然后 section（可省）、表头、正文、合计、注释。冻结到表头行。
- **测算表**（参考表这类）：几个「指标 | 数值」小区块并排，中间用 gap 列隔开。输入格标 input，公式格标 calc，最终结果标 key。
- **分组汇总**：两行表头，上层按组合并并着 ②③④⑤，下层是字段名，颜色比上层浅一档。
- **多张子表的同一份文件**：同一套组、同一色数；子表标签色可以用 ① 的深色带。
