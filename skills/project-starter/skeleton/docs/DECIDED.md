# 已定内容登记表

用户选定、定稿或验收一个界面、交互、文案、数据格式的当轮，由做这一轮的 agent 在下面加一行，并在当轮交接里写明「已登记 DECIDED.md」。以后判断「这处算不算已定」先查这里，要改登记过的内容先单独问用户；网页界面登记时同时拍基线截图（`node scripts/ui-baseline.mjs shoot`），之后的基线对比就以这里登记的截图为准。

- 一行一项，只增不删。用户同意改掉某项后，新加一行，旧行的备注写「已被 <日期> 那行取代」。
- 提交号写定下来时的那个提交；没有界面的写「无截图」；在哪定的写得能查到（会话日期、PR 或 issue 编号）。
- 没登记不等于没定：对话、PR、issue 里用户明确说过「就这个」「定了」的，照样算已定，发现了就补登记。

| 日期 | 定了什么（页面或功能） | 提交号 | 基线截图 | 在哪定的 | 备注 |
|---|---|---|---|---|---|

还没有登记，第一行照这个格式：

```markdown
| 2026-11-18 | 首页布局：顶部导航 + 四块卡片（最近动态、待办、统计、快捷入口） | `abc1234` | `docs/design/baseline/home-1280.png`、`home-1440.png` | 2026-11-18 会话，PR #12 | 无 |
```
