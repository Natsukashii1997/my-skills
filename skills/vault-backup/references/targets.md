# 备份存哪、密码怎么保管（要用户定）

本 skill 默认什么位置都不选，配置模板里三种都是注释状态。下面的对比讲给用户听，由他决定。

## 建议的组合

**至少一个本地 + 一个异地**：本地的恢复快、不花流量；异地的保证电脑和外置盘一起没了也还在。两个位置用同一个密码，脚本会依次备份到每一个。

推荐顺序（在不新增付费的前提下）：

1. 有外置盘：**外置盘 + iCloud**（iCloud 空间不够再考虑 B2）。
2. 没有外置盘：**iCloud** 先用起来，再考虑买盘或开 B2。
3. 已经在付 iCloud+，空间充足：iCloud 是最省事的异地位置。

## 三种位置对比

| | 外置盘 | iCloud 云盘目录 | S3 / B2 兼容云存储 |
|---|---|---|---|
| 配置写法 | `target = 外置盘 \| /Volumes/盘名/vault-backup` | `target = iCloud \| ~/Library/Mobile Documents/com~apple~CloudDocs/vault-backup` | `target = B2 \| s3:https://s3.<区域>.backblazeb2.com/<桶名>/vault-backup` |
| 算不算异地 | ✗ 一般和电脑放一起 | ✓ | ✓ |
| 费用 | 已有盘就免费 | 免费 5 GB，常被照片占满；不够要 iCloud+（已有订阅就不算新增） | B2 前 10 GB 免费，之后约 6 美元 / TB / 月（3 GB 约每月几分钱）；Cloudflare R2 也有 10 GB 免费额度 |
| 速度 | 最快 | 先写本地再后台上传 | 看网速 |
| 要额外做的 | 插着盘才能备份；建议格式化成 APFS | 关掉该文件夹的「优化 Mac 储存空间」（见下） | 注册账号、建桶、建只能访问这个桶的密钥，存进钥匙串 |
| 主要风险 | 和电脑一起丢、一起坏 | 「备份完成」不等于「已上传完」；和 Apple ID 绑定 | 账号或密钥丢失；需要信用卡 |

### iCloud 要注意的三件事

1. **上传有延迟**：脚本写完就算成功，但 iCloud 可能还在后台上传。第一次备份后，在访达里打开 iCloud 云盘 → `vault-backup`，等云朵图标消失才算异地副本真的有了。
2. **别让 Mac 把备份文件「移到云端」**：系统设置 → Apple ID → iCloud → iCloud 云盘 → 关闭「优化 Mac 储存空间」；或在访达里右键 `vault-backup` 文件夹 → 「保留下载」。否则检查和演练时要现下载，慢且可能失败。
3. **备份库里的文件不要手动动**：不要在访达里删、移、重命名里面的东西。

### 顺便确认一件事

如果「系统设置 → iCloud → iCloud 云盘 → 桌面与文稿文件夹」是开着的，知识库（在「文稿」里）其实已经在 iCloud 上了。但这是**同步**不是备份：误删、改坏会同步过去。本 skill 的加密备份照样需要。

### 用 S3 / B2 时

- 在服务商后台建一个私有桶，再建一个**只允许访问这个桶**的应用密钥。
- 密钥存进钥匙串（用户自己在终端输入）：
  ```bash
  security add-generic-password -s vault-backup -a s3-access-key-id -w
  security add-generic-password -s vault-backup -a s3-secret-access-key -w
  ```
- 这两项丢了可以在服务商后台重新生成，不影响备份内容；**备份密码丢了才是真丢**。

## 密码怎么保管（最重要）

restic 的备份密码是唯一的钥匙。**忘了密码，备份就永远打不开，restic 和任何人都没有找回办法。**

钥匙串里那份只在这台 Mac 上（`security add-generic-password` 存的是本机登录钥匙串，不会同步到 iCloud 钥匙串）。电脑丢了，这份也没了。所以：

1. **再存一份在电脑以外**，二选一或都做：
   - 手机或另一台设备上的密码管理器（「密码」App、1Password 等）里建一条「知识库备份 restic 密码」。
   - 写在纸上，和护照、房产证这类东西放一起。
2. **用够长的密码**：4–6 个随机词或 20 位以上随机字符。可以用「密码」App 自动生成后复制。
3. **不要**：存在知识库里、发在聊天里、写在配置文件或备忘录里、和备份放在同一个地方。
4. 要不要告诉家人放在哪里，由用户自己决定。
5. 要换密码：`restic -r <位置> key add` 加新密码、确认能用后 `key remove` 旧的，每个位置各做一次。不常用，需要时再问。
