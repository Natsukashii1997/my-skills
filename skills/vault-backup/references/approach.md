# 方案取舍：为什么用 restic，备选是什么

## 先说结论

用 **restic**。它一次满足「异地、加密、留历史版本、包含未提交改动、增量、能校验能演练」这几条；恢复时只要 restic 本身和密码，不依赖本 skill。**age + git bundle** 作为备选：工具更简单，但只能备份已提交的 git 内容、每次都是全量，只适合临时应急拷一份。

## 从需求倒推：备份必须做到什么

这些是从「知识库是最核心资产、目前没有任何异地副本」推出来的硬要求，不是行业惯例：

| # | 要求 | 为什么必须 |
|---|---|---|
| 1 | **异地** | 电脑丢失、进水、被盗时，同一台电脑或同一个房间里的副本会一起没 |
| 2 | **加密** | 知识库里可能有公司和学生信息；存到云端后，云服务商或账号被盗都不能让人读到内容 |
| 3 | **留历史版本** | 误删、插件把笔记改坏、勒索软件加密文件，这些「坏」会被同步到所有副本。要能回到「坏之前」 |
| 4 | **包含未提交的改动和非 git 文件** | 知识库经常有没提交的改动，附件也可能没进 git |
| 5 | **增量** | 2.2 GB 每天全量上传云端不现实，只传变化的部分 |
| 6 | **能校验、能演练** | 没恢复过的备份不算备份 |
| 7 | **少维护、恢复不依赖本工具** | 用户不读代码；真出事时要能用公开工具在任何电脑上取回 |

## 两个方案对比

| 要求 | restic | age + git bundle |
|---|---|---|
| 1 异地 | ✓ 本地路径、iCloud 目录、S3/B2、SFTP 等都能直接当备份位置 | ✓ 生成的加密文件拷到哪都行 |
| 2 加密 | ✓ 默认加密（AES-256），没有不加密的选项 | ✓ age 用口令加密 |
| 3 历史版本 | ✓ 每次备份是一个版本，按规则保留（每天 / 每周 / 每月 / 每年） | △ git 历史在，但只有提交过的；文件要自己按日期命名、自己删旧的 |
| 4 未提交改动 | ✓ 直接备份文件本身，提不提交都一样 | ✗ bundle 只含提交过的内容。要覆盖就得每次自动提交，会改动用户的仓库 |
| 4 非 git 目录 | ✓ 任何目录 | ✗ 只能是 git 仓库；`.gitignore` 掉的文件也不在里面 |
| 5 增量 | ✓ 按内容切块去重，改一篇笔记只传几 KB | ✗ 每次是完整 bundle（约等于 .git 大小）。增量 bundle 要维护基准链，一断就恢复不了 |
| 6 校验 / 演练 | ✓ `restic check` 校验结构和数据；恢复时逐块核对哈希 | △ `git bundle verify` + 解密成功 = 完整；演练要自己写 |
| 7 恢复依赖 | restic 一个程序（macOS / Windows / Linux 都有）+ 密码 | age + git，都很常见 + 口令 |
| 安装 | `brew install restic`，一个程序 | `brew install age`；git 已有 |
| 缺点 | 备份库是一堆加密小文件，在访达里看不懂，要用 restic 取回；密码丢了谁都救不回 | 见上面 ✗ 和 △ |

结论：restic 满足全部 7 条；age + git bundle 在第 4、5 条上做不到，第 3、6 条要自己补。

## 还考虑过的

- **Time Machine**：苹果自带，免费，适合当「本地这一层」——建议用户也开上（要一块外置盘）。但它不在异地，备份盘一般和电脑放在一起；也不方便放到云端。它是补充，不能替代异地备份。
- **只用 iCloud / Obsidian Sync 同步**：同步不是备份。删掉或改坏会同步到所有设备；历史版本有限，也不受自己控制。
- **Kopia**：和 restic 同类（加密、去重、多种存储），带图形界面。能用，但 restic 更老牌、命令行更稳定、文档更多，所以选 restic。
- **Borg**：同类老牌工具，但不能直接存 S3 / iCloud，要有一台 SSH 服务器，对用户不合适。
- **Arq**：付费图形界面备份软件，好用，但要付费，且备份格式依赖它自己。

## 应急：没有 restic 时临时拷一份（age + git bundle）

只适合「今天就要有一份异地副本、来不及装 restic」。它**不含未提交改动**，所以先提交：

```bash
cd ~/Documents/"Obsidian Vault"
git add -A && git commit -m "应急备份前快照"      # 用户同意才做
git bundle create - --all | age -p -o ~/Desktop/vault-$(date +%F).bundle.age   # 按提示输入口令；不落未加密的中间文件
# 把 ~/Desktop/vault-日期.bundle.age 拷到 U 盘或网盘
```

恢复：

```bash
age -d -o vault.bundle vault-日期.bundle.age   # 输入口令
git clone vault.bundle "Obsidian Vault 恢复"
```

缺点见上表；restic 装好后以 restic 为准。
