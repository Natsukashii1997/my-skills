# ui-styles 修订记录（原 hairline-page）

版本号写在 SKILL.md frontmatter 的 `metadata.version`，和这里最上面一条一致。升版本的规则见仓库 `templates/CHANGELOG.md`：改措辞升修订号，加构件或规则升次版本，改令牌、文件格式这类会让旧页面不再符合的改动升主版本。改了某种风格的 `styles/<英文名>/reference.html` 的，在条目里写明换了哪些组件；加一种风格升次版本。改完重跑 [evals.md](evals.md)。
