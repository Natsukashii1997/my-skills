# ui-styles 修订记录（原 hairline-page）

版本号写在 SKILL.md frontmatter 的 `metadata.version`，和这里最上面一条一致。升版本的规则见仓库 `templates/CHANGELOG.md`：改措辞升修订号，加构件或规则升次版本，改令牌、文件格式这类会让旧页面不再符合的改动升主版本。改了某种风格的 `styles/<英文名>/reference.html` 的，在条目里写明换了哪些组件；加一种风格升次版本。改完重跑 [evals.md](evals.md)。

## 2.0.0 - 2026-11-15

荧光笔的薄荷主色整组调淡（#101）。常浩 11-15 给了一张截图，要用里面的浅薄荷替换薄荷，在对照页上选了「整组调淡」。本文件开头写明改令牌升主版本：照旧值做出来的薄荷页面不再符合，所以升到 2.0.0。

- 改动：薄荷四个令牌里改了三个，色相不变（169° 左右），只改深浅：`--hl` `#4FD1BA` → `#92DDCF`、`--hl-band` `#98E4D6` → `#B1E7DD`、`--hl-soft` `#D0F4ED` → `#D9F4EF`（就是截图里的颜色）；`--inv-hl` `#16695C` 不变。黄、天蓝、珊瑚、淡紫不变。
- 改动：`styles/marker/STYLE.md` 的薄荷令牌、主色表同步；薄荷的「要留意」加一句「五种里最淡」；对比度按实测改成：深墨字在 `--hl` 上 6.5–9.7:1、在 `--hl-band` 上 9.2–11.1:1，主色在白底上 1.6–2.3:1。
- 改动：`styles/marker/reference.html` 的薄荷令牌、主色切换按钮色点、主色表、「主色不当字色」反例说明里的对比度同步；组件没换。
- 改动：evals E6 判定标准里的薄荷四个值同步。
- 改动：补收尾条写法。本版第一轮盲测 E1 不过：细线页的收尾条把各段读者又对照了一遍，规则只禁了「收尾前再加一块对照」，没管收尾条本身。SKILL.md 共用底线第 2 条补「收尾条本身也不复述：只写读者接下来要做的一件事」并附反例；`styles/hairline/STYLE.md`「收尾」一行同步。
- 盲测：第 8 轮（只调薄荷）6 过 1 不过（E1 收尾条复述）；补规则后第 9 轮 7 条全过。记录见 evals.md「盲测记录」，产出在 `~/Library/Application Support/my-skills/evidence/2026-11-15-ui-styles-marker/mint/`。
