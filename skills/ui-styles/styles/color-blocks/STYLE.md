# 色块拼接（color-blocks）

一句话：像一张拼贴海报，每一节是一整块纯色，块与块直接相接、中间不画线；靠色块交替分节，靠粗圆黑体和黑白胶囊撑住层级。

参考页面：[reference.html](reference.html)（三步法样张，首页 + 内容页；截图是灰色占位）。CSS 规则以 `.st-35` 开头。动手前先通读它的 CSS 和 `TPL[35]` 模板，组件照着用，不要凭印象重写。

## 气质

- 明快、外向，像活动页或产品宣传页，不像文档。
- 分节不靠线和留白，靠换底色：读者往下滚，看到颜色变了就知道进了下一节。
- 色块全是浅而饱和的粉彩，只有海军蓝一块深色，用来压住开头和结尾。
- 字少而大：标题 Nunito 900，正文 16px，栏目标签是 12px 等宽大写小字。

## 适合 / 不适合

适合：
- 对外介绍一个项目、一套方法的落地页，节数 5–8 节。
- 活动、培训、分享会的说明页，需要一眼看出分了几块。
- 面向一线同事的「这一步做什么」讲解页，内容以短句、编号、公式为主。

不适合：
- 长文、规范、手册：段落一多，大面积彩色底会让人累。
- 数据密集的表格、看板：粉彩底上的细小数字不好读。
- 需要严肃、克制观感的汇报（给管理层的决策材料、财务数据）。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  /* 底色：拼贴外的页面底，也是两张拼贴之间 20px 的白缝 */
  --bg:#FFFFFF;
  /* 色块：每节一整块（注释里是参考页的原变量名） */
  --lime:#DDF27A;     /* --li */
  --lavender:#CFC2FF; /* --la */
  --cream:#FFF0C4;    /* --cr */
  --mint:#B4EAD0;     /* --mi */
  --pink:#FFC7E3;     /* --pk */
  --coral:#FF8B66;    /* --co */
  --sky:#BFE2FF;      /* --sk */
  --navy:#1C2552;     /* --nv，唯一的深色块 */
  /* 表面：色块里面的子容器 */
  --surface:#FFFFFF;
  --surface-55:rgba(255,255,255,.55); --surface-80:rgba(255,255,255,.8);
  --surface-pink:#FFF7FB;             /* 演示第二栏底 */
  /* 文字 */
  --ink:#0B0B0B;                      /* 所有浅色块上的字、黑胶囊底 */
  --ink-off:rgba(11,11,11,.45);       /* 步骤条里还没到的步骤 */
  --on-navy:#FFFFFF; --on-navy-2:#DCE0FA; --on-navy-3:#B9C1F0;
  /* 线：没有。块与块之间不画线 */
  /* 状态（演示里用） */
  --now:#0B0B0B;      /* 步骤条当前步：黑底白字 */
  --now-card:#DDF27A; /* 技术侧当前卡 */
  --done:#B4EAD0;     /* 已完成卡的编号圆 */
  --flash:#FFF0C4;    /* 被跳转命中的提示词段落、高亮栏 */
}
```

每一节的底色和块上的文字色（参考页的实际顺序）：

| 位置 | 块 | 底色 | 主文字 | 次要文字 |
|---|---|---|---|---|
| 首页首屏 | `.cb-hero` | `#DDF27A` | `#0B0B0B` | 同色 |
| 首页原话 | `.cb-q` | `#CFC2FF` | `#0B0B0B` | 同色 |
| 首页读者 | `.cb-aud` | `#1C2552` | `#FFFFFF` | 标签 `#B9C1F0` |
| 三个环节标题 | `.cb-sh` | `#FFF0C4` | `#0B0B0B` | 同色 |
| 环节 1 / 2 / 3 | `.cb-st` | `#FF8B66` / `#B4EAD0` / `#FFC7E3` | `#0B0B0B` | 同色 |
| 内容页首屏 | `.cb-chero` | `#1C2552` | `#FFFFFF`，h1 里 `em` 用 `#DDF27A` | 副标题 `#DCE0FA` |
| 01 目标 → 06 演示 | `.cb-b` | `#DDF27A` → `#FFF0C4` → `#CFC2FF` → `#FF8B66` → `#B4EAD0` → `#FFC7E3` | `#0B0B0B` | 同色 |
| 06 演示 · 续 | `.cb-b` | `#BFE2FF` | `#0B0B0B` | 同色 |
| 07 产出 | `.cb-b` | `#1C2552` | `#FFFFFF` | 说明 `#DCE0FA`，标签 `#B9C1F0`，大数字 `#DDF27A`，重点数字 `#FF8B66` |

- 浅色块上文字一律 `#0B0B0B`，不用灰色值分层；层级靠字号和字重。演示里的时间、署名小字用 `opacity:.7`–`.75` 淡化，是唯一例外。
- 海军蓝只放在开头和结尾（首页读者块、内容页首屏、产出块），中间各节不用。
- 珊瑚 `#FF8B66` 上只写黑字，不写白字。
- `--nvt:#E9ECFF` 在参考 CSS 里定义了但没有用到，不要拿来当新色块。
- 相邻两块不能同色；超过 8 节时按上表顺序循环，并检查首尾相接处。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;700;900&family=JetBrains+Mono:wght@400;700&family=IBM+Plex+Mono:wght@400;500&family=Nunito:wght@800;900&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 标题、大数字 | Nunito，中文落到 Noto Sans SC | 900，`letter-spacing:-.01em`；原话引文用 800、24px、行高 1.45 |
| 正文 | Noto Sans SC | 16px / 1.65；大段 `.cb-lg` 24px / 1.5、500；短说明 `.cb-w` 15px / 1.6；按钮 700 |
| 栏目标签 | IBM Plex Mono | `.cb-ey`：12px、500、`letter-spacing:.1em`、大写、行高 1.4 |
| 提示词原文 | JetBrains Mono | `.seg-code`：13px / 1.85 |

## 标题

- 首屏 h1：`.cb-hero h1` 84px、行高 1.05、`text-wrap:balance`；块底部对齐（`justify-content:flex-end`），上面留空。用 `.nb` 包住短语，避免中文断在词中间。
- 内容页首屏 h1：`.cb-chero h1` 76px、行高 1.08，关键词放进 `em`，染成 `#DDF27A`。
- 章节标题：`.cb-hd h2` 56px、行高 1.08；上面一行 `.cb-ey` 写「01 / 目标」，下面一句 19px、500 的说明。
- 区块标题：首页 `.cb-sh h2` 44px；环节卡 `.cb-st h3` 40px；块内小标题 `.cb-md` 22px、行高 1.35。
- 大编号：`.cb-n` 88px、行高 .9；小号 `.cb-n.sm` 56px；决策序号 `.cb-dn` 40px。

## 形状

- 圆角：拼贴外框 `.cb-mo` / `.cb-stack` 32px（窄屏 24px），靠 `overflow:hidden` 裁出来，里面的色块本身是直角。块内组件：`.cb-flow`、`.cb-sg`、`.cb-stage` 24px；`.cb-todo` 20px；`.cb-img` 18px；`.cb-tc`、`.cb-empty` 16px；`.cb-qq` 12px；按钮和标签 999px。
- 描边：只有三处。`.cb-img` 3px 黑框；`.cb-pills` 2px 黑框胶囊；内容页首屏 `.cb-ix` 2px 白框胶囊。
- 阴影：没有。
- 间距：首页色块 `.cb-t` 内边距 40px，首屏 56px 56px 52px、最小高 560px；内容块 `.cb-bi` 72px 56px，块内各组之间 36px。两张拼贴之间 20px 白缝，页面左右 20px。

## 版式

- 首页：两张拼贴，各是 12 栏网格、零间距。第一张：首屏占 8 栏 2 行，右侧上下叠原话（4 栏）和读者块（4 栏）。第二张：一整行「三个环节」标题块，下面三张环节卡各占 4 栏，三种底色。
- 内容页：一整列 `.cb-stack`，每节一块全宽色块 `.cb-b`，内容收在 1160px 内。顺序是海军蓝首屏 → 7 块浅色 → 海军蓝收尾。
- ≤1100px：首屏占满 12 栏，原话和读者块各 6 栏；五列网格变三列，演示三栏变两栏。
- ≤820px：页面左右 12px，色块内边距 28px 22px（内容块 44px 22px），全部单列；h1 收到 36px，章节标题 36px，五列网格变两列，步骤条变三列。

## 这个风格特有的禁区

- 块与块之间加分割线、加缝、加阴影。拼贴内部必须零间距直接相接，分节只靠换色。
- 相邻两块同色，或把海军蓝放在中间几节。前者分不出节，后者把页面切断。
- 在色块上直接再叠一层彩色卡片。块内的大面积子容器只用白、半透明白（.55 / .8）或 `#0B0B0B` 黑；彩色只给小件（编号圆、`.cb-key` 标签、`.ph` 槽位）和演示白底栏里的气泡、待办、写回卡。
- 给色块本身加圆角，或把拼贴拆成一张张独立圆角卡片。那会变成便当盒风格，不是拼贴。
- 标题降到 700 或以下，或换成细体。粗圆黑体是这套风格的骨架。
- 加彩色按钮。按钮只有黑、白两种胶囊；彩色只给块底和状态。
