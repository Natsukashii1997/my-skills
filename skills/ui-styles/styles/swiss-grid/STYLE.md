# 瑞士网格（swiss-grid）

一句话：像国际主义风格的印刷版面。靠一套 12 栏、24px 栏距的网格让每个元素对齐同一组栏线，用 300 细字重的超大标题和黑白两级细线分层，只用一种蓝。

参考页面：[reference.html](reference.html)（三步法样张，首页 + 内容页；截图是灰色占位）。CSS 规则以 `.st-24` 开头。动手前先通读它的 CSS 和 `TPL[24]` 模板，组件照着用，不要凭印象重写。

## 气质

- 冷静、理性、有秩序。信息靠位置和字号分层，不靠底色和卡片。
- 大面积留白，白底黑字，全部直角。
- 标题极大但极细（300），数字比文字更显眼。

## 适合 / 不适合

适合：
- 方法论、框架、原则这类结构清楚、分节固定的讲解页。
- 年度复盘、项目总结，需要大数字和清楚的章节编号。
- 设计规范、品牌规范这种本身就讲秩序的页面。

不适合：
- 组件多、交互多的工具型页面（表单、筛选、后台）。
- 要求温和亲切的面向家长、学生的页面。
- 段落很长、以连续阅读为主的文章。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  /* 底色 / 表面 */
  --bg:#FFFFFF; --soft:#F4F4F4;
  /* 文字 */
  --fg:#161616; --mut:#525252; --sub:#8C8C8C;
  /* 线 */
  --line:#E0E0E0;          /* 行与行之间 */
  --rule:#161616;          /* 开新区的黑线，即 --fg */
  --rule-mid:#C6C6C6;      /* 演示步骤条、图谱顶线、虚线 */
  --rule-grid:#D8D8D8;     /* 图谱格间 1px 缝 */
  --guide:rgba(15,98,254,.045);  /* 首屏 12 栏参考线 */
  /* 强调色：单一蓝 */
  --blue:#0F62FE; --blue-dark:#0043CE; --blue-tint:#EDF4FF;
  /* 状态 */
  --p0:#DA1E28;            /* 缺失、P0、重点数字 */
  --ok:#198038;            /* 复制成功 */
}
```

- 蓝 `#0F62FE` 用在：节号 `.sg-no`、当前环节的大数字和 2px 顶线、主按钮 `.sg-go`、内容页大节号、公式结果条、段落标签 `.sg-tag`、占位符、演示当前步。悬停和按下用 `#0043CE`。浅蓝 `#EDF4FF` 只给占位符底和段落跳转后的闪烁。
- 线分两级：1px `#161616` 黑线表示“开新区”（刊头、主线头、小节索引、公式、表头、提示词栏头）；1px `#E0E0E0` 灰线只分行。
- 灰底 `#F4F4F4` 只出现在演示行的场块、缩略图占位和代码片段底，别处不铺底色。
- 红 `#DA1E28` 只给“缺一块”标签、P0 待办和产出数字里的重点项。
- `#8C8C8C` 在白底上只有 3.36:1，低于 4.5:1：只给页码、刻度这类不用读的标注。参考页 `.sg-cap` 12px 标注用的是它，新页面要读的标注和说明改用 `#525252`（7.81:1）。
- 参考线 `--guide` 只在首屏顶部 620px 内，向下渐隐。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@300;400;500&family=IBM+Plex+Mono:wght@400&family=IBM+Plex+Sans:wght@300;400;500&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 正文 | IBM Plex Sans + Noto Sans SC | 15px / 1.65，`letter-spacing:.01em`；说明文字 14px `#525252` |
| 大标题 | 同上 | 字重 300；首页 h1 96px / 1.06、`letter-spacing:-.025em`；内容页标题 76px / 1.1，关键词用 `<b>` 500 |
| 中标题 | 同上 | 主线标题 32px、300；节名 28px、300；环节名 28px、400；副标题 22px / 1.5、300 |
| 数字 | IBM Plex Sans（`.sg-num` 开 tabular-nums） | 字重 300；内容页节号 220px / .78、`-.05em`；环节编号 120px / .9、`-.04em`；判断编号 56px；产出数字 40px |
| 标注 | 同上 | `.sg-cap` 12px `#8C8C8C`；节号 13px 蓝、500；刊头 13px |
| 等宽 | IBM Plex Mono | 提示词原文 13px / 1.8、`letter-spacing:0`；演示代码 12px |

## 标题

- 首屏 h1：`.sg-h1` 96px、300，占 1–11 栏，上距 96px，两行各一个 span 分行。下面同一行左边 1–6 栏是 22px 细字副标题（强调部分 `<b>` 500 黑色），右边 8–12 栏是引用，顶上 1px 灰线。
- 内容页首屏：`.sg-chd` 左 3 栏放 220px 蓝色节号，右 9 栏放 76px 标题，底部对齐。下接 `.sg-idx` 小节索引，顶上 1px 黑线。
- 章节标题：每节左 3 栏 `.sg-lab`，依次是 13px 蓝色节号、28px 300 节名、13px 灰色说明。节与节上距 104px，顶上 1px 灰线。
- 区块标题：不做标题，只用 12px 灰色 `.sg-cap` 标在内容上方。
- 窄屏：宽 1100px 以下 h1 72px、内容页标题 56px、节号 160px；820px 以下分别是 44px、38px、120px。

## 形状

- 圆角：0。全页直角，按钮、图片、色块都不加圆角。
- 描边：1px 为主；当前状态用 2px 蓝顶线（`.sg-st.is-on`）或 2px 黑顶线（输入产出的最后一格）；演示步骤条当前步 3px。按钮相邻时 `margin-right:-1px` 共用描边。
- 阴影：无。演示当前栏用 1px 黑色 outline 表示。
- 间距：容器最宽 1360px，左右 40px；12 栏，栏距 24px；节间 104px，主线头上距 136px；节内行距 32px；主按钮高 48px，演示按钮高 40px。

## 版式

- 首页：首屏 12 栏参考线 → 刊头 `.sg-mast`（顶上 1px 黑线，4 格各占 3 栏）→ h1 → 副标题与引用 → 主线头（节号 1–3 栏 / 标题 4–9 栏 / 说明 10–12 栏）→ 三个环节各占 4 栏，每个是大数字、环节名、说明、键值表、缩略图、按钮。
- 内容页：刊头 → 大节号加标题 → 小节索引 → 7 个 `.sg-row`。每行左 3 栏是节名，右 9 栏是内容；内容内部继续用 subgrid 按 9 栏切：目标 4 + 5，输入产出 3 + 3 + 3，判断 3 + 3 + 3，决策表 3 + 4 + 2，提示词原文 6 + 批注 3，演示三栏 3 + 3 + 3，产出缩略图 3 + 信息 6。演示那一节整行铺灰底。
- 宽 820px 以下：所有 subgrid 改成竖向 flex 单列，左右 16px；参考线只留 4 栏；决策表头隐藏；批注移到原文下方，左线改为顶线；公式 5 格变 2 列；数字 5 列变 2 列。

## 这个风格特有的禁区

1. 不用卡片、底色块和圆角分区。层级只靠位置、字号和线；全页唯一的灰底是演示那一节。
2. 每个元素都落在 12 栏栏线上。`grid-column` 写整数栏，子块用 subgrid 继承栏线；不用任意 px 宽度或自由的 flex 排版。
3. 大标题必须细（300）。改成 600、700 粗黑就成了另一种风格。强调用 `<b>` 500，不加颜色。
4. 只有一种蓝。加第二种彩色就散；红只表示缺失和风险。
5. 左 3 栏只放节号和节名，不塞正文；右 9 栏的内容不越过左边栏线。
6. 网格参考线只在首屏淡淡出现，不要铺满全页，也不要加深。
