# 精密暗色（precise-dark）

像一个深色的软件产品官网：近黑偏蓝底上分四级表面，1px 半透明细线，内容装进一块块“产品界面截图”式的窗口；全页只有一种淡紫蓝强调色，给焦点和主按钮。

参考页面：[reference.html](reference.html)（三步法样张，首页 + 内容页；截图是灰色占位）。CSS 规则以 `.st-22` 开头。动手前先通读它的 CSS 和 `TPL[22]` 模板，组件照着用，不要凭印象重写。

## 气质

- 克制、精确、安静。对比主要来自明度台阶，不来自颜色；彩色只在需要注意的地方出现。
- 标题大而紧：字距收到 `-.035em`，字重不超过 600，同一个标题分两段明暗。
- 主线、决策、提示词、演示都放进窗口里，像在看产品本身的界面：主线是项目列表，提示词是带审阅批注的编辑器，演示是工作台。

## 适合 / 不适合

适合：
- 介绍内部工具、平台能力、AI 工作流的产品说明页。
- 面向研发和产品的方案页，需要把列表、编辑器、事件流画成真实界面。
- 在投屏或暗光环境里看的讲解页。

不适合：
- 需要打印、导出 PDF 或长时间阅读的长文档。
- 主线超过一段、每段要用不同识别色区分的页面：这个风格只有一种强调色。
- 面向一线业务、需要温和亲切感的培训页。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  /* 底色 */
  --bg:#08090B;                 /* 页面底，近黑偏蓝；也用作代码块底 */
  /* 表面（四级，越往上越亮） */
  --s1:#0F1013;                 /* 卡片、窗口正文、胶囊 */
  --s2:#141519;                 /* 窗口标题栏、悬停行、选中卡 */
  --s3:#1A1B20;                 /* 批注框、标签、当前步骤格、对方消息 */
  --s4:#22232A;                 /* 标题栏圆点、我方消息、空状态圆圈 */
  /* 线 */
  --line:rgba(255,255,255,.07); /* 分隔线、行线 */
  --line2:rgba(255,255,255,.12);/* 窗口和卡片的外描边、强调描边 */
  /* 文字（四级） */
  --fg:#F4F5F6;                 /* 标题、卡片标题、关键值 */
  --fg2:#D0D4DB;                /* 正文默认色 */
  --mut:#8A8F98;                /* 副标题、说明 */
  --ter:#5E636B;                /* 表头、行号、日期、编号 */
  /* 强调色 */
  --acc:#8790F5;                /* 淡紫蓝：主按钮、焦点、当前态 */
  --acct:rgba(135,144,245,.14); /* 强调浅底：标签、结果胶囊、段落闪烁 */
  --on-acc:#0B0C1A;             /* 强调色实底上的字 */
  --acc-hover:#9EA5FA; --acc-press:#B0B6FB;
  --ph:#C9A6FF;                 /* 提示词里的 {{占位}} */
  /* 状态 */
  --ok:#4CB782;                 /* 已完成、已写回 */
  --warn:#E5A44B;               /* 缺项提示点、关键段落标记 */
  --p0:#EB5D5D;                 /* P0 优先级、重点数字 */
}
```

- `#8790F5` 只出现在：主按钮实底、列表当前行左侧 2px 内阴影线、进行中状态圆环、小节眉题 `.pd-ey`、批注头像、段落跳转标签、演示里被识别的关键词。不做大面积底，不做标题色。
- 强调色实底上的字一律用 `#0B0C1A`（6.78:1），不用白。
- `#5E636B` 在页面底上只有 3.29:1，只给 12–12.5px 的元信息（表头、行号、日期、编号）和 h1 的暗半句；要读的句子最浅用 `#8A8F98`（6.13:1）。
- 状态色只落在小面积上：圆点、圆环、优先级小块（`rgba(235,93,93,.15)` 浅底）、关键标记描边（`rgba(229,164,75,.35)`）。
- 层次靠表面阶梯：卡片 `#0F1013` 浮在 `#08090B` 上，悬停或选中升一级到 `#141519`。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;700&family=Geist:wght@400;500;600&family=Geist+Mono:wght@400&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 正文 | Geist，中文回落 Noto Sans SC | 15px / 1.65，默认色 `#D0D4DB`；卡片说明、表格行 14px |
| 标题 | Geist | 600，字距负值收紧（见下节）；卡片标题 17px / 500 / `-.01em` |
| 强调字 | Geist 500 | 列表环节名、决策判断、批注标题、数据值；正文内的重点都用 500 而不是 700 |
| 等宽 | Geist Mono 400 | `.pd-mono` 12px、`letter-spacing:0`：编号 D-1、行号、日期、业务流字段；提示词正文 13px / 1.8 |

中文在 600 下会取 Noto Sans SC 700，所以 link 里要 700。

## 标题

- **首屏 h1**（`.pd-h1`）：76px，行高 1.06，600，`letter-spacing:-.035em`，最宽 14em，左对齐。分两行：第一行 `#F4F5F6`，第二行包 `.pd-dim` 变 `#5E636B`。上方是 `.pd-badge` 胶囊眉题（6px 紫蓝圆点），下方是 19px 灰色副标题（重点词 `b` 提亮到 `#D0D4DB`、500）。
- **小节标题**（`.pd-sh h2`）：44px，行高 1.12，600，`-.025em`。上方一行 `.pd-ey` 眉题（13px、紫蓝、500），下方一句 16px 灰色说明，整组距内容 36px。
- **区块内标题**：窗口标题栏里的 `b`（13px、500、白）加一段灰色说明；卡片里先一行 12.5px `.pd-cl` 小标签，再 17px 标题。产出区标题 `.pd-rb h3` 26px / 600。
- 大字号断点：≤1100px 时 h1 收到 58px；≤820px 时 h1 40px、h2 30px。

## 形状

- 圆角：窗口、卡片、截图框 12px；批注框、待办卡、消息、业务流卡 10px；按钮 8px；小标签、复制按钮、选项胶囊 6px；P0 小块、高亮词 4px；眉题徽标、公式胶囊 999px。
- 描边：窗口和截图框用 1px `rgba(255,255,255,.12)`；普通卡片和行分隔用 1px `rgba(255,255,255,.07)`；空状态用 1px dashed。
- 阴影：只有 `.pd-win` 一处，`0 0 0 1px rgba(0,0,0,.6),0 30px 80px -40px rgba(0,0,0,.9)`。卡片不加阴影。
- 间距：内容宽 1200px、左右 32px；首屏 `padding-block:96px 56px`；小节之间 `padding-top:120px`；卡片网格间距 16px；卡片内边距 22px（判断卡 26px 24px）；列表行最低 64px、左右 20px。

## 版式

**首页**：左对齐首屏（眉题、两段明暗 h1、副标题、紫蓝主按钮加一行灰字）。下面紧接一个窗口“三步法 · 主线”，里面是项目列表 `.pd-list`：表头 36px 高，列宽 `200px | 1.2fr | 1fr | 1.3fr | 72px`（环节 / 要解决什么 / 提示词骨架 / 产出 / 日期），每行前面一个状态圆环；当前段那行是按钮，升一级底色、左侧紫蓝线、圆环半填。然后是“三份产出”小节，三张截图框横排。最后是带上边线的大引用（30px / 500）。

**内容页**：同样的首屏，之后每个小节都是“眉题 + h2 + 说明”开头：目标（左现状卡、右三张流程卡，最后一张选中）→ 先行判断（三卡）→ 设计决策（窗口里的表格行，`D-1` 编号、右列跳转标签）→ 骨架公式（胶囊用 28px 细线串起来，结果胶囊紫蓝描边浅底；下面三条缺项，顶线上一颗琥珀点）→ 提示词（编辑器窗口：40px 行号列 | 正文 | 300px 批注）→ 演示（控制按钮、工作台窗口：6 格进度条 + 三栏）→ 业务流五卡 → 产出范本（大截图 + 元信息表、五格数字条、两栏目录卡）。

**窄屏（≤820px）**：左右边距 16px；首屏 `52px 36px`；列表去掉表头，每行改成两行（环节名和日期一行，说明和标签另起）；小节间距 72px；所有多列网格改单列；决策行改单列；批注移到正文下方；进度条 6 格改 3 格；数字条改 2 列。≤1100px 时列表先去掉“产出”列。

## 这个风格特有的禁区

1. 不用纯黑底、纯白字：底是 `#08090B`，最亮的字是 `#F4F5F6`；纯黑纯白会让细线和表面阶梯全部失效。
2. 不加第二种强调色，也不给各段分配识别色；紫蓝变多就不再“只指焦点”。状态色只能落在点、环、小块上。
3. 字重不超过 600，标题不加粗到 700/800；大标题必须收字距，不收就显得松垮。
4. 不用阴影分层：阴影只在 `.pd-win` 上，卡片之间的区别只靠 `#0F1013` → `#141519` 的底色台阶和 `.07` / `.12` 两档线。
5. 别把内容平铺成段落：能画成列表、编辑器、事件流的，就放进窗口里当界面画。
6. `#5E636B` 不写正文：只给表头、行号、日期这类不需要细读的元信息。
