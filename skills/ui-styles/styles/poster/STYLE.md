# 大字动效（poster）

一句话：像一张黑底海报，标题做到 150px、字距收到 -0.055em 占满首屏；层次全靠字号落差和四级灰，页面往下滚时内容一块一块浮上来。

参考页面：[reference.html](reference.html)（三步法样张，首页 + 内容页；截图是灰色占位）。CSS 规则以 `.st-40` 开头。动手前先通读它的 CSS 和 `TPL[40]` 模板，组件照着用，不要凭印象重写。

## 气质

- 冷、静、有分量，像发布会主视觉或作品集首页。
- 没有任何彩色。白是最高一级，往下是 `#B4B4B4`、`#7A7A7A`、`#4A4A4A` 三级灰。
- 一屏只讲一件事：一个超大标题，配一两行灰色正文。
- 唯一的实心按钮是白色胶囊，其他按钮都是深灰底。

## 适合 / 不适合

适合：
- 项目发布、方法亮相的首页，需要第一眼有冲击力。
- 节数少（4–7 节）、每节有一句能做成大标题的结论的讲解页。
- 成果展示：几个关键数字放到 150px，配一句口径。

不适合：
- 信息密的说明文档、操作手册：大标题和大留白会把内容拉得很长。
- 需要打印或投到浅色会议屏上的材料。
- 用多种颜色区分主线的页面：这个风格没有识别色。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  /* 底色 */
  --bg:#000000;
  /* 表面 */
  --card:#0F0F0F;      /* 卡片、演示外框、图片占位 */
  --panel:#070707;     /* 演示里的三栏 */
  --soft:#1A1A1A;      /* 次按钮、气泡、待办卡、槽位底 */
  --soft-hover:#2A2A2A;/* 次按钮悬停、待办里的操作胶囊 */
  /* 文字 */
  --fg:#FFFFFF;        /* 标题、重点、实心按钮底 */
  --g1:#B4B4B4;        /* 正文 */
  --g2:#7A7A7A;        /* 标签、说明小字、编号 */
  --g3:#4A4A4A;        /* 标题里的弱化半句、未激活的大数字 */
  /* 线 */
  --line:rgba(255,255,255,.1);   /* 块与块之间的 1px 顶线 */
  --line2:rgba(255,255,255,.18); /* 胶囊描边、激活栏的内描边 */
  /* 强调：没有彩色。白色胶囊按钮的悬停 #DADADA，按下 #BDBDBD */
  /* 状态（演示里用） */
  --now:#FFFFFF;       /* 当前步：2px 白顶线；当前卡：1px 白内描边 */
  --done:#4A4A4A;      /* 已完成步：顶线变 g3，文字变 g1 */
  --pend-opacity:.3;   /* 还没到的卡 */
}
```

- 页面整体 `color-scheme:dark`，正文默认色是 `#B4B4B4`，不是白。白只给标题、加粗词和数值。
- `#4A4A4A` 在黑底上对比度约 2.4:1，只能用在大字和符号上（标题弱化半句、`.px-big` 编号、未激活的 `.px-nb` 数字、公式里 32px 的 + 和 =）。参考页的 `.px-off`、`.px-empty`、`.px-note` 小字也用了它，偏暗；新页面里小字最浅用 `#7A7A7A`（约 4.9:1）。
- 分隔只用 `--line` 一种 1px 顶线；不要用灰底块分节。
- 白底黑字只给这几样：`.px-pri` 主按钮、`.copy` 复制按钮、演示播放键 `.px-b.pri`、`.px-key` 标签，以及演示里自己发的气泡 `.px-msg.me` 和写回卡 `.px-wb`。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;700;900&family=JetBrains+Mono:wght@400;700&family=Bricolage+Grotesque:opsz,wght@12..96,800&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 标题、大数字 | Bricolage Grotesque 800，中文落到 Noto Sans SC | 字距随字号收紧：150px 用 `-.055em`，104px 用 `-.05em`，64px 用 `-.04em`，30px 用 `-.02em` |
| 正文 | Noto Sans SC | 17px / 1.6；大段 `.px-lg` 24px / 1.5；说明 `.px-w` 15px；小标题 `.px-md` 19px、700、白色 |
| 标签 | Noto Sans SC | `.px-k`：13px、500、`letter-spacing:.04em`、`#7A7A7A` |
| 编号、代码 | JetBrains Mono | 章节号 `.px-n` 15px；步骤号、段号 12–13px；提示词原文 13.5px / 1.85 |

## 标题

- 首屏 h1：`.px-hero h1` 为 `clamp(64px,10.4vw,150px)`、行高 .98、`letter-spacing:-.055em`。拆成两行：第一行一个短语，`<br>` 后第二行前半句加 `.px-dim` 染成 `#4A4A4A`，后半句白色。每段用 `.nb` 包住，不让中文在词中间断行。上方一行 `.px-ey`：15px 灰字，前面一条 28px × 1px 短线。
- 内容页首屏 h1：`.px-chero h1` 为 `clamp(56px,8.6vw,124px)`，结构同上。
- 章节标题：`.px-sh h2` 为 `clamp(48px,7vw,104px)`、行高 1、`-.05em`；上方 `.px-n` 写「01」，下方 `.px-s` 20px 灰色一句话。
- 区块标题：环节行 `.px-rl h3` 64px；判断句 `.px-xl` 30px；引文 `.px-quote blockquote` 48px、行高 1.25；演示结论 `.px-end` 30px。
- 大编号和大数字：`.px-big` 160px、行高 .8、`-.06em`，默认 `#4A4A4A`，所在行加 `.on` 才变白；`.px-big.sm` 96px；产出数字 `.px-nb` 为 `clamp(72px,10vw,150px)`，`.hot` 变白。

## 形状

- 圆角：胶囊 999px；演示外框 `.px-dm` 28px；卡片 `.px-card`、栏 `.px-pn`、图片 20px；待办 18px；写回卡 16px；技术卡 14px；代码块 10px；槽位 `.ph` 6px。
- 描边：块间 1px `--line` 顶线；`.px-chips` 和 `.px-fxr` 胶囊 1px `--line2`；步骤条每格 2px 顶线。
- 阴影：不用投影。只用 `box-shadow:inset 0 0 0 1px` 当描边，标出激活栏和当前卡。
- 间距：容器 1280px，左右 32px，上 40px、下 160px。首屏上下 72px / 96px；节与节之间 `padding-top:120px`；环节行上下 56px，两栏间 64px；卡片内边距 22px，卡片之间 12px。

## 版式

- 首页：首屏海报（标签、两行大标题、右下角副标题和两个按钮）→ 48px 引文块 → 三栏事实条 → 「三个环节」章节头 → 三行环节，每行左边 160px 灰编号加 64px 标题，右边缩略图。
- 内容页：首屏海报（按钮换成「← 首页」和一排小号目录胶囊）→ 7 节，每节一个大章节头接内容。节内用两栏文字、三格卡片、整行列表（判断、决策、提示词段）、演示框几种结构，行与行之间都是 1px 顶线。
- ≤1100px：环节行变单栏；演示三栏变两栏；五列卡变三列。
- ≤820px：左右 18px；首屏 h1 56px、内容页 h1 46px、章节标题 48px、`.px-big` 110px、h3 44px、引文 28px、`.px-nb` 76px；所有两栏、三栏变单栏，节间距 80px。

## 进场方式

这是全库唯一被允许的「风格自带进场」：内容块在第一次滚到时上浮一次，之后不再动。

- 带 `.px-r` 的元素：首屏的标签、h1、`.px-hb`；首页的 `.px-quote`、`.px-facts`、每个 `.px-sh`、每个 `.px-row`；内容页的 `.px-g2`、`.px-g3`、每个 `.px-jd`、`.px-dr`、`.px-fxr`、`.px-eq`、`.px-pbar`、每个 `.px-sg`、`.px-dm`、`.px-g5`、`.px-rep`、每个 `.px-num`、`.px-toc`。粒度是「一块」，不拆到每个字、每张卡。
- 过渡：`.px-r` 上写 `opacity` 和 `transform` 两项过渡，各 .9s，曲线 `cubic-bezier(.16,1,.3,1)`。隐藏态 `.px-wait` 是 `opacity:0` 加 `translateY(56px)`。不加延迟，不做依次错开。
- 什么时候加 `.px-wait`：页面渲染后跑一次 `init`，只给顶边低于视口高度 92% 的元素加。首屏里的元素从不加，所以首屏不等动画就完整可读。
- 什么时候出现：监听 `scroll` 和 `resize`（`passive:true`），元素顶边进入视口 88% 以内时，去掉 `.px-wait`，加上 `.px-in2`。`.px-in2` 只是标记，没有对应样式，元素回到默认态靠的是去掉 `.px-wait` 触发的过渡。
- 兜底：`init` 后 20 秒（`later(…,20000)`），不管滚没滚到，全部去掉 `.px-wait`。切换页面时移除两个监听。
- `prefers-reduced-motion: reduce`：脚本开头 `if(RM)return`，一个 `.px-wait` 都不加；CSS 里同时把 `.px-r` 的过渡设为 none，`.px-wait` 强制 `opacity:1`、`transform:none`。
- 边界：只做这一次性浮现。不做视差，不循环，不跟着滚动位置连续变化（不按滚动比例改透明度、位移、缩放），往回滚也不重新隐藏。演示区内部的逐步出现另走演示控制器，不借用 `.px-r`。

## 这个风格特有的禁区

- 加颜色。渐变卡片、彩色标签、彩色高亮都不要；要强调就换成白色或加大字号。
- 把进场做大：加长时长、加错开延迟、改成从侧面飞入、给首屏元素也加 `.px-wait`，或者每次滚回来都重播。
- 标题不够大或字距不收。首屏 h1 低于 `clamp(64px,10.4vw,150px)`、字距保持 0，就只是一张普通黑底页。
- 中文大标题不加 `.nb` 和 `<br>` 控制断行，让 150px 的字在词中间折行。
- 同一屏出现两个白色实心按钮。主操作用一个 `.px-pri`，其余用 `.px-ghost`。
- 卡片加边框或投影。卡片只靠 `#0F0F0F` 和黑底的一级明度差分开。
