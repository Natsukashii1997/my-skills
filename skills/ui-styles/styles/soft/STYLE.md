# 柔光（soft）

像一张 SaaS 产品功能页：浅蓝灰底上浮着白色大圆角卡片，靠柔和投影而不是描边分层，产品演示放在首屏当主视觉，讲解收进标签页。

参考页面：[reference.html](reference.html)（三步法样张，首页 + 内容页；截图是灰色占位）。CSS 规则以 `.st-4` 开头。动手前先通读它的 CSS 和 `TPL[4]` 模板，组件照着用，不要凭印象重写。

## 气质

- 亲和、轻、有产品感。读者先看到“它用起来是什么样”，再按需点开“为什么这样做”。
- 层次来自三件事：浅底与白卡的明度差、一档柔和投影、圆角大小的分级。几乎不用线。
- 全部按钮、标签、步骤都是胶囊形（999px），没有直角元素。

## 适合 / 不适合

适合：
- 介绍一个工具、工作台或 AI 功能“用起来什么样”的功能页、上线说明。
- 给一线业务、销售、运营看的流程讲解，读者不想读长文。
- 需要首屏放一段可播放演示、其余细节按需展开的页面。

不适合：
- 信息密度高、需要并排对照大量数据的分析报告。
- 严肃的制度、规范、合规类文档：圆角胶囊显得太轻。
- 必须一屏读完全部论证、不能藏进标签页的评审材料。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  /* 底色 */
  --bg:#EEF1F6;          /* 页面底，浅蓝灰 */
  /* 表面 */
  --card:#FFFFFF;        /* 卡片、应用窗口 */
  --soft:#F5F7FA;        /* 卡片里的内嵌块、胶囊底 */
  --chrome:#F8FAFC;      /* 应用窗口标题栏 */
  --chat:#F3F5F8;        /* 演示里聊天列的底 */
  --col-on:#FAFCFD;      /* 演示里当前列 */
  /* 文字 */
  --fg:#1B2333;          /* 正文、标题；也是深色主按钮的底 */
  --fg2:#4A5568;         /* 次要正文 */
  --mut:#667085;         /* 标签、说明、元信息 */
  /* 线 */
  --line:#E2E7EF;        /* 只用于窗口内分栏线、目录行线 */
  /* 强调色 */
  --c1:#EE7340; --c1t:#FDECE3;                 /* 橙：P0、缺项、引用头像、闪烁定位 */
  --c2:#2A8C83; --c2t:#DDF1EE; --c2d:#1B655E;  /* 青绿：主强调色 */
  --c3:#6A5AE0; --c3t:#ECE9FD;                 /* 紫：只在首页给第 3 段 */
  /* 演示专用 */
  --dot-r:#FF5F57; --dot-y:#FEBC2E; --dot-g:#28C840;  /* 窗口三色灯 */
  --bubble-me:#95EC69;   /* 聊天里“我方”气泡 */
  --mark:#FFE58F;        /* 聊天里被识别出的关键词 */
  /* 投影 */
  --sh:0 1px 2px rgba(27,35,51,.05),0 12px 32px -8px rgba(27,35,51,.12);
  --sh-win:0 30px 60px -24px rgba(27,35,51,.28);
}
```

- 青绿 `#2A8C83` 是唯一主强调色：主线当前步、目标卡实底、数字、选中按钮悬停、`.sf-fxr` 结果块。浅底 `#DDF1EE` 上的字用深青 `#1B655E`（5.83:1）。
- 白字压在 `#2A8C83` 上只有 4.06:1，低于 4.5:1：只用于 18px 以上粗体的短字（实底卡标题）。参考页按钮是 14px 白字，新页面小号白字改放在深青 `#1B655E` 实底上（6.84:1）。
- 橙 `#EE7340` 在 `#FDECE3` 上只有 2.55:1：参考页拿它做 12px 粗体优先级标签，新页面这类标签的字改用 `#1B2333`（13.7:1），橙色只留给浅底、顶线和大号数字。
- `--mut` `#667085` 放在页面底 `#EEF1F6` 上是 4.39:1，略低于 4.5:1；要读的说明小字放在白卡上用（4.97:1）。
- 三段识别色（橙、青绿、紫）只在首页步骤条和三张卡的 3px 顶线上同时出现；内容页只用当前段的颜色。参考页内容页是环节二，所以写死了 `--c2`，做别的环节时把这些 `var(--c2*)` 换成该段颜色。
- `#95EC69`、`#FFE58F` 和三色灯只在演示窗口里模拟真实界面，页面其他地方不用。
- 深色主按钮是 `#1B2333` 底白字，不是品牌色底。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;700;900&family=JetBrains+Mono:wght@400&family=Manrope:wght@500;700;800&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 正文 | Noto Sans SC | 16px / 1.7；卡片说明 14px；元信息 12.5–13px |
| 标题 | Manrope（中文回落 Noto Sans SC） | 800，`letter-spacing:-.02em`；h1 里的灰色半句用 500 |
| 数字、步骤号 | Manrope | 统计数字 44px / 800；产出数字条 24px / 800；圆点编号 12px / 700 |
| 代码 | JetBrains Mono | 只在演示的 `.code` 块里，12px / 1.6 |
| 提示词正文 | Noto Sans SC | `.sf-code` 15px / 1.85，不用等宽 |

中文在 800 下会取 Noto Sans SC 900，在 600 下取 700，所以 link 里要 900 和 700。

## 标题

- **首屏 h1**（`.sf-h1`）：`clamp(40px,4.8vw,66px)`，行高 1.12，800，`-.02em`，左对齐。第二行开头一段包在 `span` 里，变 `#667085` 灰、500 字重，做轻重对比。上方放一颗 `.sf-pill` 胶囊眉题（白底、投影、8px 青绿圆点）。
- **内容页标题**（`.sf-h2`）：`clamp(34px,4.4vw,58px)`，行高 1.15，800，居中；关键词 `span` 变青绿。上方同样是胶囊眉题，下方 18px 副标题。
- **区块标题**：不用大标题。每个区块是一张卡，卡里第一行是 `.sf-lab`（13px、700、灰）的短标签；大块内容用 `.sf-tabs` 标签页的按钮名当标题。演示下方用 `.sf-cap`（17px、700、居中）写一句结论。

## 形状

- 圆角分级（从外到内递减）：演示舞台 28px → 主卡片 22px → 应用窗口、流程卡 18px → 小卡、聊天待办 16px → 内嵌块 14px → 代码、元信息块 10–12px → 缩略图、占位符 6px。按钮、标签、步骤、胶囊一律 999px。
- 描边：卡片不加描边。1px `#E2E7EF` 只出现在应用窗口标题栏下沿、演示分栏、目录行之间；首页三张段落卡用 3px 顶线标段色。
- 投影：普通卡、按钮、胶囊都用 `--sh`；浮起的应用窗口用 `0 30px 60px -24px rgba(27,35,51,.28)`（演示窗口 .3）；内嵌块不加投影。
- 间距：卡片内边距 20–24px；卡片间距 12–14px；区块 `padding-block:40px`；首页首屏 `56px 32px`，引用区 `16px 88px`。

## 版式

**首页**：两栏首屏（`.sf-hin`，左 .9fr、右 1.25fr，间距 48px）。左栏依次是胶囊眉题、h1、副标题、深色胶囊按钮加一行灰字。右栏是一个产品窗口 `.sf-mock`：三色灯标题栏，里面是三步胶囊步骤条（当前步浅青绿底）、三张段落卡（顶线段色、标签、产出缩略图）、底部一行循环说明。下面一排是引用卡加三张统计卡。

**内容页**：居中标题区下面直接放演示——青绿浅底的大圆角舞台 `.sf-stage` 里放白色应用窗口，三栏是聊天 / 系统后台 / 侧边栏；下方左边胶囊步骤、右边播放按钮，再一句结论。接着是“现在的问题 → 这一步要做到”两张卡（目标卡青绿实底白字）、三格输入产出、五格业务流。最后一组 `.sf-tabs` 收起四块：为什么这样写 / 设计决策 / 提示词 / 产出范本。

**窄屏（≤820px）**：所有多列网格改单列；步骤条改竖排；演示三栏改上下排、栏间换上边线；舞台内边距收到 12px；产出数字条改 2 列；目标卡之间的箭头转 90 度。

## 这个风格特有的禁区

1. 卡片不加描边，也不加深投影：分层只用 `--sh` 这一档，靠白卡浮在 `#EEF1F6` 上；一加 1px 边框就变成后台表单。
2. 圆角只用上面的级别，不出现直角卡片，按钮不做成 8px 小圆角——要么卡片圆角，要么胶囊。
3. 内容页首屏必须是演示，不能先放大段文字；判断、决策、提示词、产出放进标签页，不平铺成长页。
4. 不加第四种强调色，不做渐变彩色背景。舞台的浅青绿是纯色（`linear-gradient(var(--c2t),var(--c2t))`），不是渐变效果。
5. 橙色不当主色：它只表示优先级、缺项和定位闪烁，大面积用会让页面变成警告。
6. 演示里的微信绿气泡、黄色高亮、三色灯是模拟真实界面，不能拿到页面装饰里用。
