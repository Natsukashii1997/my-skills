# 玻璃拟态（glass）

一句话：像浅色的 Raycast。冷灰底上铺几团大面积模糊的粉彩色块，内容放进半透明磨砂面板；首页就是一块命令面板，快捷键用键帽提示，键盘真能操作。

参考页面：[reference.html](reference.html)（三步法样张，首页 + 内容页；截图是灰色占位）。CSS 规则以 `.st-32` 开头。动手前先通读它的 CSS 和 `TPL[32]` 模板，组件照着用，不要凭印象重写。

## 气质

- 轻、透、安静：颜色只在背景的模糊色块和 28px 小图标里，前景是白色磨砂和深色字。
- 像一个桌面工具，不像网页：主要单元是列表项（图标 / 标题 / 副标题 / 右侧附属），右侧挂键帽和小标签。
- 键帽 `kbd` 是页面里唯一有立体感的元素。

## 适合 / 不适合

适合：
- 工具、插件、工作流的介绍页：本身就有「搜索 → 挑选 → 打开」的使用方式。
- 条目目录、命令清单、模板库：一列可选项，右边看详情。
- 给效率工具用户看的方案说明：读者习惯快捷键。

不适合：
- 数字和表格多的页面：半透明底上读数字吃力（用 data-table）。
- 长篇正文、报告：磨砂面板叠多了很闷。
- 深色主题需求：这套只做浅色。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  /* 底色：冷灰底 + 模糊色块（filter:blur(70px)，opacity:.75） */
  --bg:#EDEFF4;
  --blob-1:#FFC7A6; --blob-2:#A9D8FF; --blob-3:#B4EBD3; --blob-4:#FFC0D2;
  --blob-5:#FFE7A3; --blob-6:#FFD9B8; --blob-7:#B9DCFF; --blob-8:#C4EEDC;
  /* 表面：半透明白 */
  --glass:rgba(255,255,255,.56);  /* 四种磨砂容器的底 */
  --glass2:rgba(255,255,255,.74); /* 胶囊小标题 */
  --sel:rgba(255,255,255,.86);    /* 选中的列表项、段落按钮、演示当前步 */
  --edge:rgba(255,255,255,.8);    /* 磨砂容器的 1px 白描边 */
  /* 文字 */
  --ink:#14161D;  /* 标题、列表项标题、主按钮底 */
  --fg:#2E323D;   /* 正文 */
  --mut:#5C6274;  /* 副标题、说明句 */
  --ter:#8B91A1;  /* 分组小标题、计数、提示 */
  /* 线 */
  --hair:rgba(24,28,44,.09);  /* 分隔线、0.5px 外轮廓 */
  --hair2:rgba(24,28,44,.14); /* 键帽描边、选中项轮廓 */
  /* 强调色 */
  --orange:#E8692F;  /* 搜索框光标；内容页 h1 关键词渐变 #E8692F → #D9475E */
  --blue:#3D8EE6;    /* 键盘焦点框、演示运行中的步骤、代码关键字 */
  /* 图标渐变（160deg，浅 → 深），类名 .gl-pe .gl-mi .gl-sk .gl-ro .gl-bu */
  --ic-pe:#FFB38A,#F2804F; --ic-mi:#62D6A9,#25A97A; --ic-sk:#7CBEFF,#3D8EE6;
  --ic-ro:#FF9DB6,#E3607F; --ic-bu:#FFD66B,#E8A91F;
  /* 键帽 */
  --kbd:#FFFFFF,#E9ECF2;      /* 普通键帽，竖向渐变 */
  --kbd-dark:#2A2D38,#14161D; /* 结果键帽、演示当前步 */
  /* 状态 */
  --p0:#D9475E;     /* P0 小标、警示数字 */
  --ok:#25A97A;     /* 完成勾、复制成功 */
  --ok-bg:#DDF3E8;  /* 已写回提示条、聊天里自己的气泡 */
  --mark:#FFE08A;   /* 演示里被识别出的词 */
  --ph:#C2410C;     /* 提示词 {{槽位}} 文字，底 rgba(255,199,166,.45) */
  --key:#B4532A;    /* 「最关键的一句」小标 */
  --flash:#F2804F;  /* 跳到提示词段落后的 2px 外框 */
}
```

- 磨砂配方只给四种容器：命令面板 `.gl-pal`、首屏引用 `.gl-q`、内容页面板 `.gl-pn`、吸顶导航 `.gl-nav`。配方是 `backdrop-filter:blur(28px) saturate(170%)` + 1px 白描边 + 四层阴影（见「形状」）。面板里面的列表项不再叠磨砂，只用 `rgba(255,255,255,.42)` 或 `rgba(255,255,255,.5)` 加 0.5px 轮廓。
- 渐变只出现在三处：28px 图标、内容页 h1 的 `em` 关键词、胶囊小标题前的小圆点（`#F2804F` → `#E3607F`）。按钮、面板、背景不用渐变。
- 主按钮是深色 `#14161D` 实底白字，不是彩色。
- `#8B91A1` 在页面底上只有 2.74:1，低于 4.5:1：只给计数、快捷键提示这类不用读的标记。分组标题、副标题这类要读的字用 `#5C6274`（5.28:1）；参考页分组标题 `.gl-grp` 用的是 `#8B91A1`，新页面改掉。

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;700&family=JetBrains+Mono:wght@400;700&family=Figtree:wght@400;500;600;700&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 标题 | Figtree + Noto Sans SC | 700 字重、负字距：h1 58px / 1.12、`letter-spacing:-.025em`；面板 h2 26px、`-.015em`；详情 h3 24px、`-.015em` |
| 正文、列表 | Figtree + Noto Sans SC | 根字号 15px / 1.6；列表项标题 14.5px、600，副标题 13px 灰；搜索框文字 19px、500 |
| 键帽 | Figtree | 11.5px、600，20px 高；公式大键帽 `kbd.gl-big` 16px、44px 高 |
| 提示词原文、目录编号、代码 | JetBrains Mono | 原文 12.5px / 1.8；目录编号 `.gl-cn` 12px |

## 标题

- 首屏 h1：58px、700、`line-height:1.12`、`letter-spacing:-.025em`，颜色 `#14161D`；上方是胶囊小标题 `.gl-pill`（28px 高、全圆、渐变小圆点），下方 18px 灰色副标题 `.gl-sub`，里面的加粗变成深色 600。窄屏 36px。
- 内容页 h1 同字号，关键词包在 `em` 里，用 `#E8692F` → `#D9475E` 的文字渐变。全页只有这一处彩色标题。
- 章节标题在面板头 `.gl-pnh` 里：h2 26px、700，右边同一行接 14px 灰色说明，最右是 `.gl-hint`（「按键跳到这里」+ 键帽）。
- 列表分组标题 `.gl-grp`：12px、600、`#8B91A1`，后面接一句 400 字重的小字。

## 形状

- 圆角：命令面板、内容页面板 18px；首屏引用 16px；吸顶导航、演示小窗 14px；提示词行、待办卡、数字格、产出封面图 12px；列表项、主按钮、公式大键帽、命令面板详情图 10px；演示按钮、复制按钮 9px；28px 图标、段落按钮、跳转按钮 8px；标签 6px；普通键帽 5px；胶囊小标题全圆 999px。
- 磨砂容器阴影：`0 0 0 .5px var(--hair),inset 0 1px 0 rgba(255,255,255,.9),0 10px 34px rgba(34,42,80,.10),0 2px 6px rgba(34,42,80,.05)`。顶部那道内阴影是玻璃的高光边，不能省。
- 选中列表项：`var(--sel)` 底 + `0 0 0 .5px var(--hair2),0 2px 8px rgba(34,42,80,.08)`。
- 键帽：`linear-gradient(#FFFFFF,#E9ECF2)` + 1px `var(--hair2)` 描边 + 底部 `0 1px 0 rgba(24,28,44,.16)`。
- 间距：内容区最大宽 1120px、左右 32px、`padding-block:56px 120px`、区块 `gap:28px`；面板内边距 8px，列表项 `padding:9px 10px`；命令面板列表 `gap:2px`，内容页列表 `gap:6px`。

## 版式

- 外壳：`.glr` 根容器里先放背景层 `.gl-bg`（8 团色块，`z-index:-1`），再放 1120px 内容 `.gl-in`。
- 首页：首屏 `.gl-hero` 两列（左标题、右磨砂引用 `.gl-q`，底对齐）；下面整宽命令面板 `.gl-pal`：60px 高搜索行（放大镜、查询词 + 闪烁光标、「N 项」、⌘K 键帽）→ 左列表右详情两栏（最小高 440px）→ 底栏（应用名 + ↑↓ 挑选、↵ 打开 + 一句串联说明）。
- 内容页：吸顶磨砂导航 `.gl-nav`（面包屑 + 7 个带数字键帽的跳转按钮）→ 标题区 `.gl-chd` → 每节一块 `.gl-pn` 面板。面板里用列表项 `.gl-it` 组织：目标是两项并排 `.gl-two` + 三格流程 `.gl-flow`；判断和决策是 `.gl-ls` 列表；公式是一排大键帽；提示词每段一行；演示是三扇小窗；产出是封面 + 数字格 + 两列目录。
- 窄屏：≤980px 首屏变单列、演示三窗变两窗；≤820px 左右 16px、h1 36px，命令面板变成列表在上、详情在下，列表项右侧键帽隐藏；导航吸顶 8px，跳转按钮横向滑动，键帽和按键提示隐藏（手机没有键盘）。

## 关键组件

| 构件 | 类名 | 样子 | 什么时候用 |
|---|---|---|---|
| 背景色块 | `.gl-bg` | 8 团圆形粉彩，`blur(70px)`，铺在内容后面不动 | 每页都要，是磨砂能透出颜色的前提 |
| 命令面板 | `.gl-pal` + `.gl-srch` + `.gl-list` + `.gl-det` + `.gl-foot` | 18px 圆角磨砂；搜索行 / 左列表右详情 / 底部快捷键提示 | 首页主体：把几个入口做成可挑选的列表 |
| 列表项 | `.gl-it` + `.gl-ic` + `.gl-itt` + `.gl-acc` | 28px 渐变图标、粗体标题 + 灰色副标题、右侧标签和键帽；选中项更白并浮起一点 | 全页的基本单元 |
| 键帽 | `kbd` / `kbd.gl-big` / `kbd.gl-res` | 白到浅灰竖向渐变、底部 1px 阴影；结果键帽是深色 | 快捷键提示；公式里每一项 |
| 磨砂面板 | `.gl-pn` + `.gl-pnh` + `.gl-hint` | 18px 圆角，头部 h2 + 说明 + 「按键跳到这里」键帽 | 内容页每一节 |
| 吸顶导航 | `.gl-nav` + `.gl-jumps` | 14px 圆角磨砂条，跳转按钮各带数字键帽 | 内容页顶部 |
| 段落按钮 | `.gl-seg` | 28px 高白底小按钮，段落名 + ↵ 键帽 | 决策列表右侧，跳到提示词段落 |
| 提示词行 | `.gl-sg` + `.gl-sn` | 两列：等宽原文 / 300px 批注（小图标 + 段名 + `.gl-key` 小标） | 逐段解释长文本 |
| 演示小窗 | `.gl-w` + `.gl-wh` + `.gl-dots` | 14px 圆角半透明窗，标题栏三个灰点；当前窗 `.act` 底色加到 `rgba(255,255,255,.82)`、上浮 2px | 演示的三个系统 |
| 主按钮 | `.gl-pri` | 38px 高深色实底，右侧嵌一个半透明键帽 | 进入下一页、打开原文 |

交互（都在 `TPL[32].init` 里）：
- **首页命令面板**（`if(p==='home')` 分支）：列表项是 `role="option"` 的按钮。鼠标移入即选中；`↑` `↓` 循环移动选中并聚焦；数字 `1`–`3` 直接选第几个环节；每次选中由 `sel()` 用 `ITEMS[i].det()` 重画右侧详情。已选中「环节二」时再点它（或在它上面按回车）进入内容页；详情里的 `.gl-pri`（`data-go-ch`）也进入内容页。
- **内容页数字键跳转**（`else` 分支）：全局监听 `1`–`7`，点击对应的 `.gl-jumps [data-jump]`；按着 ⌘ / Ctrl / Alt 或焦点在输入框里时不响应。
- 搜索框光标 `.gl-car` 以 1.1s 闪烁（`glBl`），表示面板可输入；`prefers-reduced-motion` 时停掉，演示小窗也不再上浮。
- `.gl-seg` 的 `data-seg` 由通用行为滚到对应 `.gl-sg` 并加 `.flash`（2px `#F2804F` 外框）。

## 这个风格特有的禁区

1. **不做深色玻璃。** 底色固定 `#EDEFF4`，面板是半透明白，字是深色。改成黑底霓虹就是另一种风格。
2. **不层层叠磨砂。** `backdrop-filter` 只用在四种容器上；面板里的列表项、数字格、小窗只用半透明白加 0.5px 轮廓。叠多了会糊，也很耗性能。
3. **色块只在背景。** 彩色来自 `.gl-bg` 的模糊色块和 28px 图标；不要给面板、按钮、文字大面积上色，也不要让色块动起来。
4. **键帽出现就要能按。** 页面上画了哪个键（↑↓、↵、1–3、1–7），就必须接上对应的键盘操作；没有键盘的窄屏把键帽提示藏掉。参考页搜索行的 ⌘K 只是「这是命令面板」的标识，没有接按键；新页面放它就要接上（例如聚焦列表），否则去掉。
5. **面板不能没有高光边。** 去掉 `inset 0 1px 0 rgba(255,255,255,.9)` 和 1px 白描边，磨砂面板会变成灰蒙蒙的普通卡片。
6. **列表项结构不改。** 一律「图标 / 标题 + 副标题 / 右侧附属」，不要在面板里塞大段正文或表格。
