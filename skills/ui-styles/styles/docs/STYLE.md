# 文档站（docs）

一句话：像开发者文档站。靠固定的三栏骨架（目录 / 正文 / 本页大纲）、白底冷灰细线和一种深青绿，把内容装进提示框、参数表、步骤条这些读者熟悉的文档组件里。

参考页面：[reference.html](reference.html)（三步法样张，首页 + 内容页；截图是灰色占位）。CSS 规则以 `.st-23` 开头。动手前先通读它的 CSS 和 `TPL[23]` 模板，组件照着用，不要凭印象重写。

## 气质

- 克制、可查。读者是来找东西的，不是来看展示的。
- 标题最大只有 34px，层级靠目录位置、面包屑和 22px 的章节标题区分。
- 颜色只做标记：青绿表示“当前 / 可点”，蓝和琥珀只出现在提示框里，深色只给代码。

## 适合 / 不适合

适合：
- 方法手册、操作指南、规范说明，有多页、要来回翻。
- 提示词、配置、接口这类需要逐段对照解释的文本。
- 内部知识库页面，读者会按目录跳着看。

不适合：
- 发布会、对外宣传、需要第一眼抓人的落地页。
- 只有一屏的结论汇报或数据大屏。
- 没有分节、内容不到三屏的单页。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  /* 底色 / 表面 */
  --bg:#FFFFFF; --soft:#F6F7F9;
  /* 文字 */
  --fg:#141A21; --fg2:#3B4450; --mut:#6A7380;
  /* 线 */
  --line:#E4E7EB; --line2:#EEF0F3;
  /* 强调色：深青绿 */
  --acc:#0B7A64; --acct:#E7F3EF;
  /* 状态：提示框与优先级 */
  --note:#1F5FA8; --notet:#EEF4FB; --notel:#CFE0F3;   /* 说明 */
  --warn:#8F5200; --warnt:#FFF7E8; --warnl:#F3DDB3;   /* 风险、现状 */
  --p0:#C2362F;                                        /* P0、重点数字 */
  /* 代码区（深色） */
  --code:#0E1217; --code2:#161B22; --codel:#252C36;
  --codefg:#D5DCE4; --codemut:#7D8794; --codeph:#E7C27D;
}
```

- `--acc` 用在：当前目录项、面包屑、参数名、编号、`.dc-tag` 标签、`.dc-more` 链接、演示当前步。浅底 `--acct` 只给标签、徽章和 tip 提示框。不用它做标题色或大面积底色。
- 正文用 `--fg2`，标题和表格首列用 `--fg`，辅助小字最浅用 `--mut`。`#9AA2AD` 只用于目录里“未展开”的斜体小字，`#B3BAC3` 只用于面包屑分隔符、锚点 `#` 和元信息圆点。
- 蓝 `--note*` 和琥珀 `--warn*` 只出现在 `.dc-call` 提示框里，tip 提示框边线是 `#CBE6DE`。
- 深色 `--code*` 只给代码：骨架公式、提示词原文、演示里的代码片段。代码里的高亮用 `#7FD8C0`，占位符用 `--codeph`，行号用 `#4A5360`。
- 红 `--p0` 只给 P0 待办（底色 `#FDECEA`）和产出数字里的重点项。
- 演示里聊天关键词高亮用 `#FFE6A8` 底加 `#F1C766` 描边，别处不用黄色。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;700&family=Geist+Mono:wght@400;500&family=Instrument+Sans:wght@400;500;600&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 正文 | Instrument Sans + Noto Sans SC | 15px / 1.75，颜色 `--fg2`；段落最宽 42em；导语 `.dc-lead` 17px / 1.7 |
| 标题 | 同上 | 字重 600（中文落到 Noto Sans SC 700）；h1 34px / 1.25、`letter-spacing:-.01em`；h2 22px / 1.35；h3 17px |
| 导航小字 | 同上 | 目录项 14px / 1.5；大纲 13px；目录分组名 11.5px、600、`letter-spacing:.06em` |
| 等宽 | Geist Mono | 行内 code `.86em`；版本号 11.5px；类型、日期 12px；骨架公式 14px / 1.7；提示词原文 13px / 1.75；行号 12px |

## 标题

- 首屏 h1：`.dc-h1` 34px、600，上面是 13px 青绿面包屑 `.dc-crumb`，下面接 17px 导语和 13px 元信息行 `.dc-meta`（圆点分隔，底部 1px `--line`）。不另做首屏大图或色带。窄屏 27px。
- 章节标题：`.dc-h2` 22px、600、黑色，上距 52px、下距 12px；悬停时右侧出现灰色 `#` 锚点 `.dc-anc`。每个 h2 对应右侧大纲一项。
- 区块标题：步骤和卡片里的 h3 17px、600；目录分组 `.dc-toc-h b` 15px。不用彩色短线、编号大字这类装饰。

## 形状

- 圆角：提示框、表格、参数卡、翻页卡 10px；代码块、演示框、产出卡、数字条 12px；演示内画布 9px、按钮 7px、技术卡 8px；行内 code 5px，标签 6px；版本号胶囊 999px；步骤编号 28px 圆。
- 描边：一律 1px `--line`，表格行间用 `--line2`。当前目录项是 2px 青绿左边线。
- 阴影：没有投影。只有两处描边式阴影：演示当前步 `0 0 0 1px`、当前技术卡 `0 0 0 3px var(--acct)`。
- 间距：顶栏高 56px；三栏 240px / 正文最宽 760px / 208px，栏距 56px，左右 28px；正文上下 40px / 96px；步骤之间 30px；提示框内边距 14px 16px。

## 版式

- 首页：吸顶顶栏（logo、版本胶囊、右侧来源）→ 左目录 + 正文 + 右大纲。正文依次是面包屑、h1、导语、出处提示框、「给谁看」参数表、「主线」步骤条（每步一张键值表加 168px 缩略图）、tip 提示框、上一页 / 下一页翻页卡、更新日期。
- 内容页：面包屑、h1、导语、元信息行；然后每个小节一个 h2：目标（warn + note 提示框 + 表格）、先行判断（编号列表）、设计决策（三列表格，右列标签跳到提示词段落）、骨架公式（深色代码块 + warn 提示框）、提示词（原文与批注左右并排）、演示、产出范本（卡片 + 数字条 + 分组目录），最后是翻页卡。
- 宽 1180px 以下：隐藏右侧大纲，左目录收到 220px。
- 宽 820px 以下：顶栏 50px 高、不再吸顶；隐藏左目录；大纲变成正文上方的灰底框、横排换行；所有左右并排（缩略图、产出卡、提示词批注、演示三栏）收成单列；数字条 5 列变 2 列，翻页卡 2 列变 1 列。

## 关键组件

| 构件 | 类名 | 样子 | 什么时候用 |
|---|---|---|---|
| 顶栏 | `.dc-top` | 56px 高，白色 .94 透明加模糊，底部 1px 线；左边 logo 和等宽版本胶囊 `.dc-ver` | 每页 |
| 左目录 | `.dc-nav` | 吸顶，分组名小号粗字，条目挂在 1px 竖线上；当前项青绿、加粗、2px 左线；未展开项灰色带斜体注记 | 每页 |
| 本页大纲 | `.dc-otl` | 13px 灰字列表，第一项青绿 | 每页，列出本页 h2 |
| 章节标题 | `.dc-h2` + `.dc-anc` | 22px 黑字，悬停出现 `#` | 每个小节 |
| 提示框 | `.dc-call` / `.dc-call-warn` / `.dc-call-tip` | 10px 圆角，浅底加同色系描边，左侧 16px 线性图标；默认蓝色说明 | 出处、现状、建议、“缺一块会怎样” |
| 参数表 | `.dc-props` / `.dc-prop` / `.dc-type` | 青绿 code 键名 + 灰色等宽类型，下一行说明，行间 1px 线 | 读者、目标这类键值说明 |
| 步骤条 | `.dc-steps` / `.dc-step` / `.dc-step-n` | 28px 圆形编号，竖线连接；`.is-on` 编号变黑底白字 | 主线、流程 |
| 键值表 | `.dc-kv` | 10px 圆角框，左 96px 灰色键名 | 步骤和产出卡里的元信息 |
| 表格 | `.dc-tbl`（`.dc-dect`、`.dc-gt`） | 10px 圆角外框，`--soft` 表头 12.5px 粗字 | 输入产出、设计决策、图谱 |
| 段落标签 | `.dc-tag` | 青绿等宽字，`--acct` 浅底，6px 圆角，点击跳转 | 表格里指向提示词段落 |
| 编号列表 | `.dc-jl` | 青绿等宽编号 + 粗体判断 + 正文说明 | 先行判断 |
| 骨架公式 | `.dc-fxc` | 深色 10px 圆角块，等宽 14px，结果用 `#7FD8C0` | 一行公式 |
| 提示词对照 | `.dc-code` / `.dc-seg` / `.dc-seg-n` / `.dc-badge` / `.dc-key` | 深色代码区带文件名栏和复制按钮；每段左边带行号原文，右边 264px 白底批注 | 需要逐段解释的文本 |
| 演示框 | `.dc-frame` / `.dc-st6` / `.dc-panes` / `.dc-pane` | `--soft` 外框，顶部 6 步进度，白色画布分三栏 | 真实业务过程演示 |
| 产出卡 | `.dc-card` | 左 240px 缩略图，右侧标题、键值表、`.dc-link` | 展示一份产出 |
| 数字条 | `.dc-nums` | 5 列等宽数字 22px，列间 1px 线；重点项红色 | 关键数据 |
| 分组目录 | `.dc-toc` | 分组标题 + 挂在竖线上的三列条目（编号 / 章节名 / 说明） | 产出的章节结构 |
| 翻页 | `.dc-pager` / `.dc-pg` | 两张 10px 圆角卡，下一页右对齐，悬停描边变青绿 | 每页底部，后接 `.dc-upd` |

## 这个风格特有的禁区

1. 不放大标题。h1 34px 就是上限，不做超大编号、首屏色带或渐变背景；一放大就成了落地页。
2. 不加第二种强调色。青绿只做标记，不做标题色和大面积底色；蓝和琥珀离开提示框就不能用。
3. 深色只给代码。不要做深色整带、深色卡片或深色首屏。
4. 提示框只表达语义（说明 / 风险 / 建议），不当卡片排版用；连续堆三个以上就成了色块墙。
5. 不改三栏骨架：正文最宽 760px，左目录和右大纲保留；正文铺满全宽就失去文档感。
6. 不加投影，圆角不超过 12px。
