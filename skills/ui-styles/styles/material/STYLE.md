# Material 层级（material）

一句话：照 Material 3 做的浅色页面。用一套青色种子生成的色调表面（五级容器色）分出层级，再叠一到三级高程阴影；胶囊按钮、筛选标签、导航轨道、悬浮操作按钮都按 M3 规格，批注做成可展开卡片。

参考页面：[reference.html](reference.html)（三步法样张，首页 + 内容页；截图是灰色占位）。CSS 规则以 `.st-34` 开头。动手前先通读它的 CSS 和 `TPL[34]` 模板，组件照着用，不要凭印象重写。

## 气质

- 规整、友好、有秩序：每个元素都有固定的形状档、颜色角色和高程档，看得出是一套系统。
- 层级先靠底色深浅（白卡浮在浅青灰上），再靠阴影；标题用 400 常规字重，不靠加粗。
- 大块用 28px 圆角，小件用全圆胶囊，整体偏圆润。

## 适合 / 不适合

适合：
- 产品功能说明、帮助中心、操作指南：读者熟悉安卓 / Google 产品的交互。
- 有多个章节、要来回跳的内容页：左侧导航轨道很顺手。
- 需要筛选、展开、切换的轻交互说明页。

不适合：
- 想要强烈品牌个性的落地页：M3 的辨识度属于 Google。
- 信息密度很高的数据页（用 data-table）：72px 一行的列表太松。
- 编辑感、印刷感的长文专题（用 hairline、swiss-grid）。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  /* 底色 / 表面：五级容器色，从白到深 */
  --bg:#F5FAFB;   /* 页面底、应用栏、描边卡底 */
  --s0:#FFFFFF;   /* 最高层：被选中的卡、列表容器、演示当前面板、待办卡 */
  --s1:#EFF5F6;   /* 首屏和标题区大块、未选中的环节卡、代码底 */
  --s2:#E9EFF0;   /* 提示词行、演示面板、数字格 */
  --s3:#E3E9EA;   /* 「现状」实心卡、列表分隔线 */
  --s4:#DEE3E5;   /* 演示聊天里的时间跳转小条 */
  /* 文字 */
  --on:#171D1E;   /* 标题、正文 */
  --onv:#3F484A;  /* 次要文字、说明、导航轨道未选中项 */
  /* 线 */
  --ol:#6F797A;   /* 分段按钮、筛选标签的描边 */
  --olv:#BFC8CA;  /* 辅助标签、描边卡、步骤圆圈的浅描边 */
  /* 强调色：每种容器色都配一种「容器上的字色」，成对使用 */
  --pri:#006874;  --onpri:#FFFFFF;  --pric:#A5EEFA; --onpric:#001F24;  /* 主色：实心按钮、链接、进度 */
  --sec:#4A6267;  --secc:#CDE7EC;   --onsecc:#051F23;                  /* 次色：色调按钮、选中态、输入标签 */
  --ter:#545D7E;  --terc:#DBE1FF;   --onterc:#101A37;                  /* 第三色：引用块、序号头像、{{槽位}} */
  --inv:#2B3133;  --oninv:#ECF2F3;                                     /* 反色：snackbar */
  /* 状态 */
  --err:#BA1A1A;  --errc:#FFDAD6;   --onerrc:#410002;                  /* 错误：缺失项、P0、警示数字 */
  --pri-hover:#127784;                /* 实心按钮悬停 */
  --state:rgba(23,29,30,.08);         /* 悬停状态层 */
  --mark:#FFDF92; --onmark:#261A00;   /* 演示里被识别出的词 */
  /* 高程 */
  --e1:0 1px 2px rgba(0,0,0,.3),0 1px 3px 1px rgba(0,0,0,.15);
  --e2:0 1px 2px rgba(0,0,0,.3),0 2px 6px 2px rgba(0,0,0,.15);
  --e3:0 4px 8px 3px rgba(0,0,0,.15),0 1px 3px rgba(0,0,0,.3);
}
```

- 颜色按角色成对用：`--pric` 底上的字用 `--onpric`，`--secc` 配 `--onsecc`，`--terc` 配 `--onterc`，`--errc` 配 `--onerrc`。不要把主色 `#006874` 字放在 `#A5EEFA` 上。
- 主色 `#006874` 只给每屏最重要的一个动作（实心按钮、悬浮按钮）和链接、进度。选中态用次色容器 `#CDE7EC`，不用主色。
- 错误色只给真实的缺失和风险：公式的「缺一块」卡、P0 小标、产出数字里的警示格。
- 悬停一律叠 `rgba(23,29,30,.08)` 状态层，列表行悬停用 `rgba(23,29,30,.04)`，不换底色。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;700&family=JetBrains+Mono:wght@400;700&family=Roboto:wght@400;500;700&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 标题 | Roboto + Noto Sans SC | 一律 400：h1 52px / 1.18、`letter-spacing:-.01em`；h2 32px / 40px；卡片 h3 和应用栏标题 22px / 28px；数字 36px / 44px |
| 正文 | Roboto + Noto Sans SC | 根字号 16px / 1.5、`letter-spacing:.01em`；副标题 18px / 1.6；实心卡正文 17px / 1.6；列表主行 16px / 24px，次行 14px / 20px |
| 标签、按钮 | Roboto | 500：按钮 14px；小标题 `.m3-ov` 12px、`letter-spacing:.06em`；导航轨道 12px |
| 提示词原文、代码 | JetBrains Mono | 13px / 1.8 |

`--f-m` 里写的第一顺位是 Roboto Mono，但参考页没加载它，实际显示的是 JetBrains Mono；照参考页只加载 JetBrains Mono 即可。首屏引用的大引号用 Georgia 72px。

## 标题

- 首屏 h1：52px、400、`line-height:1.18`，放在 `--s1` 底、28px 圆角、48px 内边距的大块 `.m3-hl` 里；上方 12px 小标题 `.m3-ov`，下方 18px 灰色副标题，再下是一个实心按钮 + 一个色调按钮，最后一排辅助标签。窄屏 34px。
- 内容页 h1 同规格，放在 `.m3-chd` 大块里，关键词包在 `em` 里用主色 `#006874`。
- 章节标题 `.m3-sh`：h2 32px / 40px、400，下面一行 16px 灰色说明，整组下边距 16px。窄屏 26px / 34px。
- 列表分组标题 `.m3-sub2`：14px、500、主色字，下面一行 13px 灰字。

## 形状

- 形状档（参考 CSS 注释原话「形状 8/12/16/28/全圆」）：28px 给首屏大块、引用块、内容页标题区；16px 给提示词行、演示面板、数字格、悬浮按钮；12px 给卡片、列表容器、实心卡、描边卡、Logo、错误卡；8px 给辅助标签、筛选标签、输入标签、目录编号、代码块；全圆给按钮、分段按钮、头像。例外只在小件上：4px 给 snackbar、聊天气泡的尖角、行内高亮和 `{{槽位}}`；6px 给 P0 / NEXT 小标；进度条 2px。
- 高程只有三档：`--e1` 给列表容器、公式区、演示容器、产出封面卡（类名 `.m3-elev1`），以及收起的批注卡、聊天气泡、按钮悬停；`--e2` 给展开的批注卡、演示当前面板、运行中的技术步骤；`--e3` 给选中的环节卡、待办卡、悬浮按钮、snackbar。
- 描边：分段按钮和筛选标签 1px `#6F797A`；辅助标签和描边卡 1px `#BFC8CA`；列表项之间 1px `--s3`。
- 间距：内容最大宽 1280px，首页左右 24px；首页区块 `gap:48px`，内容页 `gap:56px`；栅格间距 12px 或 16px；列表项最小高 72px、`padding:10px 24px 10px 16px`。

## 版式

- 首页：64px 小型顶部应用栏 `.m3-bar`（40px 主色容器 Logo + 22px 标题 + 右侧一句小字）→ 首屏 `.m3-hero` 两列（1.5fr 标题块 / 1fr 第三色引用块 `.m3-quote`，等高）→「三个环节」：分段按钮 `.m3-seg` + 三列环节卡 `.m3-cards`，选中卡变白、加 `--e3`、上移 4px → 右下角悬浮按钮 `.m3-fab`。
- 内容页：应用栏左边是圆形返回按钮；下面 `.m3-shell` 两列：88px 导航轨道 `.m3-rail`（吸顶，图标 + 文字，选中项图标套 56×32 次色胶囊）+ 主栏。主栏依次：标题区 → 目标（两张实心卡 `.m3-g2` + 列表）→ 判断（三张描边卡 `.m3-g3`）→ 决策（筛选标签 + 列表）→ 公式（输入标签相加 = 主色结果，下面三张错误卡）→ 提示词（每段一行，右边批注卡）→ 演示（线性进度条 + 步骤 + 三面板 + snackbar）→ 产出（封面卡 + 五格数字 + 两列目录）。
- 窄屏：≤1100px 首屏变单列、演示变两栏、批注列收到 260px；≤820px 应用栏小字隐藏，h1 34px，分段按钮撑满整宽，环节卡只显示选中的那张（分段按钮变成切换标签）；导航轨道变成应用栏下方一排横向滑动的描边小标签（32px 高、8px 圆角）；所有栅格变单列，列表右侧附属换到下一行。

|---|---|---|---|
| 按钮与辅助标签 | `.m3-filled` / `.m3-tonal` / `.m3-ac` | 按钮 40px 全圆，实心是主色底白字，色调是次色容器底；辅助标签 `.m3-ac` 32px、8px 圆角、1px 浅描边 | 一屏一个实心按钮；次要动作用色调；附加信息用辅助标签 |
| 分段按钮 | `.m3-seg` | 1px 描边全圆条，选中段次色底并出现勾 | 在几个并列对象间切换 |
| 环节卡 | `.m3-card` + `.m3-media` + `.m3-cb` | 12px 圆角，上图下文；未选中 `--s1` 底，选中 `.on` 白底 + `--e3` + 上移 4px | 首页并列的几个入口 |
| 悬浮操作按钮 | `.m3-fab` | 56px 高、16px 圆角、主色容器底、`--e3`，固定在右下角 | 首页的唯一主动作 |
| 导航轨道 | `.m3-rail` | 88px 竖栏，图标在 56×32 胶囊里，下面 12px 文字；选中项次色胶囊 | 内容页章节导航 |
| 实心卡 / 描边卡 | `.m3-filledc` / `.m3-outc` | 实心 `--s3` 底，`.pri` 为主色容器；描边卡 1px 浅描边 + 40px 序号块 | 现状与目标对照；几条并列判断 |
| 列表 | `.m3-list` + `.m3-li` | 白底 12px 圆角 + `--e1`；行最小高 72px，前导头像 / 两行文字 / 尾部标签 | 交付关系、决策、数据流、目录 |
| 筛选标签 | `.m3-flt` | 32px、8px 圆角、1px 描边；选中后次色底，左侧出现勾 | 按段落筛列表 |
| 可展开批注卡 | `.m3-xc` + `.m3-xh` + `.m3-xp` + `.m3-xb` | 白卡 + `--e1`；头部序号头像、段名、一句摘要、下箭头；收起时两行预览，展开后全文 + `--e2`，箭头转 180° | 提示词每段的批注 |
| 错误卡 | `.m3-err` | 错误容器色底，小标题用错误色 | 「缺一块会怎样」 |
| 线性进度 + snackbar | `.m3-prog` / `.m3-snack` | 4px 高进度条；反色底 4px 圆角提示条 | 演示进度；「已写回」反馈 |

交互（都在 `TPL[34].init` 里）：
- **分段按钮切换环节卡**（`if(p==='home')` 分支）：点 `[data-st]` 设 `aria-selected`，并给相同编号的 `[data-sc]` 卡加 `.on`。宽屏是「选中的卡浮起来」，窄屏是「只显示选中的卡」。
- **筛选标签**（`/* 筛选标签 */`）：`.m3-flt` 多选，切换 `aria-pressed`；有选中时只显示 `data-dk` 在选中集合里的列表行，全部取消则全显示。
- **可展开批注卡**（`/* 可展开批注卡 */`）：点 `.m3-xh` 给 `.m3-xc` 切换 `.open` 和 `aria-expanded`。标了「最关键的一句」的段落默认展开。
- **跳到段落时展开批注**（`/* 跳到段落时展开批注 */`）：点决策列表里的链接标签（`data-seg`），通用行为负责滚动并给 `.m3-sg` 加 `.flash`（3px 主色外框），这里再把那段的批注卡打开。
- **导航轨道跟随滚动**（`/* 导航轨道跟随滚动 */`）：滚过哪一节，对应轨道项加 `.on`。
- **演示进度条**（`/* 演示进度条 */`）：用 `MutationObserver` 监听演示根节点的 `data-k`，进度条宽度 = `k × 10%`。

## 这个风格特有的禁区

1. **层级先用底色，不先用阴影。** 先在 `--s0`–`--s4` 和三种容器色里选，再决定要不要 `--e1`–`--e3`；不要自己写新阴影，也不要每张卡都加阴影。
2. **颜色不拆对。** 容器色必须配它的 on 色。随手把主色字放到彩色底上，就不再是 M3。
3. **标题不加粗。** h1、h2、卡片标题都是 400；只有按钮、标签、小标题用 500。
4. **形状档不加新值。** 只用 8 / 12 / 16 / 28 / 全圆（加上上面列出的小件例外）；6px、10px、20px 这类中间值会让整页失去系统感。
5. **主色不泛滥。** 一屏只有一个实心主色按钮；悬浮按钮全页一个，只放在首页；选中态用次色容器。
6. **导航轨道窄屏要变形。** 88px 竖栏在手机上必须变成横向胶囊条，不能保留左栏把正文挤窄。
