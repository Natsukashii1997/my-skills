# 数据表格（data-table）

一句话：像 Airtable 的一张数据库视图。白底、冷灰 1px 网格线、13–14px 紧凑字号，表格本身就是页面主体；彩色标签只表达状态和分类，蓝色只表达选中和链接。

参考页面：[reference.html](reference.html)（三步法样张，首页 + 内容页；截图是灰色占位）。CSS 规则以 `.st-31` 开头。动手前先通读它的 CSS 和 `TPL[31]` 模板，组件照着用，不要凭印象重写。

## 气质

- 克制、工整，读起来像在查一份数据，不像在读文章。
- 信息都拆成「记录 · 字段 · 值」：一行一件事，一列一个属性，长段落尽量变成表格里的一格。
- 层级靠表头灰底、网格线和字重区分，不靠大字号和色块。

## 适合 / 不适合

适合：
- 方案对比、需求清单、决策记录：每条有固定的几个属性，读者要排序、筛选、逐条看。
- 项目进度、交付排期、任务分派：有状态、日期、负责人的列表。
- 报告目录、知识条目索引：需要分组、折叠、按编号找。

不适合：
- 讲一个观点或一段故事的专题页（用 hairline、poster 这类）。
- 以大图、品牌氛围为主的首页。
- 条目少于 3 条、属性少于 3 个的内容：做成表格反而空。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  /* 底色 / 表面 */
  --bg:#FFFFFF;        /* 页面、单元格、记录卡、视图容器 */
  --bg2:#F7F8FA;       /* 表头、视图条、记录卡标题栏、底部汇总栏 */
  --bg3:#F1F3F6;       /* 按钮、标签页悬停 */
  --row-hover:#FAFBFC; /* 表格行悬停 */
  --row-open:#FBFCFD;  /* 展开行底色、提示词批注列、公式结果栏 */
  /* 文字 */
  --ink:#181D26;       /* 标题、主键列、单元格重点值 */
  --fg:#3B4250;        /* 正文、普通单元格 */
  --mut:#646B79;       /* 表头文字、字段名、记录数、说明句 */
  --ter:#959CA8;       /* 行号、面包屑分隔符、等待态 */
  /* 线 */
  --line:#E1E4EA;      /* 单元格网格线、字段分隔 */
  --line2:#CDD2DA;     /* 视图外框、首列冻结的右边线、视图条下边线 */
  /* 强调色（只有一种蓝） */
  --blue:#1B61C9;      /* 当前标签页、排序箭头、公式引用、演示当前步 */
  --bluet:#EAF1FD;     /* 上面这些的浅底 */
  --blue-edge:#BFD3F6; /* 选中筛选按钮、展开按钮的描边 */
  /* 分类标签：8 对「底 / 字」，类名 .dt-bl 等 */
  --chip-bl:#D3E3FF; --chip-bl-fg:#0F3E8C;  --chip-cy:#CDF1F4; --chip-cy-fg:#0B5560;
  --chip-pu:#E7DEFE; --chip-pu-fg:#47279A;  --chip-gn:#D3F2CB; --chip-gn-fg:#1E5A16;
  --chip-ye:#FFEAB6; --chip-ye-fg:#664700;  --chip-or:#FFE1CC; --chip-or-fg:#853806;
  --chip-rd:#FFD9DF; --chip-rd-fg:#8A1E33;  --chip-gy:#E8EAEE; --chip-gy-fg:#3B4250;
  /* 状态 */
  --flash:#FFF8E1;     /* 跳到提示词段落后整行闪一下 */
  --mark-line:#E0A800; /* 演示里高亮词的下划线（底色用 #FFEAB6） */
  --hot-bg:#FFF4F5; --hot:#B4233F; /* 汇总数字里需要警示的那一格 */
  --writeback:#4CA83A; /* 演示里「字段已写回」的左边线 */
  --ph:#8A1E33; --ph-bg:#FFF0F2;   /* 提示词里的 {{槽位}} */
  --btn-hover:#2C3341; /* 深色主按钮悬停 */
}
```

- `--ter` `#959CA8` 在白底上只有 2.76:1，低于 4.5:1：只给行号、分隔符、等待态这类不用读的标记；要读的小字最浅用 `--mut` `#646B79`（5.36:1）。参考页底部汇总栏的前缀「汇总」（`.dt-foot span`）也用了它，新页面改用 `--mut`。
- 页面只有一种强调色 `#1B61C9`。它只出现在：当前标签页、被排序的列、选中的筛选、公式引用、演示的当前步。不要拿它做大面积底色或标题色（内容页 h1 的 `em` 关键词除外）。
- 主按钮 `.dt-pri` 和复制按钮是深色 `#181D26` 实底白字，不是蓝色。
- 8 对标签色按含义分配，一个含义全页固定一种颜色：例如「本页展开」用绿 `.dt-gn`，「仅预览」用灰 `.dt-gy`，「缺失 / P0」用红 `.dt-rd`。
- 红色 `.dt-rd` 只给缺失和 P0，其他 7 种按分类分配。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;500;700&family=IBM+Plex+Mono:wght@400;500;600&family=Hanken+Grotesk:wght@400;500;600;700&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 标题、正文、表格 | Hanken Grotesk + Noto Sans SC | 根字号 14px / 1.55；表格 13.5px；表头 12.5px、500、灰 `#646B79`；主键列标题 14.5px、600 |
| 数字、日期、行号、公式、提示词原文 | IBM Plex Mono | 日期和数字 12.5px（`.dt-num`）；行号 11.5px、`#959CA8`；公式 15px / 2.2；提示词原文 12.5px / 1.75 |
| 小标签 | Hanken Grotesk | 标签 12.5px、500；底部汇总栏前缀 11.5px、600、大写、`letter-spacing:.06em` |

全页 `font-variant-numeric:tabular-nums`，数字列对齐。

## 标题

- 首屏 h1：44px、`line-height:1.15`、500 字重、`letter-spacing:-.01em`，颜色 `#181D26`；上方 13px 灰色小标题 `.dt-eb`，下方 18px 副标题 `.dt-sub`，里面的加粗用 600。内容页 h1 48px，关键词包在 `em` 里变蓝。窄屏两者都收到 32px。
- 章节标题 `.dt-sh`：h2 24px、500，右边同一基线接一句 14px 灰色说明。不加编号、不加色条。
- 区块标题就是视图条 `.dt-vb`：左边网格图标（蓝）+ 13.5px 粗体视图名，中间放筛选，最右边是「N 条记录」。每张表都有一条。

## 形状

- 圆角：视图和记录卡 10px；视图里嵌套的字段卡、待办卡、主按钮 8px；左上角品牌方块和复制按钮 7px；标签页、筛选按钮、演示按钮 6px；展开按钮、关联标签 5px；展开详情和附件里的大图 6px；表格里的小缩略图、公式引用、关键段标记 4px；分类标签全圆 999px。
- 描边：视图外框 `1px solid` `#CDD2DA`，单元格网格线 `#E1E4EA`；首列冻结时右边线加深到 `#CDD2DA`，作为冻结的提示。
- 阴影只有两档，只给「浮起来」的东西：记录卡 `0 1px 2px rgba(24,29,38,.05),0 4px 14px rgba(24,29,38,.05)`；缩略图和演示里的待办卡 `0 2px 10px rgba(24,29,38,.08)`。表格视图本身不加阴影。
- 间距：单元格 `padding:9px 12px`，表头 `7px 12px`；内容区 `padding-block:40px 112px`，区块之间 `gap:40px`。

## 版式

- 外壳：吸顶应用栏 `.dt-bar`（最小高度 52px，底部 1px 线）：28px 深色方块图标 + 面包屑 + 标签页；下面是 1240px 内容区 `.dt-in`，左右 24px。
- 首页：首屏 `.dt-hd` 两列（左标题、右最宽 520px 的记录卡 `.dt-rec`，记录卡里是两列字段表 `.dt-fd`）；下面一张主表 `.dt-view`，带状态筛选、可排序列、行内展开和底部汇总栏 `.dt-foot`。
- 内容页：应用栏的标签页就是本页章节锚点，随滚动高亮。每节都是「`.dt-sh` 标题 + 一张视图」：目标用记录卡 + 交付关系表；判断用可排序表；决策用带段落筛选的表；公式用 `.dt-fxw`（左公式字段、右「缺一块会怎样」表）；提示词用四列行表；演示用 `.dt-dm`；产出用 `.dt-orec` + 五格汇总 `.dt-agg` + 分组目录表。
- 窄屏：≤1100px 首屏变单列、演示三栏变两栏；≤820px 左右边距 16px，字段表变单列，表格在 `.dt-sc` 里横向滑动、首列冻结（最小宽 150px），提示词表头隐藏、每行变成「行号 + 内容」两列，汇总格变两列。

## 关键组件

| 构件 | 类名 | 样子 | 什么时候用 |
|---|---|---|---|
| 视图 | `.dt-view` + `.dt-vb` + `.dt-sc` + `.dt-tb` | 10px 圆角外框；灰底视图条；表格白底网格线，表头灰底 | 页面主体，一节一张 |
| 可排序表头 | `th[data-sort]` + `.dt-ar` | 表头文字右边一对上下小三角，未排序 45% 透明；排序后变蓝、只留一个方向 | 有编号、日期、名称可比较的列 |
| 筛选组 | `.dt-fl` | 漏斗图标 + 标签名 + 一排 26px 小按钮，选中项浅蓝底蓝字蓝描边 | 按状态、分类只看一部分 |
| 冻结首列 | `.dt-fz` + `.dt-pk` | 首列 sticky、右边线加深；里面是展开按钮、行号、粗体标题和一行小字 | 每张主表的第一列 |
| 行内展开 | `.dt-x` + `.dt-xr` + `.dt-xd` | 24px 方形箭头按钮；展开后下面多一整行浅底详情：缩略图 / 字段卡 / 主按钮三栏 | 一行装不下的详情；只展开当前关心的那条 |
| 分类标签 | `.dt-chip` + `.dt-bl` 等 | 22px 高全圆小标签，8 种底色 | 状态、段落、槽位 |
| 关联标签 | `.dt-lk` | 浅蓝底、链接图标 + 被关联记录名 | 「输入来自上一条」这类关联字段 |
| 记录卡 | `.dt-rec` + `.dt-fd` | 带阴影的卡；标题栏灰底；字段两列网格，字段名 12px 灰、值 14px 黑 | 首屏「关于这页」、目标、产出 |
| 公式字段 | `.dt-fxe` + `.dt-ref` | 等宽字 `= {a} & {b}`，引用是浅蓝小块；底栏写「5 / 5 字段已填」 | 把一个结论写成几项之和 |
| 提示词行表 | `.dt-ptr` | 四列：行号 44px / 段落标签 112px / 原文 / 批注 300px；关键段批注加黄色 `.dt-key` | 逐段解释一份长文本 |
| 汇总格 | `.dt-agg` | 5 格灰底，28px 数字配 12px 口径；警示格 `.hot` 淡红底红字 | 关键数字 |
| 分组行 | `.dt-gp` + `.dt-gi` | 灰底整行按钮，箭头 + 粗体组名 + 章数；点开收起本组 | 目录、长清单分组 |
| 演示面板 | `.dt-dm` + `.dt-s6` + `.dt-stage` | 视图条放播放控件；6 格步骤条（完成绿圈、当前蓝底）；三栏面板，当前栏顶部 2px 蓝线；运行步骤 `.dt-run` 带「等待 / 运行中 / 完成」小胶囊 | 演示一条数据流过几个环节 |

交互（都在 `TPL[31].init` 里，按注释分段）：
- **排序**（`/* 排序 */`）：点 `th[data-sort]` 的按钮，按行上的 `data-v-<键>` 排；`data-type="n"` 按数字，其他按中文 `localeCompare`。再点一次反向。`aria-sort` 记录方向。排序时展开行 `.dt-xr` 跟着自己那一行走。
- **筛选**（`/* 筛选 */`）：点 `[data-f]` 按钮，`aria-pressed` 单选；按行上的 `data-fv` 显示或隐藏，`all` 显示全部；同时更新视图条的 `[data-cnt]` 记录数。被筛掉的行，展开行也一起隐藏。
- **行内展开**（`/* 行内展开 */`）：`[data-x]` 切换 `aria-expanded`，箭头转 90°（0.15s），下一行 `.dt-xr` 跟着显隐。
- **分组折叠**（`/* 分组折叠 */`）：`[data-grp]` 切换本 `tbody` 里所有 `.dt-gi` 行。
- **标签页跟随滚动**（`/* 顶部标签跟随滚动 */`）：滚动时把已滚过的最后一节对应的 `.dt-tabs [data-jump]` 设为 `.on`。
- 点决策表里的段落标签 `.dt-tag`（`data-seg`），由通用行为滚到提示词对应行并给 `.dt-ptr` 加 `.flash`。

## 这个风格特有的禁区

1. **不把内容做成卡片墙。** 这个风格的主体是表格。三张并排大卡、整屏色块、大段正文都会让它变成普通落地页。能拆成「行 × 列」的就拆。
2. **不放大字号、不加粗标题。** 表格 13–14.5px，h1 只用 500 字重。把表格字号调到 16px 或标题用 700，紧凑感就没了。
3. **标签色不当装饰。** 一个颜色对应一个含义，全页一致；不为「好看」给每列配不同颜色。
4. **蓝色不铺底。** `#1B61C9` 只标当前、选中、链接；按钮主色是深色 `#181D26`。
5. **宽表不压缩列。** 列宽靠 `.dt-wide`、`.dt-mid` 这类最小宽度撑开，在 `.dt-sc` 里横向滑动，首列冻结；不要为了塞进屏幕把列挤成多行碎字。
6. **排序、筛选、展开要真能用。** 表头出现排序箭头、出现筛选按钮，就必须接上对应 JS，并保证展开行跟随、记录数同步。
