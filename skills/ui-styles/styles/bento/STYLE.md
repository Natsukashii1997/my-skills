# 便当卡片（bento）

一句话：像产品发布页里的便当盒式信息格。浅灰底上排大小不一的圆角瓦片，一格只讲一件事，白瓦片和近黑瓦片穿插出节奏，交互只用一种蓝。

参考页面：[reference.html](reference.html)（三步法样张，首页 + 内容页；截图是灰色占位）。CSS 规则以 `.st-25` 开头。动手前先通读它的 CSS 和 `TPL[25]` 模板，组件照着用，不要凭印象重写。

## 气质

- 明快、有产品感，信息被切成一口一口。
- 每格一个主句，字大、字重 600、字距略收紧，读者扫一眼就能抓到要点。
- 没有线框和投影，瓦片之间只靠 16px 的灰缝分开。

## 适合 / 不适合

适合：
- 方案亮点、产品功能介绍、项目成果汇报，要点并列、彼此独立。
- 首页式的总览：几个数字、几条结论、几个入口放在一屏里。
- 给管理层看的一页式总结。

不适合：
- 需要连续阅读的长文、操作手册。
- 要点之间有强先后顺序或因果链，切成格子会断开逻辑。
- 数据密集的表格页、后台工具。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  /* 底色 / 表面 */
  --bg:#F5F5F7;            /* 页面底，也是白瓦片里的内层底（胶囊、方块、技术卡） */
  --tile:#FFFFFF;          /* 默认瓦片 */
  --dk:#1D1D1F;            /* 深瓦片 */
  --dk2:#2C2C2E;           /* 深瓦片里的内层（胶囊、按钮、步骤） */
  /* 文字 */
  --fg:#1D1D1F; --fg2:#424245; --mut:#6E6E73; --ter:#A1A1A6;
  --on-dk:#F5F5F7; --on-dk2:#D2D2D7;   /* 深瓦片上的标题 / 正文 */
  /* 线 */
  --line:#E5E5EA;          /* 只用在瓦片内部分隔 */
  /* 强调色：单一蓝 */
  --blue:#0071E3; --blue-light:#2997FF; --blue-tint:#E8F2FD;
  /* 状态 */
  --p0:#E3342F; --p0-on-dk:#FF6961;    /* 缺失、P0、重点数字 */
  --ok:#1D8A3A; --ok-tint:#E3F5E8;     /* 已写回、已复制 */
  --mark:#FFD60A;                      /* 演示中聊天关键词高亮 */
}
```

- `--ter` `#A1A1A6` 只放在深瓦片上（在 `#1D1D1F` 上 6.54:1）；放在浅底上只有 2.36:1。参考页脚注 `.bt-note2` 在浅底上用了它，新页面浅底上的小字最浅用 `--mut` `#6E6E73`（4.66:1）。
- 瓦片只有三种底：白 `#FFFFFF` 是默认；近黑 `#1D1D1F` 用于首屏、当前环节、“产出”格、演示大瓦片和重点数字；蓝实底 `#0071E3` 全页最多一块（参考页里是内容页的“这一步要做到”）。
- 深瓦片里的文字只用 `#F5F5F7`、`#D2D2D7`、`#A1A1A6`；需要强调时用浅蓝 `#2997FF`（首屏标题关键词、当前环节大编号）。
- 蓝 `#0071E3` 用在按钮、段落标签、占位符、演示当前步和当前技术卡。按钮悬停 `#0077ED`，按下 `#0058B0`；标签悬停 `#D6E8FC`。
- 红只表示缺失和优先级：白瓦片上用 `#E3342F`，深瓦片上用 `#FF6961`。
- 绿 `#1D8A3A` 只表示“已写回”“已复制”这类完成状态。
- 灰线 `#E5E5EA` 只在瓦片内部用（提示词分段、目录行、缩略图顶边），瓦片本身不加描边。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400;700&family=Geist+Mono:wght@400&display=swap">
```

主字体是系统字（`-apple-system`、`SF Pro Display` / `SF Pro Text`、`PingFang SC`），Noto Sans SC 和 Geist Mono 只是非苹果设备的后备。字重只用 400 和 600（中文后备落到 Noto Sans SC 700）。

| 角色 | 字体 | 用法 |
|---|---|---|
| 正文 | SF Pro Text / PingFang SC | 17px / 1.5，`letter-spacing:-.01em`，颜色 `#424245` |
| 大标题 | SF Pro Display / PingFang SC | 600；首屏 h1 56px / 1.08、`-.025em`；区块标题 40px / 1.1、`-.025em` |
| 瓦片主句 | 同上 | `.bt-big` 30px / 1.2、600、`-.02em`；`.bt-mid` 21px / 1.4、600、`-.015em`；环节名 28px、600 |
| 瓦片标签与说明 | SF Pro Text / PingFang SC | `.bt-cap` 14px、600、`#6E6E73`；`.bt-w` 15px / 1.5、`#6E6E73` |
| 数字 | SF Pro Display | 600；环节编号 56px / 1、`-.04em`；判断编号 44px；产出数字 36px、`-.03em`、tabular-nums |
| 等宽 | ui-monospace / SF Mono / Geist Mono | 提示词原文 13.5px / 1.75、`letter-spacing:0`；演示代码 12px |

## 标题

- 首屏 h1：`.bt-h1` 56px、600、`#F5F5F7`，放在深色首屏瓦片 `.bt-hero` 里（首页占 8 栏，最小高 400px，内容贴底，内边距 44px）；关键词用 `<em>` 变成浅蓝 `#2997FF`。下接 21px 导语，颜色 `#D2D2D7`。内容页首屏是 12 栏的 `.bt-chero`。窄屏 h1 依次缩到 44px、34px。
- 区块标题：`.bt-sh` 放在瓦片外面，h2 40px、600，下接 19px 灰色说明，上距 72px。窄屏 h2 30px。
- 瓦片内标题：14px 灰色 `.bt-cap` 小标签在上，主句（`.bt-big` 或 `.bt-mid`）在下。不再加第三级标题。

## 形状

- 圆角分层，外大内小：瓦片 22px（窄屏 20px）；演示内面板 18px；公式方块、公式结果条、批注 16px；技术卡、待办、空状态、写回提示 14px；缩略图浮层 12px；代码片段 10px。按钮、标签、胶囊、步骤 999px。
- 描边：瓦片不加描边。唯一的高亮框是演示当前栏 `box-shadow:0 0 0 3px var(--bluel)`。
- 阴影：没有投影。
- 间距：容器最宽 1080px，左右 28px；12 栏瓦片网格，缝 16px（窄屏 12px）；瓦片内边距 28px，首屏 44px，演示 32px，数字格 22px；瓦片内元素间距 10px。按钮高 36px。

## 版式

- 首页：第一排深色首屏 8 栏 + 引用 4 栏；第二排 4 + 4 + 4（给谁看 / 看完能 / 怎么串起来）；区块标题「三个环节」；三张环节瓦片各 4 栏，当前环节是深色，底部是贴边缩略图，上面压一条半透明白色浮层写产出名和日期。
- 内容页：12 栏深色首屏；每节一个区块标题加一组瓦片：目标 6 + 6（白 + 蓝），下面 4 + 4 + 4（最后一格深色）；判断 4 × 3；决策 4 × 6；公式 7 + 5；提示词 12 栏一整块；演示 12 栏深色大瓦片，下面 5 等分图谱；产出 7 栏截图 + 5 栏信息，5 等分数字，6 + 6 目录。
- 宽 900px 以下：5、7、8 栏瓦片占满整行。宽 820px 以下：4、6 栏也占满整行；5 等分变 2 列，最后一格跨 2 列；提示词批注移到原文下方；演示三栏收成单列，步骤 6 列变 2 列。

## 这个风格特有的禁区

1. 一格只放一件事：一个判断、一个数字、一段批注。把一段长文或多个要点塞进一块瓦片，便当就成了普通卡片列表。
2. 不加投影、描边和渐变。瓦片只靠 `#F5F5F7` 底上的 16px 缝分开。
3. 深色瓦片要少而有理由（首屏、当前、产出、演示、重点数字），不要整排全深或棋盘式交替；蓝实底瓦片全页最多一块。
4. 每一排的栏数加起来等于 12，同排瓦片等高，不留空洞。
5. 区块标题放在瓦片外面，不做成一块“标题瓦片”。
6. 圆角外大内小（22 → 18 → 16 → 14）。内外同圆角或改成直角，都会失去便当盒的层次。
