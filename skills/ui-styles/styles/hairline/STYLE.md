# 细线（hairline）

一句话：**像精心打磨的产品专题页，不像文档。** 用细线和留白分层，用超大字号和编号建立节奏，用一种识别色串起一条主线，用真实业务过程的演示代替装饰动效。

参考页面：[reference.html](reference.html)（「AI 落地三步法」第八版，2026-11-05；截图已换成灰色占位）。写新页面前先通读它的 CSS 和一个演示的 JS（`Demo(root,cfg)`），组件照着用，不要凭印象重写。

## 气质

冷灰底、1px 细线分隔、方角无阴影、超大粗黑标题与 Archivo 大编号；每条主线一种识别色；演示放进深色全宽带里的浅色应用窗口。整页只有浅色一套。

## 适合 / 不适合

- 适合：方法论讲解、方案讲解、流程复盘、专题说明；有一条能数出段数的主线（例如「三个环节 · 三套提示词 · 三份产出」）的页面。没指定风格时默认用它。
- 不适合：以筛选、排序为主的数据页（用数据表格）；手册式多页文档（用文档站）；要深色观感的产品页（用精密暗色）。

## 动手前先定三件事

1. **主线有几段**：首屏下方用主线骨架 `.spine` 画出来，后面每章一一对应，每段一种识别色。
2. **每段演示什么过程**：每章最多一个演示，演示带 band / panel 换着用。
3. **哪些内容会重复**：按 SKILL.md 共用底线第 2 条先删掉。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  --bg:#F3F4F6; --surface:#FFFFFF; --surface2:#FAFAFB; --ink:#101318; --ink2:#434A55; --ink3:#5F6672; --rule:#D7DAE0; --rule2:#E6E8EC;
  --ink4:#7A818C;   /* 只给 32px 以上的大字做细体对比，见下文例外 */
  --dark:#15181D; --dark2:#1D2128; --dark3:#262B33; --darkrule:#2E343D; --dink:#ECEEF2; --dink2:#A7AEBA; --dink3:#8D95A2;
  --s1:#DD5129; --s1t:#FBE8E1; --s1d:#AE3714;   /* 朱红：主线第 1 段 */
  --s2:#2D53D2; --s2t:#E6ECFB; --s2d:#1D3BA3;   /* 钴蓝：第 2 段 */
  --s3:#0A8470; --s3t:#DBF0EA; --s3d:#05604F;   /* 青绿：第 3 段 */
  --bad:#C8331B; --badt:#FCE9E5; --badd:#A32A16; /* 状态：异常 主色 / 浅底 / 深色字 */
  --cur:#F2F4F7;                                 /* 状态：当前行、选中行的底 */
  --c:var(--ink); --ct:var(--rule2); --cd:var(--ink);   /* 当前段的 主色 / 浅底 / 深色字 */
  --ease:cubic-bezier(.22,.7,.2,1);
  --w:1240px; --g:40px;
}
.s1{--c:var(--s1);--ct:var(--s1t);--cd:var(--s1d)}  /* .s2 .s3 同理；组件一律用 --c/--ct/--cd */
```

- 识别色只有三种用法：**主色**（编号、顶线、按钮、当前态）、**浅底**（标签、占位符、高亮块）、**深色字**（浅底上的文字、小号彩色字）。小号文字不用主色，用深色版。
- 主线超过 3 段时，再加的颜色要同等饱和度、明显不同色相，并用同样的三级派生。
- **状态色**和识别色分开用：异常（超期、跌幅超阈值、P0）用 `--bad` 做标签实底或 3px 顶线，异常行底用 `--badt`，浅底上的红字用 `--badd`（6.2:1）；当前行、选中行用 `--cur` 做底，左侧加 2px `--c` 竖线。不要拿朱红 `--s1` 当异常色：它是主线第 1 段的身份色。
- 只做浅色一套，这是有意为之。`body` 写死 `background:#F3F4F6`，颜色全部明确写出。
- 深色只出现在两处：演示带和收尾的「下一步」条。深色区里的文字用 `--dink*`。
- 辅助小字最浅用 `--ink3` `#5F6672`（在 #F3F4F6 上对比度约 5.3:1），不能再浅。**唯一例外**是 `--ink4` `#7A818C`（3.6:1）：只用在 32px 以上的大字里做细体对比（首屏 h1 的细体半句、大号删除线），够大字的 3:1，不能用于正文和小字。表格里表示「无」的占位符「—」按辅助小字算，用 `--ink3`。
- 灰底面板（批注栏、文件头、封面卡）用 `--surface2`。参考页面里另有几处历史遗留的零散灰（如 `#F7F8F9`、`#59606B`），新页面不要抄，一律换成上面的令牌。参考页里散写的 `#fff` 就是 `--surface`，新页面写 `var(--surface)`；应用窗口 `.win` 的黑描边是 1px `--ink`。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Archivo:wght@500;700;800&family=JetBrains+Mono:wght@400;500;700&family=Noto+Sans+SC:wght@400;500;700;900&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 正文、标题 | Noto Sans SC | 正文 16px / 1.75；标题 900 粗、`letter-spacing:-.015em`；首屏 h1 `clamp(42px,6.4vw,86px)`，同一标题里用一段 400 细体灰字（`--ink4` #7A818C，大字例外，见上）做对比 |
| 数字、编号 | Archivo 800 | 章节大编号 `clamp(110px,15vw,200px)`、`line-height:.78`、`letter-spacing:-.05em`；数字条 28–40px |
| 标签、代码、元信息 | JetBrains Mono | 11–12px，大写，`letter-spacing:.08em`；行号、时间、文件路径、状态码 |

全页开 `font-variant-numeric:tabular-nums`。

## 标题

- **首屏 h1**：Noto Sans SC 900，`clamp(42px,6.4vw,86px)`，`letter-spacing:-.015em`；同一标题里用一段 400 细体 `--ink4` 灰字做对比。
- **章节头** `.st-head`：Archivo 800 超大色编号 `clamp(110px,15vw,200px)` 配粗黑标题，标题里的关键词用当前段主色，底部 1px 黑线；`.rev` 让编号移到右边，章与章左右交替。
- **区块标题** `.blk-k`：16px 色短线 +「四字标签｜说明」，整行 21px、900；全页同级标题都用这一个格式，不加编号。

## 关键组件

每个构件在参考实现里都有完整的 HTML 和 CSS，类名照抄。

| 构件 | 类名 | 样子 | 什么时候用 |
|---|---|---|---|
| 顶栏 | `.top` | 56px 高，半透明冷灰加毛玻璃，左边是三色竖条加品牌字，右边是带编号的锚点导航 | 每页都要 |
| 首屏 | `.hero` | 40px 细网格底，往下渐隐；左边是超大标题和副标题，右边是 2px 黑顶线的引用块 | 每页都要 |
| 主线骨架 | `.spine` / `.sp-col` | N 列白卡，4px 色顶线，内部用细线分格，列间是黑色箭头；悬停时上移 3px、描边变主色 | 首屏下方，把主线画出来 |
| 核心思路 | `.idea` | 白底整带；左边是 h2，右边三列，顶上 2px 黑线、列间 1px 细线；每条配一个小视觉（标签、对照、链条） | 主线背后的逻辑，最多 3 条 |
| 章节头 | `.st-head` | 超大 Archivo 色编号配粗黑标题，标题里的关键词用主色，底部 1px 黑线；`.rev` 让编号移到右边 | 每段一章，左右交替 |
| 区块标题 | `.blk-k` + `.bk-t` + `.bk-d` | 16px 色短线，接四字标签（识别色），竖线分隔，再接一句说明（黑色），整行 21px、900 字重 | 章内分块。全页同级标题都用这一个构件，格式一律是「四字标签｜说明」 |
| 现状 → 目标 | `.goal` / `.g-row` | 两行同字号：「现状」灰色等宽小标签，写表层问题；中间是「↓ 所以」（箭头用识别色，「所以」是灰色小字）；「目标」用识别色标签，文字加粗，左侧加 3px 竖线，写深层目标 | 一步要解决什么。用标签、颜色和字重表达由表及里，不靠字号大小 |
| 输入 → 产出 | `.flow3` | 三格，最后一格是主色实底白字 | 说明这一步的对象、输入、产出，每章一处 |
| 方法三行 | `.method` / `.m-row` | 左侧 sticky 标签栏（A/B/C 加四字标题）；右侧三块依次是：判断三列 `.jdg` → 决策对照 `.dec-r`（每条判断配一个段落按钮 `.seg-tag`，点击跳到批注视图里对应段落并高亮）→ 骨架公式 `.fx`。尺寸、配色以参考实现为准 | 讲清“为什么这样做”，放在“怎么做”之前 |
| 批注视图 | `.rv` / `.seg` | 代码评审样式：左边是带行号的等宽正文，按段落拆分，`{{占位}}` 用浅底高亮，XML 标签行用浅灰小字；右边 340px 灰底批注，顶部写段落名，下面一句作用；关键段落左侧加主色边线，并打「最关键的一句」；顶部放复制按钮（复制原文） | 提示词、配置、规则这类需要逐段解释的文本 |
| 报告范本 | `.rep` | 封面卡 `.rc`（原页缩略图、标题与基本信息、打开原页）加分组目录 `.toc`（按逻辑分 3–4 段，每章一行：编号、章节名、核心句）；`.rev` 让封面换到右边。细节以参考实现为准 | 展示一份真实产出。用本页构件重画它的结构，原图只当封面缩略图 |
| 数字条 | `.nums` | 顶上 2px 黑线，5 列 Archivo 大数字配小字口径，重点数字用主色并带比例条 | 关键数据；每个数字都要写口径 |
| 窄链桥 | `.bridge` | 白底窄带，4 格横向链条，人工步骤用虚线框 | 两段之间有一个不由 AI 完成的中间步骤时 |
| 演示带 | `.blk.band.dark` / `.blk.panel.dark` | 深色区：band 横跨全宽、尺度最大，panel 收在内容宽度内；里面放浅色 `.win` 应用窗口（8px 圆角、1px `--ink` 描边） | 每段的演示；三段要换着用，不要都一样 |
| 接力卡 | `.ch3` / `.c3` | N 张竖卡：大编号、翻译方向、对象 / 输入 / 产出小字，底部是主色实底的“交给下一步”；卡之间放箭头，人工步骤用虚线框。参考页是三段，列宽写死为「卡 / 92px / 卡 / 56px / 卡」（92px 那列放人工步骤虚线框，56px 只放箭头）；段数不是 3 时，改成 N 张卡加 N−1 个连接列，每个连接按是否人工步骤选 92px 或 56px，不要直接套三段的网格 | 总结时把各段串起来 |
| 要素矩阵 | `.mx` | 行是要素（左列灰底），列是各段（顶部是识别色粗线），格子左侧有一道 3px 浅色边，最后一行放各段的公式；矩阵下面接一句粗体结论。参考页是三段四要素：`grid-template-columns:150px repeat(3,…)`、`grid-template-rows:repeat(6,auto)`（表头 + 4 个要素 + 公式行），`grid-auto-flow:column`，所以 HTML 按列写：先写整列要素名，再每段写一列。段数或要素数变了，把 3 改成段数、6 改成要素数加 2 | 提炼通用方法：每段在同几个问题上分别怎么填 |
| 切换示例 | `.mig` + `.sw-l` | 左边是竖排选项（选中项加粗、左侧加竖线），右边是灰底定义表 | 同一结构套到几个不同场景 |
| 前提三栏 | `.pre` | 顶部 2px 黑线；三栏之间用细线分隔，每栏依次是编号、粗体前提，以及一句灰色标签“不满足时”的调整办法 | 方法的适用条件 |
| 文件卡 | `.sk` | 仿文件头：三色小条加文件名；每行左边是等宽键名，右边是值（标签、分段流程） | 展示一份配置、skill 或规格的骨架 |
| 收尾 | `.next` + `.foot` | 深色条写一句下一步，下面两栏放来源和免责说明 | 每页都要 |

## 版式

- 区块之间用留白（区块 64px，章节 112–120px）和 1px 细线分隔。**不用卡片阴影，不用大圆角**：圆角只有应用窗口用 8px，按钮 2–3px。
- 各章区块顺序可以一致，但构图必须变化：演示的位置（前、中、后）、尺度（band 或 panel）、章节头方向（正或 `.rev`）至少换两样。三章完全同构就会像文档。
- 段落最多 3 行；能用构件表达的不写成段落。白底整带（`.idea`、`.bridge`、总结 `.sum`）和灰底交替出现，形成节奏。

## 演示控制器

细线的演示用参考页面里的 `Demo(root,cfg)`，行为要求见 SKILL.md「动效规则」。写法：

- `cfg.render(k,mode)` 按第 k 步画出整个画面，`total`、`delay` 定义步数和节奏，`modes` 支持 A/B 切换，模式切换放在 `.seg-sw`。
- `lock()` 遍历所有模式和所有步骤，取最大高度作为 min-height。
- 演示结束出现 `.dm-end` 结论句，带一条主色竖线。新出现的元素用 `.enter`（0.42s，上移 8px 并淡入）。

## 形状

- 方角。圆角只有两处：应用窗口 `.win` 8px，按钮和小标签 2–3px。
- 不用卡片阴影；层次靠 1px 细线（`--rule`、`--rule2`）、2px 黑顶线和 4px 色顶线。
- 区块之间 64px，章节之间 112–120px。

## 这个风格特有的禁区

1. 卡片阴影、大于 8px 的圆角、渐变背景。
2. 深色区出现在演示带和收尾条以外的地方；做深色版本。
3. 小号文字用识别色主色（要用深色字 `--s*d`）；拿 `--s1` 当异常色。
4. 三章完全同构：演示位置、band / panel、章节头方向至少换两样。
5. 放缩小的整屏截图：用本页构件重画结构，原图最多当封面缩略图。
