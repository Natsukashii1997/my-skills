# 荧光笔（marker）

一句话：浅灰底上两团静止的柔光，深墨标题左对齐，一支荧光笔只压住每个标题里的结论词；产品界面是主角，也是唯一带大投影的东西。

参考页面：[reference.html](reference.html)（组件总览 + 5 种页型，截图是灰色占位）。风格的 CSS 规则都以 `.mk-` 开头，按 A–I 分组编号（01–41）。动手前先通读它的 CSS 和要用的那种页型，组件照着用，不要凭印象重写。

参考页里这些是查看用外壳，不属于风格，不要抄进页面：顶部视图切换栏 `.sw`、视图容器 `.view`、组件总览每格的 `.kit-cell` 框和 `.how` 说明、色板 `.swatch`、字号行 `.type-row`、动效清单 `.lv` `.mlist`、主色切换按钮 `.sw-hl`，以及反例类 `.kit-bad-*`（CSS 末尾「以下是查看用外壳」之后的全部规则）；脚本里标了「查看用外壳」的主色切换和视图切换。看某种主色的效果：点切换栏右边的色块，或在地址后面写 `#视图-主色`（如 `#launch-mint`）。

## 气质

- 像一支产品发布视频的网页版：读者先看到产品界面在做什么，再读一句结论。
- 一页只有一种彩色，叫「主色」，从五种里选一种：黄（默认）、天蓝、珊瑚、薄荷、淡紫（见「主色」一节）。它不串主线、不当字色，只做底：标题里的荧光带、标签实底、短条、圆点、下划线。
- 层次来自三件事：浅底与白面的明度差、`--soft` 浅灰块或 1px 线、产品窗口的一档大投影。讲解内容是平的，产品界面是浮起来的。
- 标题都左对齐，写成结论句；高亮的词连起来读，就是这一页的结论。

## 适合 / 不适合

适合：
- 产品或工具的发布专题页、功能介绍页：产品窗口和演示当主视觉。
- 方法、skill、流程的讲解长页：步骤链、原文对照、场景卡。
- 复盘报告、方案对比评审：时间轴、KPI 格、对比矩阵、结论判定、行动项。
- 要导出成社媒长图或封面的一页内容。

不适合：
- 以筛选、排序为主的数据页：用数据表格。
- 给研发看的脚本、配置讲解：用终端。
- 多页手册、逐段对照的规范：用文档站。
- 要用几种识别色串起几段主线的方法论页：用细线。
- 要投到深色会议屏上的材料：这个风格只有浅色一套（反白段只是一页里的一段）。

## 色值令牌（照抄，不即兴调色）

```css
:root{
  color-scheme:light;
  /* 底与面 */
  --bg:#F6F7F9; --aur-cool:#DCE6F8; --aur-warm:#F6EBD8;
  --card:#FFFFFF; --soft:#F2F3F5; --line:#E3E6EB; --sand:#E2D7BF;
  /* 字 */
  --ink:#22262E; --ink2:#4B5260; --mut:#5E6571; --bar:#9AA1AD;
  /* 主色：一页只用一种，只做底。默认黄，另有天蓝、珊瑚、薄荷、淡紫（见下方 data-hl），新页面把选定那种的四个值写在这里 */
  --hl:#F5BC3B;        /* 标签实底、3px 下划、编号圆点、关键条形 */
  --hl-band:#F8D27E;   /* 标题荧光带（比实底浅一档，读起来像笔迹） */
  --hl-soft:#FCE9B4;   /* 正文荧光 */
  /* 状态：只表示状态，用在哪见 STYLE.md */
  --ok:#1F6E3E; --ok-t:#E6F4EA; --run:#2F67B8; --run-t:#E7EFFB;
  --ask:#8A5A0F; --ask-t:#FDF3E1; --ask-b:#EBC98A; --ask-bg:#FFFCF6;
  --bad:#A33A26; --bad-t:#FBEAE6;
  /* 反白段 */
  --inv-bg:#15171C; --inv-card:#1F232B; --inv-soft:#22262E; --inv-line:#2E333D; --inv-ink:#F3F4F6; --inv-ink2:#B9BEC8; --inv-hl:#7A5C16;
  /* 半透明面与占位 */
  --glass:rgba(255,255,255,.6); --glass2:rgba(255,255,255,.86); --sand-t:#FBF8F1; --ph2:#ECEDF0;
  /* 投影：只给产品界面和浮层 */
  --sh-chip:0 1px 2px rgba(30,40,60,.06),0 4px 12px -6px rgba(30,40,60,.14);
  --sh-win:0 28px 64px -28px rgba(30,40,60,.26),0 2px 6px rgba(30,40,60,.05);
  --sh-flat:0 1px 2px rgba(30,40,60,.06);
  /* 字体 */
  --f-head:"Inter Tight","Noto Sans SC","PingFang SC",system-ui,sans-serif;
  --f-sans:"Noto Sans SC","PingFang SC","Microsoft YaHei",system-ui,sans-serif;
  --f-mono:"JetBrains Mono","Noto Sans SC",ui-monospace,Menlo,monospace;
  --ease:cubic-bezier(.16,1,.3,1); --ease-draw:cubic-bezier(.65,0,.35,1);
}
/* 另外四种主色：结构和黄色一样，四个令牌一起换（--inv-hl 是反白段里的暗色带） */
:root[data-hl="sky"]   {--hl:#62BDF0;--hl-band:#A3D8F6;--hl-soft:#D6EDFB;--inv-hl:#1F5D85}
:root[data-hl="coral"] {--hl:#FF946B;--hl-band:#FFBEA3;--hl-soft:#FFE1D4;--inv-hl:#8E3A1C}
:root[data-hl="mint"]  {--hl:#92DDCF;--hl-band:#B1E7DD;--hl-soft:#D9F4EF;--inv-hl:#16695C}
:root[data-hl="violet"]{--hl:#B39DF5;--hl-band:#CFC2F9;--hl-soft:#E9E3FC;--inv-hl:#5940A6}
```

- 背景：`body` 写 `background:var(--bg)`，再用 `body::before`（`position:fixed`）叠两团径向柔光：左上 `--aur-cool`、右下 `--aur-warm`，写法照参考页。柔光是静止的，不动、不随滚动变。
- 白字一律写 `var(--card)`（就是 `#FFFFFF`），只压在 `--ink`、`--ok` 上。
- 对比度（实测）：`--ink2` 在 `--bg` 上 7.3:1；`--mut` 在 `--bg` 上 5.5:1，在 `--aur-cool` 最浅处 4.7:1，在 `--hl-band` 上只有 4.1:1，所以 `--mut` 小字不压在荧光带上。`--bar`（2.4:1）只用在线、条形、空勾选框、虚线这类不用读的标记上，不写字。五种主色的 `--hl` 在白底上只有 1.6–2.3:1，所以**主色永远不当字色**。
- 状态色 `--ok` `--run` `--ask` `--bad` 及其 `-t` 浅底只表示状态：状态标签 `.mk-st`、矩阵结论词 `.mk-yes` `.mk-no` `.mk-mid`、差异卡增删行、额度条超速、行动项完成勾、步骤清单的勾、提示条 `.mk-callout.warn` 的竖条。不拿来做标题色、正文强调、分节色或装饰。
- 反白段里荧光带换成主色的暗色版 `--inv-hl`（`--inv-ink` 在它上面 5.7–7.0:1），其他颜色换成 `--inv-*` 一组，写法照参考页 `.mk-invert`。

## 主色（五选一）

一页只用一种主色。五种的结构完全一样：`--hl` 实底、`--hl-band` 标题荧光带、`--hl-soft` 正文荧光、`--inv-hl` 反白段里的暗色带。组件只引用这四个令牌，换主色时组件一处不改；底色、柔光、字色、状态色五种都不变。

| 主色 | `data-hl` | `--hl` · `--hl-band` · `--hl-soft` · `--inv-hl` | 先推荐给什么内容 | 要留意 |
|---|---|---|---|---|
| 黄（默认） | `yellow` | `#F5BC3B` · `#F8D27E` · `#FCE9B4` · `#7A5C16` | 产品发布、功能介绍、讲解页；拿不准时 | 和「需要你回答」的琥珀同色系 |
| 天蓝 | `sky` | `#62BDF0` · `#A3D8F6` · `#D6EDFB` · `#1F5D85` | 技术方案、数据复盘、工程向的说明 | 和「运行中」的蓝、左上角冷色柔光同色系 |
| 珊瑚 | `coral` | `#FF946B` · `#FFBEA3` · `#FFE1D4` · `#8E3A1C` | 对外活动、招募、培训分享、热闹的发布 | 和「异常」的红同属暖色 |
| 薄荷 | `mint` | `#92DDCF` · `#B1E7DD` · `#D9F4EF` · `#16695C` | 流程改进、效率成果、工具上手指南 | 和「完成」的绿同属绿色系，但更偏青；五种里最淡（标题带和页面底色只差 1.28:1，常浩 11-15 照截图色调淡） |
| 淡紫 | `violet` | `#B39DF5` · `#CFC2F9` · `#E9E3FC` · `#5940A6` | 给管理层的报告、方案评审、策略和 AI 方向的讨论 | 荧光感最弱 |

对比度（实测）：深墨字压在 `--hl` 上 6.5–9.7:1（淡紫最低、薄荷最高），压在 `--hl-band` 上 9.2–11.1:1；反白段白字压在 `--inv-hl` 上 5.7–7.0:1。状态色撞色系的几种，状态标签照样用 `--ok` `--run` `--ask` `--bad`（深色字 + 浅底），主色只做高亮，不拿来表示状态，两者靠深浅分开。

**怎么选（每次用荧光笔都要走这一步）：**

1. 用户在请求里点名了主色（如「用薄荷」「蓝色那版」），就用那种，不再问。
2. 没点名：先读完要做的内容，按上表「先推荐给什么内容」挑一种，然后**停下来问用户**。问法：一句推荐加理由（理由要落到这份内容上，例如「这是给管理层的季度评审，推荐淡紫：正式、安静」），再列出全部五种、每种一句适合什么，请用户选。等用户回复后再开始做页面。
3. 内容同时像两类（例如对外发布的技术工具），推荐更贴近读者的那一类：读者是谁比内容是什么更重要。
4. 没有人能回答的场合（后台任务、定时任务、批量生成）：直接用推荐的那种，在答复里写明用了哪种、为什么，用户可以要求换。

**怎么写进页面：** 把选定那种的四个值写进页面 `:root` 的 `--hl`、`--hl-band`、`--hl-soft`、`--inv-hl`，其他令牌照抄。新页面不需要 `data-hl`，那是参考页切换主色用的。页面上不出现第二种主色，也不用五种以外的颜色当主色。

## 字体

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter+Tight:wght@600;700;800&family=Noto+Sans+SC:wght@400;500;700;800&family=JetBrains+Mono:wght@500;700;800&display=swap">
```

| 角色 | 字体 | 用法 |
|---|---|---|
| 标题 | Inter Tight 800，中文落到 Noto Sans SC | 字距随字号收紧：h1 `-.025em`、h2 `-.02em`、h3 `-.01em`；`text-wrap:balance` |
| 正文 | Noto Sans SC | 16px / 1.7，`--ink2`；导语 `.mk-lead` 17px、最宽 38em；卡片说明 15px，辅助 14px，注释 13px，标签 12px |
| 数字、版本、时间、代码 | JetBrains Mono 800 | 行内数字 `.mk-num`；含中文的标签不用等宽 |

全页开 `font-variant-numeric:tabular-nums`。

## 标题

- h1 `.mk-h1`：`clamp(38px,5vw,64px)`、行高 1.12、800。h2 `.mk-h2`：`clamp(28px,3.2vw,42px)`、行高 1.2。h3 `.mk-h3` 20px / 700，h4 `.mk-h4` 17px / 700。
- 标题左对齐，写成一句结论（「每一步勾完才往下」），不写成名词（「三个步骤」）。
- 中文标题按 400px 宽检查断行：不该拆开的词组用 `.nb`（`white-space:nowrap`）包住，例如 `五家 AI，<span class="nb">收进<span class="mk-hl">一条侧栏</span></span>`，免得折成「收 / 进」。`.nb` 里的字不超过 8 个汉字。
- 标题上方可以放编号眉题 `.mk-kicker`（白胶囊、主色圆点编号），间距 16px。**同一页同级的 h2 要么都有眉题，要么都没有。**
- 标题荧光 `.mk-hl`，规则见下一节。

## 高亮怎么用（这个风格的识别点）

| 类名 | 样子 | 用在哪 | 限量 |
|---|---|---|---|
| `.mk-hl` 标题荧光 | `--hl-band` 色带压在字的下半部，带厚 h1 `.36em`、h2 `.42em`、数字墙 `.34em`，`white-space:nowrap` | h1、h2、金句卡 blockquote、数字墙里的一个数字 | 每个 h1 / h2 / blockquote 最多 1 处；数字墙只高亮 1 个数 |
| `.mk-hl-soft` 正文荧光 | `--hl-soft` 盖住字的下半截 | 正文里的一句关键话 | 一段最多 1 处 |
| `.mk-ul` 下划荧光 | 深墨粗体，3px `--hl` 下划线，偏移 5px | 链接、按钮、菜单路径里的关键字 | — |
| `.mk-tag` 问题标签 | `--hl` 实底、深墨字、6px 圆角 | 痛点列表 `.mk-tags` 的每条前面；矩阵里的「推荐」 | 同组字数相同 |

判定标准（逐条可查）：
1. 每个 h1、h2、`.mk-quote blockquote` 里 `.mk-hl` 不超过 1 个；页面里 20px 以下的文字不用 `.mk-hl`（小字要强调用 `.mk-hl-soft` 或 `.mk-ul`）。
2. `.mk-hl` 包住的词不超过 8 个汉字（或等宽的字符），因为它不折行，窄屏 38px 的 h1 再长就会溢出。
3. 只读所有 `.mk-hl` 的词，能说出这一页的结论；高亮的是结论词，不是名词或修饰词。
4. 高亮词**不用斜体**，也不改字重、字色。
5. 任何地方不写 `color:var(--hl)`、`color:var(--hl-band)`、`color:var(--hl-soft)`；按钮底、整块卡片底、整句底都不用主色。

## 形状

- 圆角五级：6px 标签、状态、勾选框；10px 小件（时间戳、图标格、占位、通知条）；14px 卡片、面板、表格框；18px 产品窗口、命令面板、金句卡、结论判定；999px 胶囊（眉题、按钮、吸附目录）。
- 线：`--line` 1px，用 `box-shadow:inset 0 0 0 1px var(--line)` 或 `border`；问答、行动项、表格行用 1px 分隔线。
- 投影三档，**只能用在下面这些类上**：
  - `--sh-win`：产品窗口 `.mk-win`、命令面板 `.mk-cmd`、通知条 `.mk-toast`、金句卡 `.mk-quote`、社媒图外框 `.art`、任务卡悬停 `.mk-lift:hover`。
  - `--sh-chip`：小件和浮层：`.mk-kicker`、`.mk-time`、`.mk-feat i`、`.mk-step .n`、`.mk-trace .note`、`.mk-diff`、`.mk-stats`、`.mk-nav .in`、`.mk-cta`、`.art .row3 div`。
  - `--sh-flat`：产品界面内部的气泡 `.mk-msg`、任务卡 `.mk-task`。
- 讲解内容不加投影：面板 `.mk-panel`、痛点解法 `.mk-pair`、场景卡 `.mk-scene`、前后对比 `.mk-delta`、提示条 `.mk-callout`、代码块 `.mk-code`、表格 `.mk-table`、问答 `.mk-faq`、结论判定 `.mk-verdict`，只用 `--soft` 浅灰底或 1px 线。
- 产品窗口顶栏是三颗 `--line` 灰点加一条网址栏 `.url`，不用红黄绿三色灯。

## 版式

- 容器 `.mk-wrap` 最宽 1180px，左右 20px（带安全区）。12 栏网格 `.mk-grid`，列距 24px；常用跨 `.c7`+`.c5`、`.c5`+`.c7`、`.c4`+`.c8`、`.c6`+`.c6`、三张 `.c4`。860px 以下全部单栏；`.mk-flip` 在单栏时把最后一块（通常是标题组）提到前面。
- 节间距 `.mk-sec` 上 96px，节内子块 `.mk-sub` 上 64px；组件内 8 / 12 / 16px。最后一节或页脚下面留 96–110px。
- 每页开头一条吸附目录 `.mk-nav`（居中毛玻璃胶囊，当前章节下一道主色短线）；首屏是标题组（眉题、h1、导语、主行动）加一个主视觉（代码块、金句卡、产品窗口或数字条）。
- 两种版式限量用：
  - 全宽舞台 `.mk-stage`：左上标题和导语、右上时间戳加来源注，下面 `.floor` 铺满 12 栏的产品窗口或演示。**每页最多 2 次。**
  - 反白段 `.mk-invert`：一整段换近黑底，放在产品演示最强的那一段，给页面换一次节奏。**每页最多 1 次**，它在 `.mk-wrap` 外面铺满全宽。
- 五种页型（参考页各有一个视图，照着组织）：
  - 讲解长页 `#explain`：首屏 → 为什么（`.mk-pair` 三组）→ 步骤（`.mk-steps` 演示）→ 原文对照（舞台 + `.mk-trace`）→ 怎么用（三张 `.mk-scene`）→ 常见问题（`.mk-faq`）→ 收尾一句 + 主行动。
  - 发布专题页 `#launch`：首屏就是舞台（要点 `.mk-feats.sync` + 窗口演示，带镜头推近）→ 问题（`.mk-tags` + `.mk-pair` + `.mk-delta`）→ 单项功能（窗口 + 文字左右交替）→ 反白段演示 → 数字墙 → 收尾。
  - 复盘报告页 `#review`：来源注 + h1 + KPI 格 `.mk-stats.grid` → 时间轴演示 → 各轮结果（表格 + `.mk-delta`）→ 根因（`.mk-pair` + 差异卡）→ 下一步（`.mk-actions`）。
  - 对比评审页 `#compare`：h1 + 结论判定 `.mk-verdict` → 对比矩阵 `.mk-matrix` → 结论依据（`.mk-callout.warn` + `.mk-delta`）→ 行动项。
  - 社媒长图 / 封面 `#social`：`.art` 设计宽 1080，用 `cqw` 按容器缩放；封面 `.art.cover` 4:5，长图高度随内容。一张图一个标题高亮，数字条最多 3 项，字号不小于设计宽的 2.6%；没有演示、没有进场，荧光直接画满。
- 演示下方用 `.mk-democap` 写一句「示例数据」或数据来源；演示旁边可放来源注 `.mk-src`（时间戳 + 一句出处）。截图一律用 `.mk-ph` 灰色斜纹占位，配 `.mk-fig` 图注。

## 进场方式

荧光笔有自己的进场，满足 SKILL.md 第三节「风格自带进场」的全部条件。只有下面三种，别的都不做。

1. **标题荧光划出**（`.mk-hl`）
   - 隐藏态 `.mk-hl.mk-wait` 是 `background-size:0%`，去掉后色带从左往右划出：0.6s，曲线 `--ease-draw`。在 `.mk-r` 块里的再晚 0.35s，跟在块浮现后面。
   - 首屏的标题在载入 250ms 后划出；其余的在顶边进入视口 88% 以内时划出。字本身一直在，首屏不等动画也完整可读。
   - 组件总览格子里、社媒长图视图里的 `.mk-hl` 不参与，直接画满。
2. **块浮现**（`.mk-r`）
   - **每节最多 2 块**：标题组一块、主视觉一块。不拆到每张卡、每行字。
   - 隐藏态 `.mk-r.mk-wait` 是 `opacity:0` 加 `translateY(24px)`；出现时 0.7s、曲线 `--ease`，不错开、不加延迟。
   - 渲染后跑一次：顶边已在视口 92% 以内的直接显示，所以首屏从不隐藏。之后监听 `scroll`（`passive:true`），顶边进入视口 88% 以内时显示；键盘聚焦到还没出现的块（`focusin`）时立即显示。
   - 兜底：20 秒后全部显示。显示过的不再隐藏，往回滚也不重播。
3. **镜头推近**（只在演示里，`.zooming`）
   - 窗口框 `.mk-win` 不动，框内 `.body` 以当前那张卡为中心放大 1.05 倍（上限 1.06），其余卡加 `.mk-dim` 变到 45% 透明。
   - 顶栏 `.mk-win>.bar` 要写 `position:relative;z-index:1;background:var(--card)`，叠在缩放层上面；不然放大的内容会盖住顶栏下沿（1440 宽约 7px）。
   - 每段演示最多推近一次，只在一步里；下一步复原。

`prefers-reduced-motion: reduce` 时：脚本不加任何 `.mk-wait`，演示直接到最后一步、不推近；CSS 里所有过渡和动画关闭，荧光直接画满。

演示里的「生成中」`.mk-gen` 有一道从左到右的微光（`mk-shim`，1.4s 循环）。它只在演示里对方正在生成的那一步显示，下一步就 `hidden`，减少动态效果时没有；这是全页唯一允许的循环动画，不能挪到演示外面当装饰。

## 这个风格特有的禁区

1. 主色当字色、当按钮底、铺满整句或整张卡。主色只做小面积的底：荧光带、标签、短条、圆点、下划线。
2. 一页里混用两种主色，或用五种以外的颜色当主色（自己调一个「品牌色」）。要换主色就把四个令牌一起换成另一种。
3. 一个标题里高亮两处，或给 20px 以下的字加 `.mk-hl`；高亮名词、修饰词而不是结论词；高亮词用斜体。
4. 照搬视频分镜：标题居中、整块粗高亮（色带盖满整个字高）。标题一律左对齐，带厚照上面的比例。
5. 给讲解内容套投影卡。面板、对比、场景卡、提示条、表格只用 `--soft` 底或 1px 线；投影只用在「形状」里列出的类上。
6. 状态色拿去装饰：用绿色写标题、用红色分节、用蓝色做链接色。状态色只表示状态。
7. 把进场做大：每节浮现超过 2 块、卡片逐张浮现、加长时长或错开延迟、往回滚重播；做数字滚动计数、背景柔光漂移、阅读进度条、视差或任何随滚动连续变化的效果。
8. 超量：全宽舞台每页超过 2 次、反白段超过 1 次、数字墙超过 1 次、金句卡超过 2 张、结论判定超过 1 块、每屏主行动超过 1 个。
9. 产品窗口用红黄绿三色灯，或拿掉网址栏；截图直接放原图（一律用 `.mk-ph` 占位或用组件重画）。
10. 和柔光混用。柔光禁止渐变彩色背景和装饰性的黄色高亮，荧光笔正好靠这两样；两种风格不在同一页出现。
