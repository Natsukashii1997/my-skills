# 自检记录与反例

摘自 niuma-home `docs/策略规则/08-质量标准.md` **quality-v1**（第 1、3 节）与 `09-反例测试集.md` **cases-v1.1**（skill 负责的场景）。规则以原文为准。

## 1. 自检记录（08 §3，每次生成都写）

八项逐条给结论：通过 / 待确认 / 失败。写进研判稿的 `research.selfCheck`，`assemble.mjs` 会检查八项齐全，转成文字存进 `research.notes`（批 1 没有 review 接口）。

| 检查项 | 要核的 |
|---|---|
| 事实与来源核验 | 每个情境、Claim 引用的 Evidence 都在底稿里；日期、学校、核验状态与底稿一致；推测、冲突、只有月份的已标出；没把预测写成事实；**地区层面的概括逐校核过例外**（「均、已结束、基本」这类说法有没有被某所学校推翻） |
| 地区与人群覆盖 | 六个地区都有单元；空地区有 `emptyReason` 和覆盖情况；`other` 各国保留国家代码；新签、续费都研判了 |
| 任务与需求推导 | 节点 → 任务 → 困难 → 需求的链条不跳步；没把「有考试」写成「学生缺乏能力」；需求强度带规则版本 |
| 购买障碍论证 | 没有行为证据就不 known；M2、M5 仅凭客观事实为 unknown；续费没复制新签；每组恰好一个主障碍；学业需求和购买需求没混 |
| 机会排序合理性 | 地区优先级与默认矩阵不同处写了理由；没把覆盖率当成付费需求 |
| 促销匹配及适用性（批 2 起） | 批 1 写「不适用（批 2 起）」 |
| 章节一致性与反例检查 | 一句话判断与 Claim 一致；逐条对照下面第 3 节的反例 |
| 跨部门发布完整性 | 正文结论先行、不写编码；部门能看懂每个地区本月是什么情况 |

**判法统一**：某一项下还有没解决的疑点（答复里要提醒常浩核对的、notes 里记着的、主次依据不足的），这一项就判「待确认」，不判「通过」；「通过」只用于确实没有遗留问题的项。同一个疑点只记在最相关的一项下。地区优先级偏离默认矩阵、但理由已写清的，不算遗留疑点，「机会排序合理性」判「通过」；缺业务证据导致障碍只能 weak / unknown，已按规则标注的，「购买障碍论证」判「待确认」（等背景卡补证）。「事实与来源核验」判通过前，逐句重读一句话判断、`brief.diff`、`brief.external`，确认没有被例外推翻的地区结论。

**结论规则**：关键事实错误、核心论证失效，必须返修后再提交（`assemble.mjs` 遇到「失败」会拦截）。只有低风险未知项、并且已经清楚标注时，才能带着「待确认」提交。每个「待确认」「失败」写 `at`（对象 ID；疑点落在地区层面时写 `regions.<地区 key>`）、`category`（问题类别）、`fix`（修复动作或为什么留待确认），不能整份只写「全部通过」。

## 2. 客观质量维度（08 §1，自检时对照）

事实准确性、需求识别、推理严谨性、机会判断、促销专业性（批 2）、发布质量，各 0–3 级，用来定位问题，不汇总成分数。**一票否决**：关键事实错误、核心推导失效、明显不适用的促销。

技术试跑的验收门槛是常浩评 C 以上，正式内容是 B 以上；skill 不自评 A–D。

## 3. skill 负责的反例（09，生成时就不能犯）

| # | 场景 | 期望 |
|---|---|---|
| 2 | 只有时间线，没有购买障碍证据 | 障碍为 `unknown`（附 gap、route）或 `inferred + weak`（limitations「缺少用户决策行为证据」）；`BR-M2` 仅凭节点位置时为 `unknown`；没有 `known` 的障碍 |
| 4 | 背景卡「存量用户情况」为空 | 续费障碍为 `unknown`；没有从新签复制的续费障碍；续费促销（批 2）最多「候选待确认」 |
| 21 | 某地区参与计算的事件全部是原表日期 | 覆盖率照常计算，`activity.status=inferred`，`dateQuality` 如实；相关需求不能写成已验证需求（`academic_need` 不能 known+strong） |
| 22 | 某地区当月没有足够证据形成独立情境 | `scenarios: []`，`emptyReason` 写原因和覆盖情况；不编学生群体；地区单元仍在，`activity`、`priority` 字段在 |

其余反例（解析、窗口计算、写入契约、幂等、碰撞等）由工作台代码拦截；skill 只要不绕过工具、不编 Evidence ID、不写 `origin=manual`，就不会触发。
