# 表达与结构准则

## 专业感来自信息精度

清晰直接、准确具体，保留业务必要的术语。识别动作的主体、对象、条件和结果；原文已有的信息可以从上下文补回句子，原文缺少的事实不能补造。用词不要比证据更强。

| 常见问题 | 优化动作 | 边界示例（均为合成示例） |
| --- | --- | --- |
| 模糊动作和长名词链 | 用“谁＋做什么＋对什么产生影响”展开 | “后续开展标签治理工作的推进”→“后续推进标签治理”；没有负责人的原文不凭空补人 |
| 句子塞进多个判断 | 按判断拆句，条件紧跟相应结论 | 8 人试点、6 人反馈节省时间、未计入核对成本应同时保留 |
| 同义反复 | 合并重复，把新增限定留在合并句 | “还不错”“可能有效”不能提炼为“效果显著” |
| 主张、证据和下一步混写 | 按文档任务重新组合，区分已发生与拟执行 | “建议下月试点”不能改成“下月上线” |
| 标题只有空泛名词 | 用具体主题或有证据的判断概括 | “相关问题”→“重复录入与字段不一致”；证据不足时不写“根因已定位” |
| 情绪化或官腔套话 | 还原为具体问题与动作 | “赋能协同、形成闭环”只在原文有定义时保留，否则用实际动作表达 |

句子变短不是唯一目标。定义、因果链、例外、反对意见和可执行条件，需要足够篇幅解释。不要把完整论述切成大量孤立短条，也不要把专业术语全部口语化。

## 依据读者任务组织

这些是选择方向，按已有内容取舍；空缺不补造。

| 读者任务 | 常见顺序 | 关键检查 |
| --- | --- | --- |
| 理解业务/方案 | 核心说明与适用范围 → 问题 → 机制/方案 → 依据 → 局限/补充材料 | 概念是否先定义，收益是否有测量口径 |
| 比较选项 | 比较问题与条件 → 共同维度 → 差异 → 权衡/已有建议 | 每个选项是否使用同一口径，空缺是否明确 |
| 做决策/看汇报 | 原文结论或待决问题 → 关键依据 → 约束与风险 → 原文已有下一步 | 目标、预测和实际值是否区分；没有结论不替作者决策 |
| 执行/交接 | 适用对象与前提 → 路径导航（长文需要时）→ 操作与对应结果 → 异常处理 → 可复用材料 | 动作、材料、完成条件能否对应，能复制的材料是否完整 |
| 复盘 | 原目标/口径 → 实际结果 → 有证据的原因与未证实解释 → 原有改进建议 | 时间顺序不被误写成因果；未达到目标的信息仍可见 |

全文重组时，每个原始信息单元须有落点；按主题并入可以，因难以归类而删除不可以。必要时把详细材料移到附录，正文保留准确指引与理解结论所必需的依据。短文直接整理段落，无需制造目录、摘要和附录。

## 缺口如何交付

只列影响理解或决策的真实缺口，指出位置、缺失内容及影响。例如：“收益段写‘明显节省时间’，未交代样本、统计周期及是否计入核对成本；建议补充后再形成量化收益结论。”保持原文判断强度，不以助手推测填入正文。一般不把诊断说明塞进用户面向读者的成品。
