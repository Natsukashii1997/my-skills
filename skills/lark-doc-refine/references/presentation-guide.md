# 飞书原生呈现与范例学习

## 先定阅读任务，再定视觉层级

全篇层级通常由“标题 → 关键判断 → 支撑说明 → 补充材料”构成。正文以可连续阅读的段落为底，重点靠位置、标题和少量加粗显现；颜色与组件用于解释关系。先确定主题与结构，再在段落、章节和全篇三个尺度检查节奏。

| 信息关系/读者动作 | 优先组件 | 设计与适用边界 |
| --- | --- | --- |
| 背景、引言或真实引用 | 引用块，必要时灰色斜体 | 降低背景权重；实际引语保留原文和出处。风险、关键条件与主要结论不放成低对比说明 |
| 同层并列信息 | 无序列表 | 各项句式、抽象层级一致。短标签可加粗；内容长时用段落/小标题，不把全文拆成碎片 |
| 有先后或依赖的操作 | 有序列表或画板 | 有序列表表达线性步骤；分支、角色交接/依赖明确且图更易读时用画板 |
| 段内关键词/短标签 | 加粗，少量行内代码 | 加粗标判断与关键信息；行内代码适合字段、变量、精确名称或有意区分的极短标签。真正章节仍使用标题，不用代码伪造层级 |
| 一个核心结论、限制或提醒 | 高亮块 | 浅底色、明确文字标签。相同语义使用同一配色，图标可省略；大段正文不全部塞入高亮块 |
| 两至三组简短、等权内容 | 分栏＋各栏高亮块或短段落 | 两栏通常更稳；三栏仅用于短卡片。并列块文字量接近，但不能为等高补字。窄屏长段落、必须顺序阅读的论证不分栏 |
| 对象×维度、阶段×动作/结果 | 飞书原生文档表格 | 明确横纵表头、同列口径、顶端对齐；宽列留给解释，窄列留给序号/状态。按内容分配列宽，普通并列不硬建表 |
| 可复制模板、提示词、配置 | 带标题的代码块 | 复制区完整且原样可用，说明在区外，避免把说明混入可执行文本。业务正文不整体代码化 |
| 附件、参考材料、补充证据 | 附录＋原生附件/文档卡片 | 按用途分组，有简短说明和真实可用链接；正文保留必要引用，不把关键反证藏入附录 |

## 配色和密度

默认黑/灰正文和一个强调色，按用途调整：内部决策文档偏克制；分享与培训可用浅色块加强导航。橙色标题是一种参考风格，不是专业感的固定条件。红黄绿只在明确的状态或风险差异中使用，保留“允许/有条件/禁止”等文字，不能仅靠色彩传义。

表头用浅灰底＋明确字重；局部着色用于分类/状态。表格按信息宽度配置，避免大面积空列、过多窄列和嵌套复杂组件。长说明与比较任务不合适时，改成有标题的分段。避免靠连续空行制造版式；通过正常段落间距和组件分组形成留白。

制作后看真实页面：首屏是否能定位主题；扫描标题能否理解路径；高亮是否争抢注意力；分栏是否拥挤、断裂；表格是否需要反复左右寻找对应项；末尾材料能否直接使用。组件变多或配色丰富均不构成成功证据。

## 两份参考的可迁移规律

学习证据读取于 2026-09-07：完整结构/样式数据＋关键页面视觉核对。下面保存规律与来源，避免每次运行都重新抓取整篇；只有复核范例或用户要求时再访问。

### 参考一：解释价值与展示成果

[AnyGen ✖️ Lark｜长在 Lark 里的 AI 销售专家｜对外分享版 副本](https://vm94j8bzy7.feishu.cn/wiki/MaxgwJDXKikErIkquOycukWUn7c)

可观察模式：背景→痛点→方案→关键节点→收益→附录；引用与灰色斜体降低背景权重，短标签方便扫读，双栏卡片表达并列能力，原生表格表达多维对应，附录卡片组织补充材料。

应用方式：用层级与位置控制阅读速度；能力并列才分栏，关系比较才建表，重要收益与其条件一起强调。该文首屏含停用应用块，部分收益未交代测量口径；学习有效的组织方式，不继承组件故障或证据缺口，也不把该个例称为企业标准。

### 参考二：按读者意图组织执行材料

[绝活日资料包｜HR Shared Agent 副本](https://vm94j8bzy7.feishu.cn/wiki/E0Kmws1V2i4WIAkaa1BcZaM4njf)

可观察模式：“你想做什么→看哪一节→得到什么”导航表；“时间→动作→产物→完成标准”步骤表；变量说明与可复制指令分开；权限表局部着色且保留文字意义；开头承诺由模板、自检、示例和末尾行动兑现。

应用方式：长指南面向不同读者时设导航；原文已有的动作和标准放在同一行；复制材料与解释分层；完整指令用代码块。没有时间或标准时不替作者填写。该文的密集表格/代码块适合资料包，普通汇报照搬会打断论证；较宽导航列和并不总是一致的图标/色彩无需继承。副本作者身份未核验，不以页面分享者推断作者。

两篇共同支持的原则：阅读目的决定结构，信息关系决定组件；准确内容和有效层级共同产生专业感。
