# 深挖：把问题问到底

三步都用。产出的清晰和深刻，来自问得够深：同一件事，不同角色做法不同，同一角色新人和老手不同，同一个人在不同情境下也不同。这些差异不会自己出现在材料里，要先想到去问、去查，才挖得出来。

思路来自 grill-me：把要弄清的事画成一棵**追问树**，每个答案会长出下一层问题；一轮问完当前能问的，再根据答案问下一轮，直到树上没有悬而未决的分叉。

## 1. 事实自己查，决定才问用户

- **事实**（数据里有没有、谁发的、多少、多久）是你的活。材料里能查到的，自己查或交给子代理查，不问用户。
- **决定**（这次给谁看、要不要分开做、阈值定多少、哪个优先）是用户的。每个决定都要摆到用户面前，带推荐答案，用户回答“是”就按推荐来。
- 一个问题要先查事实才能问的，先派人去查，别的问题照常问，不要整轮等着。

## 2. 差异维度：每次都要过一遍

动手前把下面每个维度过一遍，写出“这里可能有什么不同”。这张表不是标准答案，路觅案例里的新老销售也只是其中一格；但每一格都要想过，想过后判断不存在的，写一句为什么。

| 维度 | 要问的 | 路觅案例里（只作参照） |
|---|---|---|
| 角色 | 这件事从头到尾经过哪些人：谁发起、谁做、谁接手、谁协作、谁检查？每个人看到的、要做的一样吗？ | 销售、客服、班主任、教务、导师、组长；导师在企微里也是“外部联系人” |
| 熟练度和程度 | 同一个角色里，新人和老手、客户多的和客户少的、能力强的和弱的，做法、卡点、要的东西一样吗？ | 新人要的是“下一步做什么”，老手要的是“别漏掉谁” |
| 业务线和产品 | 不同业务线、产品、价位的流程、对象和节奏有什么不同？差异落在字段、规则、页面还是整套流程？ | 国课按学科，大学按课号；国课先试听，大学直接买课时包的多 |
| 服务对象 | 面对的人有几类：付钱的和使用的、新客和老客、高意向和低意向？ | 国课家长为主，大学学生为主 |
| 情境 | 什么时间、什么渠道、什么阶段、什么例外情况下做法会变？ | 夜间、时差、考试季；单聊和群；改期、投诉、紧急 |
| 结果 | 做成和没做成的差在哪？承诺了的兑现了没有？ | 承诺要看有没有兑现，不是看客户有没有追问 |
| 现有工具 | 一线自己在手工补什么（自建表格、工具、备注习惯）？补的就是系统缺的 | 销售自建的意向跟进工作台、学员跟进管家 |

每个维度都走同样的路：

1. **提假设**：这里可能有什么不同。
2. **查证据**：访谈里有没有人说到，数据能不能按这个维度分组算出来。
3. **定层次**：差异是真的，落在哪一层（字段、规则、页面、整套流程）；是假的，写明依据。
4. **问决定**：只有用户能拍板的（比如要不要各做一套流程），才问。

## 3. 每个业务单元追到底

对每一件一线要处理的事，往下追六层，哪层答不上来，就是要去查或要问的地方：

1. 它是什么，业务里叫什么？
2. 什么时候发生，由什么触发？
3. 谁来处理，交给谁？
4. 怎样算做完，留下什么痕迹？
5. 没做完会怎样，多久算晚？
6. 有多少、多频繁，在不同角色、不同情境下一样吗？

**量结果，不量代理。** 想知道“承诺有没有兑现”，就去量兑现（承诺之后有没有完成的痕迹），不要拿“客户有没有追问”代替。代理指标选偏了，结论会跟着反过来。

## 4. 什么时候问、问几轮

- **动手前**：SKILL.md 第 2 节的第一轮问清现状和材料；第二轮起，把这一步 reference 的“要问用户的”和第 2 节的差异维度一起过，能问的一轮问完。
- **取证中**：数据和访谈里冒出新的分叉（比如发现新人和老手的行为差很多，或者用户的原话和证据相反），停下来补问一轮，再继续。用户明确提过的结构要求（比如“两条线要分开做”）和证据相反时，一定要问，不能自己改成另一种做法。
- **问到什么时候**：追问树上没有悬而未决的分叉，每个差异维度都有结论（是真的、落在哪层，或者不存在、为什么）。
- **问法**：照 SKILL.md 第 2 节，用业务的话、编号、给选项和推荐答案。每轮写清这一轮为什么问这些。

**不能提问时**（被别的 agent 调用、模拟测试）：把本该问的问题和推荐答案写进交付说明，按推荐答案继续；会改变方案方向的分叉，在报告首页标“待确认”。

## 5. 在三步里各问什么

| 步骤 | 深挖的重点 |
|---|---|
| 一 · 访谈提纲 | 受访者里有没有不同角色、不同熟练度、不同业务线：要不要分套，哪几段分开问；提纲里专门留追问差异的题，比如“刚来的时候你是怎么做的，现在有什么不同”“碰到夜里来的消息、考试季，做法会变吗” |
| 二 · 技术方案 | 每个差异维度用数据验证，落到字段、规则、页面或整套流程；落到整套流程的单独成为差异专题；每类待办追到第 3 节的六层 |
| 三 · 执行规范 | 不同人群的动作、节奏、检查口径是否不同；同一动作在不同情境下（夜间、例外、高峰）怎么做 |
