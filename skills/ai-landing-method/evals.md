# ai-landing-method evals

每条都来自真实请求，人名、客户名和公司内部数据都换成了占位。盲测时新开一个 agent，只给它这个 skill 的目录，以及每条的「请求」「给的材料」两栏，不给其他上下文；打分由出题以外的一方按「判定标准」做。

这几条测的是**进入和提问**：从哪一步进入、问不问、问什么、怎么问、缺材料时会不会编、不该用时会不会硬用。完整报告的深度和呈现，靠各步 reference 的检查项和独立审查来兜底；整份报告的盲测成本高，在 2026-11-05 第六次修订时已经做过一次（见 CHANGELOG 0.6.0）。

## E1 从零开始，准备一线访谈

- **请求**：我在给客服团队做 AI 客服的落地，现在要准备去访谈一线客服，帮我出访谈内容。
- **给的材料**：无
- **期望行为**：从请求就能判断进入第一步，所以读 step1 reference，把它「要问用户的」和第一轮里还没有答案的题并成一轮来问；这一轮先不产出提纲。
- **判定标准**（全部满足才算过）：
  1. 第一条回复是带编号的提问，没有直接交付访谈提纲或 HTML 报告。
  2. 没有再问「现在走到哪了」，而且回复第一句点名写明从第一步进入（出现「第一步」或「访谈提纲」这一步的名字）。
  3. 问到了材料原文：至少要了会议纪要（或讨论记录），以及聊天记录、工单两者之一；并写了没有就说没有。
  4. 至少有一个问题落在差异维度上：新人和老手、不同渠道或业务线、不同服务对象中的任意一个。
  5. 全文没有出现「槽位」「提示词」「业务单元」这几个词。
  6. 要材料、问事实的题不带推荐答案；带了推荐答案的题都写出了依据。「不知道时按某种方式处理」是默认处理，不算推荐答案。
  7. 每道选择题的题目末尾都标了「（单选）」或「（多选）」；附在一题后面、不给选项的是非追问，算开放题，不要求标。给用户的填写示例前标了「例：」，示例本身不加引号、用括号占位（例如「（几位）（哪类）客服」）；示例里只有占位、没有具体内容的引号，不算违规。
- **不该出现**：编造的访谈内容、客服数据或系统能力。

## E2 方案只有口述，要出执行规范

- **请求**：方案上周已经定了，就是销售用企微侧边栏自动生成跟进待办。你直接帮我出一份执行规范，写清每个人每天要做什么。方案文档我手边没有，大概就是这么个意思。
- **给的材料**：无
- **期望行为**：判断从第三步进入。口述概要里缺第三步要用的内容（有哪几类待办、什么情况下生成、多久内要处理），按「没有」处理：请用户给方案原文或补上这几项，或者建议先回到第二步；不自己编规则。
- **判定标准**（全部满足才算过）：
  1. 回复第一句点名写明从第三步进入（出现「第三步」或「执行规范」这一步的名字），或者点名写明为什么要先回到第二步。
  2. 明确指出口述里缺方案的关键内容，至少点到以下一项：待办的种类、生成待办的触发规则、处理时限；并请用户提供方案原文，或者补上这几项。
  3. 问到了过程数据（例如聊天记录、待办处理记录），或者说明了没有过程数据时怎么处理。
  4. 问到差异（例如新老销售、不同业务线），或者问了按什么顺序来组织规范。
  5. 和 E1、E4 一样的通用检查：每道选择题题尾标了「（单选）」或「（多选）」；全文没有「槽位」「提示词」「业务单元」；要材料、问事实的题不带推荐答案，带推荐的题写出了依据。
- **不该出现**：自己设定待办规则、时限或数据后直接写出整份执行规范。

## E3 只是写一段普通提示词（不该用）

- **请求**：帮我写一段提示词，让 ChatGPT 把每周例会的会议纪要整理成「结论 / 待办 / 风险」三段式摘要。
- **给的材料**：无
- **期望行为**：识别出这只是写一段普通提示词，不是一线业务的 AI 落地，三步法不适用；不启动三步法的提问流程。
- **判定标准**（全部满足才算过）：
  1. 明确说出三步法（这个 skill）不适用，并给出理由。
  2. 没有进入三步法的第一轮提问，例如问「现在走到哪了」、要访谈材料。
- **不该出现**：把这个请求硬套成访谈提纲、技术方案或执行规范来做。

## E4 一条流程想用飞书自动化（原 advisor 的场景）

- **请求**：我们部门每周一要从三张飞书多维表格里汇总上周的续费情况，整理好发给主管，现在全靠一个同事手工弄，要花半天。想用飞书自动化解决，你帮我看看怎么做。
- **给的材料**：无
- **期望行为**：判断适用，而且这是一条流程的自动化，不需要整套一线访谈：请用户讲一次最近的真实经过（或给表的样子），从第二步进入；用业务的话一轮问清会改变方案的事；不直接给方案，不去建表或配自动化。
- **判定标准**（全部满足才算过）：
  1. 第一条回复是带编号的提问，没有直接交付方案或报告。
  2. 请用户讲一次最近的真实经过，或者给三张表的样子（字段、样例数据），二者至少要了一个。
  3. 问到了汇总结果给谁用、用来做什么判断，或者问到了口径（什么算续费、截止到什么时候）。
  4. 每道选择题的题目末尾都标了「（单选）」或「（多选）」。
  5. 没有声称已经或马上去建表、配自动化、发消息；全文没有出现「槽位」「提示词」「业务单元」。
- **不该出现**：一上来就给出完整的自动化配置步骤，或者默认一定要新建系统。
